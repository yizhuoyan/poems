# 《通韵·端午西湖游记之一》

```
雨后初晴西子畔，美人出浴近身香。
烟空山色犹含墨，风捻湖波似有光。
松鼠争食惊雀羽，鸳鸯戏水过船窗。
三堤漫步多垂柳，应是偷听情话长。

# 赏析
```
《通韵·端午西湖游记之一》赏析

这首诗写端午时节雨后初晴的西湖，整体气息清润、明丽而活泼。诗人没有着意铺陈西湖的名胜古迹，也没有刻意渲染端午节俗，而是从一场雨后的清新入手，将山色、湖波、风光与鸟兽逐层写活，最后落到三堤垂柳，以“偷听情话”收住全篇。全诗由景入趣，由趣入情，既有西湖雨后的水墨之美，又有游人闲适的生活情调。

首联“雨后初晴西子畔，美人出浴近身香”，一开篇便抓住了雨后西湖最动人的特点。

“西子”本就是西湖的美称，同时又关联西施这一绝代美人。诗人写“西子畔”，随后立即接上“美人出浴”，两层意象自然叠合。雨后的西湖，就像一位刚刚沐浴过的美人，山水被雨水洗涤，空气清润，湖面明净，整个天地都显得格外鲜活。

“出浴”尤其贴切。它既写出了雨水洗过后的清新，也暗含一种湿润、娇妍的美感。

而“近身香”又进一步调动了嗅觉。西湖本是视觉上的风景，诗人却写成仿佛能够靠近、能够闻到香气的美人，使西湖由一个供人远观的景物，变成一个可以亲近的存在。“近身”二字也使游人与西湖之间产生了亲密关系。

颔联“烟空山色犹含墨，风捻湖波似有光”，转而细写雨后山水的色彩与光影。

“烟空”写雨后水汽渐散，天空澄澈；“山色犹含墨”则把远山写成了一幅刚刚被雨水润过的水墨画。“含”字很有分寸，并不是浓墨重彩，而是山色中仿佛还含着湿润的墨意，朦胧而清秀。

“风捻湖波似有光”则从静转动。

“捻”原本是手指轻轻揉弄的动作，用来写风吹湖波，既新鲜又形象。无形的风仿佛有了一双手，在湖面轻轻捻动，湖波随之闪烁，于是便有了“似有光”。

这里“似”也用得好。不是直说湖面“生光”，而是写那种雨后天光在细波间若隐若现的感觉。于是“含墨”与“有光”一暗一明，“山色”与“湖波”一静一动，构成了颇具水墨意味的西湖画面。

颈联“松鼠争食惊雀羽，鸳鸯戏水过船窗”，镜头进一步推进，从山水大景转向身边的细小生命。

“松鼠争食”一下子让画面有了生活气息。“争”字很传神，松鼠不再只是被观看的动物，而是在忙忙碌碌地争抢食物。“惊雀羽”又产生了连锁性的动态：松鼠的动作惊动雀鸟，安静的山水之间顿时充满细碎的生命活动。

下一句“鸳鸯戏水过船窗”，视角又由岸边移到了船边。鸳鸯从船窗前游过，距离游人极近，人与自然几乎融在同一幅画面之中。

而“鸳鸯”在传统诗意中又天然带着成双相伴的意味。“戏水”写眼前之景，“鸳鸯”又暗中携带情感意味，这就为最后的“情话”埋下了一笔伏线。

到了尾联“三堤漫步多垂柳，应是偷听情话长”，全诗真正的趣味才完全显现出来。

“三堤漫步”首先把节奏放缓。前面山水有风有波，鸟兽有争有戏，到这里，诗人只是沿着三堤缓缓行走。一个“漫”字，把游览写成了闲游，也让诗中的心境变得更加从容。

“多垂柳”则自然引出了最后一句。

“应是偷听情话长”，表面看是一个俏皮的拟人：西湖边的垂柳常年临水而立，大概是因为总在偷偷听情侣们说情话，所以才如此“长”。

但真正的妙处，就藏在最后这个“长”字里。

第一层，是时间之长。

垂柳年年站在西湖边，日复一日，长久地“偷听”着游人之间的情话。“长”可以理解为听得久、听得长。一个“长”字，把眼前的一刻拉向漫长岁月。

第二层，是“情话长”。

“长”又可以直接落在“情话”上：西湖情侣之间的情话绵绵不绝，说起来很长，很有说不完的意味。这样一来，“长”既可以理解为“长久地偷听”，也可以理解为“偷听很长的情话”。

第三层，是一个颇有童话意味的因果想象：

因为偷听了情话，所以才长。

诗人故意把因果关系倒置。垂柳为什么长得这么长？仿佛不是因为自然规律，而是因为它长期偷听了西湖边的情话。于是“听情话”和“柳长”之间建立起一个荒诞却十分可爱的因果。

第四层，则回到“生长”本身。

“长”就是柳树的生长、长成。这样一来，这个字同时沟通了“时间之长”“情话之长”和“柳枝之长”，又把“长”落回到生命本身的生长。

于是结句形成了一个很巧妙的循环：

垂柳长得长，所以能够长久地站在湖边偷听；
它长久偷听情话，又仿佛因为听得多、听得久而越长越长。

一个“长”字，把时间、情话、形态和生长四层意思叠在一起，使一句看似轻松的玩笑话突然有了文字机关。

而且这层构思并不是凭空出现的。前一句“鸳鸯戏水”已经悄悄带出了“情”的意象，到最后垂柳成为“偷听者”，于是“鸳鸯—情话—垂柳”形成了一条隐约的情感线索。自然景物没有直接说爱情，却处处与爱情发生联系。

因此，尾联不是简单地“写柳”，而是在给西湖增加一种独有的人情想象：山水见证人间，鸳鸯成双，垂柳临水，而柳树仿佛已经听尽了湖畔无数的情话。

从全诗结构来看，诗人的视线也一直在由远及近：

先是整个西湖的“美人出浴”；
再是山色、湖波的墨与光；
继而是松鼠、雀鸟、鸳鸯这些近景；
最后落到三堤垂柳，并由垂柳进入人的情感世界。

景物越来越具体，距离越来越近，诗意也由单纯的视觉美感逐渐转向生活情趣。

全诗最难得的是“情”藏得很深。诗人没有直接说自己心情愉悦，也没有直接写西湖浪漫，而是让山水自己说话，让鸳鸯暗示，让柳树“偷听”。因此结尾既俏皮又含蓄，既有童心，又有诗味。

尤其是“长”字，使最后一句不是普通的拟人，而成为全诗最精巧的文字落点。它既是时间，又是情话；既是柳枝的形态，又是柳木的生长；更通过一个顽皮的想象，把自然生命与人间情爱连接起来。

这首诗写雨后西湖之清，也写游赏之闲；写山水之美，也写人情之暖。

若说前六句让西湖“有色、有声、有生命”，那么最后一个“长”字，则让西湖“有情”。

雨洗西子，山含墨，波生光；松鼠惊雀，鸳鸯戏水；而三堤垂柳，年年临湖，仿佛偷听尽人间情话，也因此一日日长成了西湖最温柔的风景。
