# 《通韵·端午西湖游记之一》

```
雨后初晴西子畔，美人出浴近身香。
烟空山色犹含墨，风捻湖波似有光。
松鼠争食惊雀羽，鸳鸯戏水过船窗。
三堤漫步多垂柳，应是偷听情话长。
```

# 赏析
```
首联以苏轼"欲把西湖比西子"之典切入——雨后初晴的西湖，如同一出水的美人，清新脱俗、暗香浮动。"近身香"三字将嗅觉引入诗中，湖风拂面仿佛带着美人的体香，极尽曼妙。颔联写远望——烟岚中的山色如含墨未干的画卷，微风吹拂湖面泛起粼粼波光，"捻"字将风拟作手指轻轻捻动湖波，纤细柔美。

颈联以工笔细描两个活泼的场景——松鼠争食惊起飞雀，鸳鸯戏水穿梭于船窗之下，一动一静、一树一水，富有生趣。尾联"三堤漫步多垂柳，应是偷听情话长"最为动人——苏堤之上垂柳依依，诗人幽默地猜想这些柳树一定是在偷听游人的绵绵情话吧。将垂柳拟作好事者，既有生活气息又有天真的诗趣，为全诗画上了一个俏皮温馨的句号。
```
