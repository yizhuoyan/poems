# 赏析
```
《通韵·春雨湿冷》赏析

这首诗以春雨、寒潮和红日构成一明一暗的自然图景，又借自然气候的变化寄寓对人间境况的感受。前两句写连绵阴雨、寒潮反复，天地昏暗，寒意入骨；后两句忽然转折，以“红日”改变乾坤，以“人心”改变世间。诗的真正转折并不只是天气转晴，而是由“天寒”写到“心暖”，由自然的阴冷写到人间的清明。四句之间，既有气象上的变化，也有精神上的升华。

“连绵春雨压天暗，反复寒潮入骨冰。”

首句一个“压”字很有分量。

“春雨”本应与春意、生机联系在一起，但这里却是“连绵”，没有停歇；而且不是简单说天阴，而是说“压天暗”。雨势仿佛从上而下压住天空，使整个天地都沉入阴暗之中。“压”因此不只是视觉感受，也带出一种沉重、压抑的情绪。

第二句进一步加深这种感受。“反复”与“连绵”相应，前者写寒潮一次又一次袭来，后者写春雨久久不断；“入骨”则将寒意由外而内推进。最后以一个“冰”字收住，使寒冷获得了近乎凝固的质感。

“天暗”是环境之暗，“入骨冰”则是身体之寒。两句由天及人，由视觉转为触觉，寒意层层加深。

“改换乾坤红日起，人心尽暖世间清。”

第三句突然翻转。

“改换乾坤”四字气势骤然打开，与前面的“压天暗”形成强烈反差。此前仿佛整个天地都被春雨寒潮笼罩，此刻一轮“红日”出现，便使天地重新换了模样。

“红日”当然首先是自然景象，但放在“改换乾坤”之后，它已经具有超越天气本身的意味。它不是简单的“雨停了、太阳出来了”，而是一种能够驱散阴霾、改变天地面貌的光明力量。

而最重要的变化发生在第四句：

“人心尽暖世间清。”

如果说第三句改变的是“乾坤”，第四句改变的就是“人间”。

“暖”与前面的“冰”遥相对应：“入骨冰”写寒冷深入身体，“人心尽暖”则写温暖深入内心。“冰”是寒潮留下的感受，“暖”则是红日带来的精神回响。这样一来，诗便完成了从身体之寒到心灵之暖的转换。

末尾的“清”也很有意味。它不是单纯的“天气清朗”，而是与“人心尽暖”相连：人心温暖了，世间也随之变得清明、清朗。这里实际上形成了一种由心及世的关系——外在世界究竟呈现怎样的面貌，不只取决于天气，也取决于人的内心。

因此，“人心尽暖世间清”既是景的收束，也是意的升华。诗写春雨寒潮，最终真正想写的却是：阴霾可以笼罩天地，却未必能够冻结人心；一旦心中有了温暖与光明，世间便会重新显出清朗。

全诗最有力量的地方，是没有停留在“雨寒日暖”的自然转换，而是把“红日”最终化为照亮人心的力量。于是，诗中的春天真正到来之处，不只是天上的太阳，而是人的心中。
```
