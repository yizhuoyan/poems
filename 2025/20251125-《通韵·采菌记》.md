# 《通韵·采菌记》 

```
自在松林雾里呆，灭门强盗雨中来。
提篮带棍沿山扫，掀草攀崖扒地摘。
怀璧匹夫皆有罪，不材之木亦成柴。
感君怜问吾归处，已入汤锅待水开。
```
>> 周末两日与友人雨中进山摘蘑菇，作诗为记。

# 赏析
```
这是一首别出心裁的蘑菇采摘诗，全篇以蘑菇的视角展开，幽默生动。"自在松林雾里呆"写菌子在林中悠然自得的神态，"呆"字憨态可掬；"灭门强盗雨中来"称呼采菌人为"强盗"，一场快乐的采菌活动变成了"灭门惨案"，令人忍俊不禁。

颔联写采菌动作——"提篮带棍沿山扫，掀草攀崖扒地摘"用"扫""掀""攀""扒"四个动词写尽了采菌人的"凶残"与专业，从菌子的视角来看，确实是一场地毯式的扫荡。颈联"怀璧匹夫皆有罪，不材之木亦成柴"以典故作辩解——菌子何罪之有？只因鲜美如"璧"便难逃被采的命运。尾联"感君怜问吾归处，已入汤锅待水开"以菌子的口吻答谢"强盗"的问候：我已下锅，静候水开！全诗构思奇巧，视角新颖，将一次普通的采菌活动写成了充满黑色幽默的"菌子自述"，读之令人捧腹。
```
