# 《通韵·采菌记》 

```
自在松林雾里呆，灭门强盗雨中来。
提篮带棍沿山扫，掀草攀崖扒地摘。
怀璧匹夫皆有罪，不材之木亦成柴。
感君怜问吾归处，已入汤锅待水开。
```
>> 周末两日与友人雨中进山摘蘑菇，作诗为记。写于20251125

# 赏析
```
确实，上一版把叙事主体错误地理解成了采菌者。若以“蘑菇”为第一视角重新读，这首诗的结构、典故和最后一句都会发生根本性的变化：它其实是一首以蘑菇口吻写成的“受难记”，而且是一篇带着黑色幽默的蘑菇自述。

下面重新赏析。

《通韵·采菌记》赏析

《采菌记》是一首构思十分巧妙的拟人纪游诗。全诗并非站在采菌者的角度记录一次雨中采摘，而是完全站在蘑菇一方，以“我”的口吻讲述自己原本自在地生长于松林，最终却遭遇人类搜山、掀草、扒地，被发现、被摘走，直至进入汤锅的全过程。

诗最有趣之处，在于它故意借用“强盗”“怀璧其罪”“不材之木”等人类社会的语言来描述蘑菇的遭遇，使一场普通的采菌活动忽然具有了荒诞的历史剧和悲喜剧色彩。蘑菇没有犯任何错误，只因为生长在山林、长得足够好、恰好被人发现，便从“自在”的生命变成了案板上的食材。全诗表面诙谐，底层却隐含着一种颇有意味的生命视角：天地万物各自生长，人类所谓的“发现”和“收获”，从另一个生命的角度看，也可能正是一场突如其来的灾难。

首联“自在松林雾里呆，灭门强盗雨中来”，首先写蘑菇原本的生活状态，然后骤然制造灾变。

“自在松林雾里呆”，一个“呆”字非常传神。

这里的“呆”并不是贬义，而是一种毫无机心的状态。蘑菇安安静静地长在松林之中，被雾气笼罩，不争、不动，也不知道山外的人事。它甚至没有意识到自己即将面临什么。

“自在”二字尤其重要，因为它是全诗蘑菇命运的起点，也是后来“汤锅”结局的反衬。

蘑菇本来只是在自然中自在地存在。

但第二句“灭门强盗雨中来”，世界突然变了。

这里的“灭门强盗”从蘑菇视角看，就不再是诗人的自嘲，而是蘑菇对来人的真实评价。对于蘑菇而言，一群人冒雨进入松林，沿山搜寻，把自己和同类一个个掀出来、摘走，确实近似一场“灭门”。

“雨中来”又强化了这种突袭感。

蘑菇原本躲在雾中安静生长，强盗却借着雨势突然闯入。这里甚至有一种非常有趣的“猎物视角”：人类认为自己是在雨中寻菌，蘑菇却可能认为一场灾难正在降临。

于是第一联已经完成了视角转换：

人眼中的“采菌”，在蘑菇眼中是“灭门”。

颔联“提篮带棍沿山扫，掀草攀崖扒地摘”，则是蘑菇眼中的“强盗行动”。

“提篮带棍”尤其具有喜剧色彩。蘑菇并不知道人类为什么带着这些东西进山，在它眼里，那是一群装备齐全、目标明确的入侵者。

“沿山扫”的“扫”也很有意思。人类所谓“找蘑菇”，从蘑菇的视角看却像是一场地毯式搜捕。这里的“扫”已经带有清剿意味。

接下来的“掀草攀崖扒地摘”，几乎是一组连续的灾难镜头。

草被掀开，
山崖被攀上，
土地被扒开，
最后，同类被摘走。

四个动作一气呵成，节奏越来越紧，蘑菇的处境也越来越危险。

而且这几个动作都是从人的角度看“采摘过程”，从蘑菇的角度看却是对其生存空间的层层侵犯。尤其“扒地”一词，意味着人类甚至不满足于寻找表面可见之物，而是要把藏在土地中的生命也翻出来。

至此，“灭门强盗”已经不再只是夸张，而成为整首诗最核心的拟人化设定。

颈联“怀璧匹夫皆有罪，不材之木亦成柴”，则是全诗思想与语言趣味最集中的地方。

“怀璧匹夫皆有罪”，化用了“匹夫无罪，怀璧其罪”。

站在蘑菇的角度，这句话简直是对自身命运最精准的概括。

蘑菇有什么罪？

没有。

它只是长得好，恰好被发现。

但对于一个饥饿的采菌者来说，蘑菇身上的“璧”——也就是它本身具有的食用价值——反而成了它遭殃的原因。

因此，“怀璧”在这里发生了非常巧妙的拟人转换：蘑菇不是因为做错了什么而被摘，而是因为“拥有价值”而被摘。

更有趣的是，下一句“不材之木亦成柴”又将这种荒诞逻辑进一步推进。

“不材之木”本来是一个带有庄子意味的典故，指有些树木因为“不成材”，反而能够逃过砍伐。然而在这首诗里，即使是“不材”也未必能够幸免。

为什么？

因为一旦落入“强盗”的视野，就可以被赋予用途。

于是这里产生了一个非常幽默的生命哲学：

有价值，是“怀璧”，有罪；
没有价值，也可以被当成“柴”。

从蘑菇的角度说，这就是一种彻底的不讲理。

你长得好，采你；
你长得不好，也可能被顺手带走。

“皆有罪”因此带有非常强烈的荒诞感。不是蘑菇真的有罪，而是在人类的需求面前，蘑菇似乎无论如何都很难获得“无罪释放”。

同时，“不材之木亦成柴”还进一步扩大了蘑菇的悲剧范围。诗人不再只写某一朵蘑菇，而是把山林中的一切植物都纳入这种命运之中：能够被利用的，终究可能被利用。

这样，蘑菇的遭遇便不只是一个玩笑，而具有了一点寓言意味。

尾联“感君怜问吾归处，已入汤锅待水开”，则是全诗最精彩、也是最关键的收束。

“感君怜问吾归处”从语言上看极其文雅，甚至带有古典诗歌中酬答赠诗的味道。“感君怜”仿佛有人关切地询问自己的归宿。

但答案却荒诞得近乎残酷：

“已入汤锅待水开。”

这一句一下子把全诗从山林拉到了厨房。

而最妙的是“已入”。

不是“将入”，不是“欲入”，而是“已入”。

等到诗中的“我”开口回答时，灾难已经结束，命运已经完成。蘑菇甚至没有机会逃跑，甚至没有机会抗议，甚至没有机会知道自己什么时候被摘走；它现在已经躺在汤锅里，只等待最后一道程序。

“待水开”三个字尤其冷幽默。

它没有使用“受烹”“遭煮”之类沉重的词，而只是极平淡地说“等水开”。正因为如此，反而产生了强烈的喜剧效果。

这就像一个古代囚徒在临刑前平静地说：

我已经进锅了，只等水开。

生命的悲剧，被日常生活的烟火气轻轻一带，反而更加令人发笑。

而从结构上看，这一句又与首句形成极漂亮的照应：

自在松林雾里呆，
已入汤锅待水开。

一个在松林，一个在汤锅；
一个是雾里自在，一个是锅中待煮；
一个是自然生命的状态，一个是食物生命的终点。

中间不过经历了“强盗雨中来”“沿山扫”“掀草攀崖”“扒地摘”这样一场突如其来的劫难。

因此，全诗实际上可以看作蘑菇的一生被压缩成了八句：

生于松林，
自在而呆；
强盗突至，
搜山灭门；
因“怀璧”获罪，
连“不材”亦难逃；
最终入锅，
等待水开。

这就使“采菌记”三个字产生了很有趣的反讽。

所谓“采菌记”，在人类眼中是一次周末雨中进山的趣事，是提篮、搜寻、发现和收获；但在蘑菇眼中，却是一部完整的“灾难实录”。

同一件事，两个视角，完全不同的意义。

这也是全诗最值得玩味的地方。

诗人没有把采菌者写成高雅的山林游人，而是彻底站到蘑菇一边，把采菌者定义为“灭门强盗”。这种视角倒置，使普通的生活趣事获得了文学上的陌生感。读者原本知道“摘蘑菇”意味着什么，但当诗人让蘑菇自己讲述，就会突然意识到：所谓“采摘”，其实是另一个生命的终结。

不过，这首诗并没有因此变得悲苦。

恰恰相反，它始终保持着轻松、调侃甚至顽皮的语气。“强盗”“有罪”“成柴”“汤锅”这些词不断把宏大的历史词汇拉进极其日常的山野生活，使诗歌形成一种独特的黑色幽默。

尤其“怀璧匹夫皆有罪”一句，将蘑菇的命运与人类社会中的“怀璧其罪”联系起来，使一朵普通蘑菇仿佛拥有了人的意识：它知道自己没有犯罪，却偏偏因为拥有“璧”而获罪。

到了最后，它甚至已经接受了自己的命运。

“已入汤锅待水开。”

这里既有无奈，也有一种近乎认命的幽默。

全诗因此不是单纯写“采到了多少蘑菇”，而是用蘑菇的眼睛重新观看人类。人类以为自己在享受自然馈赠，蘑菇却把这一切看成一场来自山外的侵袭。正是在这种视角倒置中，诗获得了超出日常纪游的趣味。

更妙的是，诗的最后没有写“吃”，而只写“待水开”。

这一停顿给结尾留下了一点余味：蘑菇的生命已经结束，但人类的“美食故事”才刚刚开始。对采菌者而言，这是满载而归；对蘑菇而言，却是“归处已定”。

所以，《采菌记》是一首很典型的“以小见大”的趣诗：写的是蘑菇，写的却是生命视角；写的是采摘，写的却是命运；写的是汤锅，写的却是自然生命与人的关系。

全诗最妙的不是把蘑菇写得多么可怜，而是让蘑菇自己一本正经地讲述这场“灭门惨案”。它不哭、不喊，甚至还引经据典地解释自己为什么遭殃，最后平静地告诉世人：

我原本自在松林雾里呆，
如今已入汤锅，只等水开。

这一笑之中有野趣，有机锋，也有一点对生命命运的幽默凝视。

可以说，这是一篇披着古典诗歌外衣的“蘑菇受难记”，也是一次非常成功的视角倒置：人类进山本为采菌，蘑菇落笔，却把人类写成了山林里的强盗。
```
