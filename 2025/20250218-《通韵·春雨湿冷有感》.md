# 《通韵·春雨湿冷有感》
```
连绵春雨压天暗，反复寒潮入骨冰。
我换乾坤红日起，人心尽暖世间清。
```

# 赏析
```
前两句极写春寒之甚——"连绵春雨压天暗"以"压"字写乌云低垂、雨幕沉沉，透不过气的压抑感；"反复寒潮入骨冰"写寒潮一波又一波侵袭，寒意直入骨髓。一个"压"一个"冰"，将初春的湿冷写得淋漓透彻。

后两句陡然转折，气势如虹——"我换乾坤红日起"，"换乾坤"三字气吞山河，诗人不是消极忍受这阴冷天气，而是要以一己之力改天换地，让红日升起！"人心尽暖世间清"进一步拓展——不仅要驱散自然之寒，还要温暖所有人的心，使整个世界变得清澈光明。全诗前后形成强烈反差：前两句天地昏暗、寒入骨髓；后两句乾坤换尽、人心皆暖。从"压"到"换"，从"冰"到"暖"，二十八字中完成了一次精神上的彻底翻盘，豪情万丈，读之令人热血沸腾。
```
