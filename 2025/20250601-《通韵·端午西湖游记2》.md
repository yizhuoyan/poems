# 《通韵·端午西湖游记2》

```
一水泱泱绿柳长，小舟画舫躲鸳鸯。
雷峰再立劫灰上，英烈今眠笑语旁。
日月双悬于氏墓，乾坤半壁岳王堂。
千秋大义万年颂，我辈凡夫血未凉!
```

# 赏析
```
诗写端午游西湖，却并非纯粹的风景游览，而是融入了深沉的历史感怀。首联以轻松笔调开篇——湖水泱泱、绿柳垂长，画舫之间鸳鸯戏水，一派太平盛世的游春图景。颔联随即转入沉重的历史——"雷峰再立劫灰上"写雷峰塔毁后重建，"劫灰"二字暗含战火与毁灭；"英烈今眠笑语旁"将长眠的英雄与身边游人的欢声笑语并置，古今交织，令人深思。

颈联出句"日月双悬于氏墓"以日月高悬喻于谦的忠义昭昭，对句"乾坤半壁岳王堂"写岳飞撑起南宋半壁江山的功业——两位民族英雄遥相呼应。尾联"千秋大义万年颂"以宏阔的赞颂收束历史感慨，而"我辈凡夫血未凉"则从古代的英烈回到了当下的"我辈"，先贤的大义仍在血脉中奔涌。全诗于端午佳节西湖的欢声笑语之中，唤起了一段慷慨激昂的民族记忆。
```
