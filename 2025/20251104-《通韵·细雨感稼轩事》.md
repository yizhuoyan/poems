# 《通韵·细雨感稼轩事》 

```
蒙蒙细雨落何典？但向长天问稼轩。
弱冠堪鸠两千甲，苍颜老叹几十年！
从来志士志难遂，却有名词名久传。
我辈无才逢盛世，与君踏遍大河山。
```

# 赏析
```
这是一首致敬辛弃疾的怀古之作。首句"蒙蒙细雨落何典"以细雨起兴——这蒙蒙细雨像从哪部经典中飘落，引出与古人的对话。次句"但向长天问稼轩"向天发问，将辛弃疾（号稼轩）的名字呼入苍茫天地之中，开篇即有一种跨越时空的对话感。

颔联以辛弃疾一生之对照：二十岁率五十骑突入金营生擒叛徒张安国，可谓"弱冠堪鸠两千甲"；然而南归后投闲置散数十年，壮志难酬，只能"苍颜老叹几十年"。颈联慨叹英雄自古志难遂，但辛词却长留世间——一个"志"两个"名"的巧妙对举，写出命运的残酷与不朽的馈赠。尾联"我辈无才逢盛世，与君踏遍大河山"笔锋一转——恰好此身逢此盛世，愿追随稼轩的足迹游遍山河，以脚步丈量他笔墨描绘过的壮丽河山，亦是致敬，亦是传承。
```
