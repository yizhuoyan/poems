# 《通韵·周五冬日嘉陵江边观野钓有感》 

```
江日悠悠云化鳞，来回闲鸟寂为邻。
抛钩入定心无碍，山水终归野钓人。
```
>> 25年11月21日周五，喜冬日调休一日，于嘉陵江边见两岸野钓客，有感。

# 赏析
```
这首小诗写冬日江畔观钓，意境闲远。首句"江日悠悠云化鳞"——江流与冬日都显得从容缓慢，天边浮云倒映水中如片片鱼鳞，"化鳞"一词将云与鱼巧妙勾连，虚实交融。"来回闲鸟寂为邻"写闲鸟在岸边来回飞落，以动衬静，"寂为邻"三字将静谧的江水视为相守的邻居，富有温情。

后两句由观钓者写至钓者之心境——"抛钩入定心无碍"，钓鱼之人抛下鱼钩如同禅者入定，心中无牵无挂，江边独坐即是一种修行。"山水终归野钓人"以肯定的语气收束：这江山风月，终究是属于那些真正走进它、沉浸于它的人——不是拥有，而是与之同在。全诗语言清简而意蕴悠长，将调休半日偷得的闲适与山水之乐凝于二十八字之中。
```
