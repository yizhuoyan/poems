# 《通韵·夏日乌江画廊游记》

```
山劈碧浪开前路，我立船头纳爽风。
叠嶂扑来压水绿，微波荡去浴云清。
无情烈日将人煮，有胆乌江自凉生。
毕竟千年拉纤道，长听号子不屈声！
```

# 赏析
```

这首诗以夏日乌江画廊的行舟所见为起点，却逐渐从山水之美写到乌江千年的历史之重。前六句气象开阔、动感强烈：山如劈浪而开，船头迎风，群峰压水，微波浴云；烈日炙人，而乌江又从山水之间生出清凉。最后一句“不屈声”突然改变全诗的重量，使眼前的江山不再只是供人游赏的风景，而成为承载千年纤夫劳作与抗争记忆的土地。全诗因此由“游江”进入“听江”，由眼前山水听见历史深处的声音。

“山劈碧浪开前路，我立船头纳爽风。”

首联先写行舟。

“山劈碧浪开前路”是一个很有气势的开篇。通常是船在江中前行，而这里却把山写成主动的开路者。“劈”字极具力量，使山势仿佛伸入江中，将碧绿江水劈开，为船只开出一条道路。

这既写出了乌江峡谷山势与江流交错的壮观，也改变了传统山水诗中“人在景中游”的被动视角：不是船穿行于山水之间，而仿佛山河主动为行舟让出前路。

下一句转到诗中人的状态。“我立船头纳爽风”，一个“立”字很简洁，却使人物姿态挺拔起来；“纳”则不是普通的“吹”，而是主动把江风迎入怀中。经过前一句的雄奇开路，诗中的人也以一种开怀姿态进入乌江山水。

“叠嶂扑来压水绿，微波荡去浴云清。”

颔联开始集中写两岸与江面的视觉变化。

“叠嶂扑来压水绿”非常有动态感。“叠嶂”本是静景，但一个“扑来”，立刻使层层山峰仿佛迎面而至；“压水绿”又把山与江联系起来。山势越逼近，江水的绿色便越显得深沉，仿佛连群山的重量都压入了水色之中。

下一句忽然由“扑来”转为“荡去”。

“微波荡去浴云清”写江面轻波荡漾，天空与云影映入水中。这里的“浴”很有诗意：不是简单说云倒映在水里，而是写云仿佛进入清澈江水之中沐浴。如此一来，水面便不仅承接了山色，也容纳了天空。

“扑来”与“荡去”形成一收一放的动态节奏；“山压水绿”与“云浴水清”又形成上下映照。前者写群峰逼近的雄奇，后者写微波映云的清润，刚柔相济，使乌江峡谷既有压迫感，又有清凉感。

“无情烈日将人煮，有胆乌江自凉生。”

颈联是全诗很精彩的一次转折。

“无情烈日将人煮”极为口语化，也极有画面感。“煮”并非一般意义上的“晒”，而是把烈日的酷热夸张成炉火，将人在江上的炎热感受直接写出来。

但下一句马上反转：

“有胆乌江自凉生。”

“有胆”与“无情”构成鲜明对应。烈日无情，乌江却有胆。一个自然景物被赋予了人的性格，仿佛乌江面对炎炎烈日毫不退缩，反而自有一股清凉从江水、山谷与江风之中生出来。

这里的“自凉生”尤其值得注意。它不是说诗人躲进阴凉处，而是说乌江本身就能生出清凉。山峡、碧水、江风共同形成了一种天然的消暑力量。于是“无情烈日”与“有胆乌江”不仅是冷热对比，也形成了性格上的对比：烈日以强势压迫人，乌江却以自身的清凉与之抗衡。

而“有胆”二字，也悄悄为最后的“不屈声”埋下伏笔。乌江的清凉因此开始具有一种精神气质：面对强烈的外部力量，它不屈、不退，自有其力量。

“毕竟千年拉纤道，长听号子不屈声！”

尾联将全诗从眼前景色推向历史纵深。

“毕竟”二字非常关键。前面写得都是当下所见：山、水、风、云、烈日；到了这里，诗人忽然提醒读者，眼前这条乌江并不只是今天游船经过的江水，它还是一条延续千年的拉纤之道。

“千年”一下子拉长了时间尺度。“拉纤道”则把江水背后的历史具体化：过去的纤夫沿着江岸艰难前行，以人力拖拽船只，在险滩急流之间谋生。

于是前面的“船头”也有了新的意味。

今天，船行江中，可以立在船头迎风纳凉；千百年前，纤夫却可能在烈日之下沿江拉纤。今天的江风是“爽风”，江水是“凉生”；而在历史深处，这条江曾经见证的是沉重的劳作。

因此最后一句“长听号子不屈声”极有力量。

“号子”首先是纤夫劳动时的呼喊，是具体的声音；“不屈”却使它超越了普通劳动号子，成为一种精神象征。那一声声号子不仅是在协调脚步、鼓舞气力，也仿佛在山谷间留下了千百年不曾消失的生命力量。

尤其“长听”二字，使过去与现在发生联系。纤夫已经远去，拉纤的时代也已经成为历史，但乌江仍在流，峡谷仍在回响。仿佛只要站在这条古老的江道上，便仍能从山水深处听见那些劳动者留下的声音。

这样，诗的结尾实际上完成了对前文的一次重新照亮：最初的“山劈碧浪”，不只是壮景；“有胆乌江”，也不只是拟人；“自凉生”的乌江背后，还有千百年来与艰险环境相抗衡的人。自然的雄奇与人的不屈，在最后两句汇合。

全诗因此有两条并行的线索：一条是眼前的乌江山水，一条是江水背后的千年纤夫历史。前者给人清凉与壮阔，后者赋予这片山水以重量。最终，游人听到的不只是江水与风声，还有历史深处绵延至今的纤夫号子——那才是这条乌江最厚重的回声。
```
