# 《通韵·夏日乌江画廊游记》

```
山劈碧浪开前路，我立船头纳爽风。
叠嶂扑来压水绿，微波荡去浴云清。
无情烈日将人煮，有胆乌江自凉生。
本是千年拉纤道，长听号子不屈声！
```
> 写于20250814

# 赏析
```
首联"山劈碧浪开前路"以"劈"字写两岸青山如刀劈开碧波，为船开出一条路来，力度遒劲；"我立船头纳爽风"写诗人迎风而立，意气风发。颔联"叠嶂扑来压水绿"的"扑"与"压"写群山扑面而来的压迫感；"微波荡去浴云清"则以轻柔的微波与之对仗，一刚一柔，相映成趣。

颈联"无情烈日将人煮，有胆乌江自凉生"以"无情"与"有胆"对举——烈日虽毒辣，江水却自有凉意，"自凉生"三字赋予乌江以倔强的品格。尾联将全诗的境界从个人体验拉升到历史记忆——"本是千年拉纤道，长听号子不屈声"——这乌江之上，千百年来纤夫们就是在此拉纤前行，那一声声不屈的号子至今仍在峡谷间回荡。由一次夏日游船，唤起对劳动者坚韧精神的敬意，使此诗的格局骤然开阔。
```
