# 《通韵·五一黄昏钓鱼记》

```
半隐远山升晚日，一池静水落长天。
抛钩挂饵白云里，握把盯浮飞鸟边。
慢等贪鱼来送命，忽思仙手正提竿。
不然名利出何处，直钓人心万万年！
```

# 赏析
```
《通韵·五一黄昏钓鱼记》赏析

这首诗写的是黄昏垂钓，却并不止于写钓鱼。前四句先铺陈一幅宁静开阔的水乡晚景，山、日、长天、白云、飞鸟都倒映入一池静水，使现实的天空与水中的倒影彼此交融；后四句则由“等鱼”转入“思人”，最终从鱼之贪食推及人之逐名逐利，并以“直钓人心”点出全诗诗眼。作品的妙处正在于：表面写的是一竿一池，实际上写的是天地之静与人心之动。

“半隐远山升晚日，一池静水落长天。”

首联先从远景写起。“半隐远山”写山势若隐若现，给晚景留下朦胧的空间；“升晚日”中的“升”，并非实写太阳在黄昏重新升起，而是写晚日从远山之间显现、升入视野的视觉感受。下一句由天空转入水面，“落长天”则写长天的倒影沉入池中。于是“升”与“落”形成上下相对的空间构图：晚日在山后向上显现，长天却向下落入水中。山上有日，水中有天，一升一落之间，天地仿佛被压缩进这一池静水之中。

“抛钩挂饵白云里，握把盯浮飞鸟边。”

颔联是全诗最有画面感的一联。“白云里”不是说鱼钩真的抛到了云端，而是因为白云倒映在水中，鱼钩、鱼饵恰好落在云影之间，于是便产生了“钩在白云里”的诗意错觉。下一句同样如此，“飞鸟边”写的也不是飞鸟就在浮漂旁边，而是飞鸟的影子映在水中，浮漂便仿佛停在飞鸟倒影的旁边。

这样一来，诗中的垂钓空间便不再只是普通池塘，而成为一个“水中有天地”的世界：白云入水，飞鸟入水，长天入水，鱼钩和浮漂也进入其中。前三、四句实际上完成了一次视角上的转换——从“看天”转为“看水中的天”，现实景物与倒影相互叠合，形成一种清幽而略带幻境意味的晚景。

“慢等贪鱼来送命，忽思仙手正提竿。”

写景至此，诗意开始转动。“慢等”写垂钓的状态，节奏极缓；“贪鱼”却突然赋予鱼以人的性格。鱼因为贪食而吞饵，也因此“来送命”，“贪”字由鱼身上自然引出欲望的意味。

“忽思”二字是转折的关键。原本是人拿竿钓鱼，此刻诗人的思绪却忽然转向一个更高、更玄妙的视角：“仙手正提竿”。于是问题发生了倒置：人以鱼为所钓之物，那么站在更高处看，人自己是否也可能成为被“钓”的对象？这一转，使前面的“贪鱼”不再只是钓鱼过程中的趣味描写，而开始具有寓意。

“不然名利出何处，直钓人心万万年！”

尾联真正揭开前面的伏笔。鱼因贪饵而上钩，人又何尝不是如此？鱼所贪的是饵，人所逐的是名利；鱼被鱼钩牵动，人则被欲望牵动。“名利出何处”表面是在追问名利从何而来，实际上是在追问：究竟是什么力量，使人不断追逐这些东西？

于是最后一句将“钓”的对象彻底改变——不再是钓鱼，而是“钓人心”。“万万年”又把黄昏池畔这一瞬间推向漫长的人性时间：鱼会因贪饵上钩，人也会因欲望而受困，这种“钓心”的游戏并不限于一时一地，而具有恒久的人性意味。

全诗最有意思的地方，是前半首把天地写得极静，后半首却把人心写得极动。静水之中藏着长天、白云、飞鸟，而一根鱼竿又由“钓鱼”悄然钓向“人心”。至此，眼前之景与人间之理自然合流，诗眼也从“钓鱼”落到了一个更深的“钓心”。
```
