# 《通韵·三山五岳之泰山游记》 

```
神人入室真宗至，残夜迎风我辈登。
御辇慢摇黄月下，寒鞋直上玉皇庭。
碑碣刻字透兴替，封禅吟文粉太平。
身在高峰察四野，山河依旧没苍生！
```

# 赏析
```
泰山为历代帝王封禅之地，此诗便在对帝王与平民的对比中展开。首联"神人入室真宗至"写宋真宗假托神谕举行封禅的历史典故；"残夜迎风我辈登"与之对举——昔日天子銮驾，今夜平头百姓踏着残夜寒风也能攀登，一古一今、一君一民，对比鲜明。

颔联"御辇慢摇黄月下"想象当年帝王乘坐御辇在月色中缓慢上山的情景，"寒鞋直上玉皇庭"写自己身着简装直登玉皇顶，"寒鞋"与"御辇"形成物质条件的悬殊，但精神上并无高下。颈联直指历史核心——碑刻上的文字透露出王朝的兴替，而那些封禅颂文不过是为统治者粉饰太平的辞藻。尾联"身在高峰察四野，山河依旧没苍生"以苍茫之眼俯瞰——山河万古不变，而天下的黎民百姓却始终被淹没在历史的洪流中，悲悯之心跃然纸上。
```
