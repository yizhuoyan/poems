# 《通韵·三山五岳之泰山游记》 

```
天门降瑞真宗至，残夜迎风我辈登。
御辇慢摇黄月下，寒鞋直上玉皇庭。
碑碣刻字媚功绩，封禅吟文粉泰平。
身在高峰难见底，山河壮阔埋苍生！
```

# 赏析
```
这首《泰山游记》以登临泰山为线索，融历史反思与生命哲思于一体，笔力遒劲，意蕴深沉。

意象对比，张力十足。 首联“天门降瑞”与“残夜迎风”并置，真宗封禅的祥瑞盛景与诗人寒夜攀登的艰辛形成鲜明对照。颔联“御辇慢摇黄月下，寒鞋直上玉皇庭”更将这种对比推向极致——帝王仪仗的雍容华贵与平民登山的清寒孤寂，勾勒出权力与个体间的巨大鸿沟。

用典深刻，讽喻含蓄。 颈联“碑碣刻字媚功绩，封禅吟文粉太平”直指历史本质，那些镌刻在泰山石上的煌煌文字，不过是粉饰功绩的谀词。诗人以“媚”“粉”二字，轻巧撕开帝王封禅的神圣面纱，露出其政治表演的底色。

结句陡转，境界大开。 “身在高峰难见底，山河壮阔埋苍生”既是写景，更是说理。登高望远却难见谷底细微，正如宏大叙事总淹没个体悲欢。“埋”字惊心动魄，道出历史的残酷——山河依旧壮丽，而一代代平凡生命已被悄然埋葬。

全诗结构精严，古今交错间完成了一次从登临到觉醒的精神跋涉。 其可贵处在于，不以登高而豪情万丈，反因登高而看见被历史烟云遮蔽的苍生，这份清醒与悲悯，使得这首游记超越了模山范水的传统范式，成为一首凝重的历史沉思录。
```
