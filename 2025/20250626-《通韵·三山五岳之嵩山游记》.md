# 《通韵·三山五岳之嵩山游记》

```
万古浮云随落日，悠悠天地卧嵩山。
将军柏下王朝换，书册崖边海陆迁。
女帝崩殂封祀后，少林兴盛火焚前。
老夫不问荣枯事，直向峻极峰顶攀！
```

# 赏析
```
这首诗写嵩山之游，气象开阔，历史感厚重，尾联又能振起精神，是一首融怀古、览胜、抒怀于一体的登山之作。全诗紧扣嵩山特有的文化符号布局，非泛泛写山，读来见真游历、真思考。
一、首联：以宇宙时空写山之亘古
万古浮云随落日，
悠悠天地卧嵩山。

开篇不写山形，先立时空。

"万古浮云随落日"——时间的维度：浮云千载，日落无数，皆是流转变迁之象；
"悠悠天地卧嵩山"——空间的维度：天地悠悠，而嵩山安卧其间，稳如磐石。

一"随"一"卧"，两字见功力：

"随"字写云与日的流动、无常；
"卧"字写山的沉稳、亘古。
浮云落日在变，嵩山不动。这种"动"与"静"、"变"与"恒"的对照，为后面写朝代兴替、沧海桑田奠定了基调——人事纷纭，皆在此山的注视之下。

一个"卧"字尤见气魄：嵩山不是"立"、不是"耸"，而是"卧"于天地之间，从容、宽厚、亘古如斯，仿佛山有其自身的呼吸与生命。

二、颔联：以嵩山两大胜迹写时间的深度
将军柏下王朝换，
书册崖边海陆迁。

这一联可谓全诗最见构思之处，两句各扣嵩山一处名胜，且指向两种不同尺度的"变"：

将军柏——在嵩阳书院，相传为汉武帝所封，历经两千余年，见证多少王朝更替。此句是人类历史尺度的变迁。

书册崖（嵩山有"五代同堂"地质奇观，岩层层叠如书册，被誉为"天然地质博物馆"）——记录的是地质尺度的沧海桑田，亿万年的海陆变迁。

一联之内：

一句写人事（王朝换），时间以千年计；
一句写自然（海陆迁），时间以亿年计。
由人史推及地史，时间的纵深感一下子被拉开，境界骤大。而这一切"变"，都被首联那"卧"着的嵩山静静包容——山之恒，愈见人事之短、地貌之幻。

对仗上，"将军柏"对"书册崖"，皆嵩山实景；"王朝换"对"海陆迁"，皆重大变迁；工稳且贴切，绝非泛泛用典。

三、颈联：以两处宗教文化史写盛衰无常
女帝崩殂封祀后，
少林兴盛火焚前。

若说颔联写的是"漫长的变"，颈联则写"具体的兴衰"，转入嵩山特有的宗教文化史：

上句——武则天曾多次登嵩山，封禅祭祀，留下"金简"等遗迹，嵩山因此一度成为国家祭祀中心。然而"崩殂"之后，这份煊赫也随之消散。"封祀后"三字，写尽荣极而衰之感。

下句——少林寺历经隋唐鼎盛，然而1928年军阀石友三火烧少林寺，一炬之下，千年古刹几近毁尽。"兴盛"与"火焚"紧接，繁华与毁灭仅一线之隔。

两句合起来：

一写皇权兴废（女帝之荣，随人而灭）；
一写宗门盛衰（少林之兴，毁于兵燹）。
无论是至高的皇权，还是超然的佛门，在时间面前，都难逃兴衰。"后"与"前"两字尤妙——"崩殂后"指向消散，"火焚前"指向即将到来的毁灭，两字一前一后，皆是无常的时间刻度。

至此，颔联、颈联层层递进：从自然变迁，到王朝更替，到皇权兴废，再到宗门盛衰——嵩山之下，一切皆流转，一切皆无常。

四、尾联：从怀古沉思跃入登临豪情
老夫不问荣枯事，
直向峻极峰顶攀！

前六句写尽兴亡荣枯，本已情绪沉郁；至尾联，笔锋陡然一转——

"不问"二字，是全诗的转折点。

既然荣也罢、枯也罢，皇权也罢、佛门也罢，最终皆化尘烟，那便索性放下这一切！诗人不再纠缠于历史的沉重，转而以"老夫"自称，露出一种历尽沧桑之后的洒脱与豪气。

"直向峻极峰顶攀"——

"峻极"是嵩山主峰之名，也是嵩山最高处；
"直向"二字，无回顾、无迟疑，一往无前；
"攀"字有力，写出登山之实感，也写出精神之向上。
这一句妙就妙在双关：既是实写登山，也是精神超越。历史的荣枯我不再计较，我只向最高处去、向天地之极去。一"卧"（首联山之卧）一"攀"（尾联人之攀），首尾呼应又形成张力：山亘古而静，人短暂而动；山不言，人自去攀。

从沉郁到豪迈，这一转极为漂亮，全诗因此不落于"怀古伤今"的窠臼，而带出一种"知其无常仍勇往"的生命姿态。这既是登嵩山之游记，也是老年人生的自况。

五、通篇结构与艺术特色
1. 结构层层递进，境界步步开阔
联	内容	视角
首联	天地、浮云、落日、嵩山	宇宙尺度
颔联	王朝换、海陆迁	历史/地质尺度
颈联	女帝、少林	具体人事尺度
尾联	老夫、峰顶	个人生命尺度
由大到小，由远及近，由古到今，由外物到自身，最后落于"我"的一步一攀。结构十分严谨。

2. "变"与"不变"的哲学思考
全诗贯穿一个核心命题：万物皆变，唯山独立；山亦无言，人自攀之。

浮云、落日、王朝、海陆、皇权、宗门——皆变；
嵩山——不变；
但纵使山不变，人生依然要向前"攀"，这才是全诗最有力量的地方。

3. 用典皆嵩山实景，绝无泛泛
将军柏、书册崖、女帝封祀、少林火焚、峻极峰——五处典故皆嵩山独有，非可移用于他山。这体现出诗人真游、真读、真思，不是套路化的怀古。

4. 尾联的"翻转"是全诗的诗眼
如果没有尾联，全诗便只是一首较沉郁的怀古之作；有了尾联的"不问"与"直攀"，全诗气象顿开，情绪由沉入豪，读来令人振奋。这一转，是本诗最见精神处。
```
