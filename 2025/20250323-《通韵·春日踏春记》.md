#《通韵·春日踏春记》

```
粉黄白紫万千花，朵朵说春是我家。
小鸟追香将客赶，胖蜂醉蜜把枝压。
编织大地为婚服，漫剪轻云作嫁纱。
笑问东君何处娶？路边野菜待人挖。
```

# 赏析
```
此诗以极度欢快的笔调写春日踏青，想象力恣意飞扬。首句以四种颜色开篇——"粉黄白紫"如打翻的颜料盘，扑面而来的姹紫嫣红，"万千花"极言花之多。次句"朵朵说春是我家"以拟人手法写花之自信——每一朵都宣称春天是自己的家，写出了春花的烂漫与张扬。

颔联更是妙趣横生——小鸟追逐花香，反过来"将客赶"（客人反而被鸟赶着走）；蜜蜂胖嘟嘟醉醺醺地压弯了花枝，"胖蜂"一词憨态可掬。颈联以婚礼喻春——大地编成婚服、轻云剪作嫁纱，将春天拟为新嫁娘，浪漫至极。尾联"笑问东君何处娶？路旁野菜待人挖"从云端拉回地面——笑着问春神在哪里办婚礼？答：路边的野菜正等着人去挖。从华丽的婚礼想象到朴实的野菜，幽默地完成了从浪漫到现实的回返，大俗大雅，趣味横生。
```
