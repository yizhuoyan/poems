# 《通韵·五一黄昏钓鱼记》

```
半隐远山升晚日，一池静水落长天。
抛钩挂饵白云里，握把盯浮飞鸟边。
慢等贪鱼来送命，忽思仙手正提竿。
不然名利出何处，直钓人心万万年！
```

# 赏析
```
这是一首由钓鱼触发的人生哲理诗。前两联写黄昏垂钓之景——远山半隐、晚日初升，一池静水倒映满天霞光。"抛钩挂饵白云里"将钩饵抛入水中倒映的白云之中，虚实结合，诗意盎然。"握把盯浮飞鸟边"写专注之态，而飞鸟掠过的动态又打破了画面的静止，动静相宜。

后两联由钓鱼悟道。"慢等贪鱼来送命"写钓鱼人的等待，语气中带着几分悠闲与冷酷。第五句"忽思仙手正提竿"陡然翻转——诗人猛然惊觉：自己在钓着鱼的时候，是否也正被一双无形的手"钓"着？末二句"不然名利出何处，直钓人心万万年"将此感悟上升到普遍人性——名利二字，不就是钓人心的万年诱饵吗？全诗由具体到抽象、由实到虚，从一个黄昏钓鱼的场景中洞见了贯穿人类历史的欲望法则，思辨深刻而语言生动。
```
