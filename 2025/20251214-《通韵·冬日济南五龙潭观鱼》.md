# 《通韵·冬日济南五龙潭观鱼》 

```
垂柳沾金摇华年，甘泉透玉落长天
清幽黑鲤诗山水，老朽如石合此篇
```

# 赏析
```

《通韵·冬日济南五龙潭观鱼》是一首很有“泉城冬日”气息的小诗。全诗不以宏阔景象取胜，而是从垂柳、甘泉、黑鲤、顽石这些近景落笔，把济南五龙潭的清幽灵秀写得具体而有层次。尤其值得注意的是，诗的前三句都在写景，到了末句忽然将“老朽”置入其中，使人与景、生命与山水发生了微妙的对应。表面上是自谦，深处却有一种“人与天地同老、与山水相合”的洒然意味。因此，这首诗真正的落脚点并不只是“观鱼”，而是借鱼、泉、柳、石来写一种与自然相契的生命心境。

首句“垂柳沾金摇华年”，起笔便很有色彩感。“沾金”是全句最醒目的字眼。冬日的垂柳本已不复春日浓绿，却因阳光映照而仿佛枝条沾染金色，既写出了冬日暖阳的视觉质感，也使原本略显萧瑟的冬景有了温润的光泽。“摇”字又让画面动了起来：柳枝在微风中摇曳，金光随之闪动。

而“华年”二字尤其耐人寻味。它既可以理解为美好的年华，也可以理解为岁月流转中的人生盛时。柳枝一摇，摇动的不只是金色的光影，也仿佛摇动着人的“华年”。这样一来，景物中便悄然渗入了时间意识。冬日之景本就容易引发岁月之感，而“垂柳”又天然带有生命轮回的意味，因此这一句实际上已经埋下了末句“老朽”的伏笔。

第二句“甘泉透玉落长天”，转写五龙潭的泉水。

“甘泉”点明济南泉水的核心意象，而“透玉”则把泉水的清澈、洁润和温度感进一步写出来。“玉”不仅是视觉上的比喻，也使泉水带有一种晶莹、温润的质地。这里的“透”字很重要，它不是简单说泉水“如玉”，而是让人产生一种清泉澄澈见底、光线穿透其中的感觉。

“落长天”则把视野一下子拉开。前一句还是近处柳枝上的金光，这一句已经由泉水延伸到天空，空间从枝头、水面扩展至天际。于是全诗的景物开始形成一种纵向的开阔感：柳在上，泉在下，天在远处，整个画面虽然清幽，却并不局促。

“甘泉”“透玉”“长天”三个词组合在一起，也使诗的色调由金转玉，由暖转清，形成冬日济南特有的明净感。

第三句“清幽黑鲤诗山水”，是全诗最有灵气的一句，也是最明显的“诗眼”所在。

“清幽”二字承接前两句，将柳、泉、天共同营造出的环境气质凝聚起来。到了“黑鲤”，视觉焦点终于从整个景物落到了鱼身上。黑鲤本身颜色沉静，与泉水的清澈形成鲜明对照：一片明净之中，一尾黑鱼游过，黑白相映，反而更显泉水之清。

但真正精彩的是“诗山水”。

这里的“诗”可以理解为动词：黑鲤的游动，使眼前的山水本身仿佛成为一首诗。也可以理解为一种审美意义上的判断：这黑鲤已经不是普通的鱼，而是构成这幅山水诗境的一部分。鱼游泉中，泉映鱼影，人与自然共同完成了一幅动态的山水画。

更深一层看，“诗山水”还存在一种主体转换。通常是人面对山水而“诗”，这里却仿佛是黑鲤在“诗”山水。诗人的主体意识因此暂时退后，让自然本身成为审美主体。这使诗有了一点古典山水诗中“物我两忘”的意味。

末句“老朽如石合此篇”，则是全诗最值得玩味的收束。

“老朽”当然首先是诗人的自称，是一种自谦。但放在“如石”之后，这个词的意味明显扩大了。石头在山水中不言不语，经年累月承受泉水冲刷，却始终安然存在。诗人说自己“如石”，表面是说年老、迟钝、无华，实际上却是在主动寻找自己与眼前山水之间的对应关系。

尤其是“合”字，用得非常巧。

“合此篇”表面意思是：我这个“老朽”也恰好可以成为这首诗的一部分。可再深入一步，它并不是简单的“加入”，而是“契合”。前面有柳、有泉、有鱼、有山水，最后出现一个“如石”的人。至此，人不再是站在景外观看风景的旁观者，而是成为景物自身的一部分。

这样，“合此篇”甚至可以有两重理解：既是“合乎这首诗的意境”，又是“融入这片山水所成的诗篇”。前面的“清幽黑鲤诗山水”，写的是黑鲤进入山水之诗；最后的“老朽如石合此篇”，则写诗人自己也进入了这首山水之诗。人与鱼，一动一静；鱼游泉中，人如石旁；一者有生命之动，一者有岁月之静，却最终共同归于“山水”。

因此，这首诗表面上写的是冬日五龙潭观鱼，实际上写的是一种非常安静的生命感悟。首句“华年”与末句“老朽”构成了隐约的时间照应：前面写年华，后面写老朽；中间则以泉、鱼、山水承接。于是，诗中的冬日并非单纯的季节，而也带有生命之秋冬的意味。但诗人并没有因此流露出明显的伤感，因为最后不是“叹老”，而是“如石”“合此篇”。

这便使“老朽”二字反而显得旷达。

年华会老，人也会老，但柳仍摇金，泉仍透玉，黑鲤仍自在游动，而人若能如石一般安然置身其中，那么衰老便不再只是时间的剥蚀，也可以成为与山水相契的一种成熟状态。

全诗最动人的地方，正在这种“不说愁而自有岁月、不说悟而自有禅意”的含蓄。前两句写景清丽，第三句以鱼入诗，第四句以人入景，最终把“观鱼”提升为“观我”。那尾清泉中的黑鲤游过山水，也仿佛替诗人游过了自己的华年；而诗人愿化作一块石头，安静地留在这片泉水与山色之间。

可以说，这是一首以清景写岁月、以观鱼写自况的小诗。最好的地方，不在“老朽”二字的自嘲，而在“如石合此篇”的自得：人到暮年，仍能把自己放进山水，便也是山水中的一景，也是天地诗篇中的一字。
```
