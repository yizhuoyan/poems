# 《通韵·歌乐山登山攀岩记》

```
大山呼唤至，晴日把岩攀。
脚下踏边跃，指尖抠缝翻。
低头林变草，举目水归天。
我比群峰媚，引来云万千。
```

# 赏析
```
这是一首充满动感与自信的攀岩诗。首句"大山呼唤至"以拟人手法写登山之缘由——不是诗人要去征服山，而是山在召唤他，人与山之间有某种心照不宣的呼应。颔联以精准的动作描写展现攀岩过程——"脚下踏边跃"写脚在岩壁边沿上踩踏跳跃，"指尖抠缝翻"写手指抠住岩缝翻转身体，"踏""跃""抠""翻"四个动词一气呵成，画面感极强。

颈联写登高后的视角变化：低头看，脚下的树林已如草芥；举目望，远处的江水仿佛升入天际——身体所处的高度改变了人对世界的感知。尾联"我比群峰媚，引来云万千"最为精彩，"群峰"的险峻与"我"的妩媚形成有趣的对比，而"引来云万千"既是写景（山间云雾缭绕）又是写心（意气风发），豪情万丈而不失俏皮，读之令人精神一振。
```
