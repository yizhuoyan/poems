# 《通韵·歌乐山登山攀岩记》

```
大山呼唤至，晴日把岩攀。
脚下踏边跃，指尖抠缝翻。
低头林变草，举目水归天。
我比群峰媚，引来云万千。
```

# 赏析
```
《通韵·歌乐山登山攀岩记》赏析

这首诗写歌乐山登山攀岩，最突出的特点是一个“动”字。诗中没有停留在远观山色，而是从“呼唤”起笔，以“攀”“跃”“抠”“翻”等连续动作推进，把攀岩者身体与岩壁直接接触的力量感写了出来。同时，诗的视野也随着攀登不断变化：脚下由岩壁转向山林，抬头由山林望向江水与长天，最后再由眼前群峰转回自身。全诗既有运动感，也有视野不断打开的空间感，末尾更以“我比群峰媚”完成一次极具个性的反转。

“大山呼唤至，晴日把岩攀。”

首句没有写“见山”，而写“大山呼唤”。

这样一来，人与山的关系便不是简单的游览关系，而仿佛是山主动发出召唤，人受到召唤而来。“呼唤”二字赋予大山以生命，也暗中确定了全诗的情绪基调：这不是被动登山，而是一场人与山之间的主动回应。

“晴日把岩攀”则迅速进入行动。“晴日”既交代天气，也给整个攀登过程增加明朗、畅快的氛围；“把岩攀”虽然简劲，却有很强的动作感，仿佛已经顾不上从容观景，而是直接进入攀岩状态。

前一句是山在召唤，后一句是人以行动回应，开篇便建立起人与自然之间的呼应。

“脚下踏边跃，指尖抠缝翻。”

颔联是全诗最具身体感的一联。

“踏边跃”写脚下的动作。攀岩不同于普通登山，岩壁上的每一个凸起、边缘，都可能成为借力的位置。“踏”“跃”两个动词连续出现，写出身体在岩壁间不断寻找支点、腾挪移动的过程。

“指尖抠缝翻”则把动作进一步推进到手指。一个“抠”字尤其有力量，它不是轻轻扶住，而是指尖抠住岩缝，借助极小的着力点完成身体的翻越。“翻”字则使画面骤然加速：前一刻还在寻找岩缝，下一刻身体已经越过岩壁。

“脚下”与“指尖”构成上下对应，“踏”与“抠”分别写脚力与手力，“跃”与“翻”则写身体的动态变化。诗人在这里几乎没有形容词，却仅靠动作本身把攀岩的紧张、力量与畅快写了出来。

“低头林变草，举目水归天。”

到了颈联，诗的视野突然打开。

前两联主要写“身”，这一联开始写“眼”。

“低头林变草”，并不是林木真的发生了变化，而是随着高度不断增加，原本可以看见的树林在俯视中逐渐缩小、压缩，最终仿佛只剩下一片草色。一个“变”字，把登高过程中尺度变化带来的视觉感受写得十分简洁。

“举目水归天”则进一步扩大空间。随着视线抬高，远处的水面与天空仿佛连成一体，水色向天际延伸。这里的“归”很有意味：水并非只是存在于远方，而仿佛一路流向天边，最终归入天空。

于是这一联形成了很清楚的空间推进：

低头，是脚下越来越渺小的山林；
举目，是远方越来越开阔的天地。

攀岩不仅使身体升高，也使视野不断扩大。前面的“脚下”“指尖”是近距离的身体经验，到这里已经转换成“林”“水”“天”的宏阔景象。

“我比群峰媚，引来云万千。”

尾联是全诗最有性格的一笔。

通常写登山，往往会说群峰雄奇、山色秀美，人在群山面前显得渺小。但这里却反过来说：“我比群峰媚。”

这个“比”字首先带有明显的调侃与自信。经过前面的攀岩，诗中的“我”已经不是站在山脚仰望群峰的人，而是凭自己的力量攀上山岩、进入群峰之中的人。于是人的精神状态也随着高度发生变化：不再只是赞美山，而开始与山争艳。

而“媚”字又与“群峰”的“雄”形成有趣区别。群峰可以雄奇险峻，而攀岩者经过一番攀登之后，则呈现出一种带着生命力的“媚”——不是柔弱的美，而是运动、勇气和自信所产生的美。

最后一句“引来云万千”，更把这种自信推向浪漫的想象。

如果“我比群峰媚”，那么连天上的云似乎都被吸引而来。这里当然不是在写真实的气象因果，而是把登山者的精神状态夸张化、诗意化：群峰已经不足以映衬此刻的豪情，连万千云朵都仿佛要来作陪。

于是全诗形成一个很有趣的反向关系：开篇是“大山呼唤”人而来，结尾却变成“我”吸引云而来。最初是山在召唤人，最后则仿佛天地都被人的生命光彩所吸引。人与山之间的关系，也由“被山召唤”发展成“与山争辉”。

全诗从山的呼唤开始，以人的回应结束；从脚下岩壁的近身攀登，写到群峰、流水与长天的宏阔视野，最后又以一句带着自得与豪情的“我比群峰媚”收住。它写的是攀岩，更写出了攀登者在不断向上的身体运动中获得的精神舒展：山越高，人的气势反而越高。
```
