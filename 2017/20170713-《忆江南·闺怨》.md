# 《忆江南·闺怨》
>> 写于20170713
```
窗又夜，浴后画轻眉。
明月不知心上事，为何凌空照人悲。
谁是谁的谁？
```
# 赏析
``` 
《忆江南·闺怨》篇幅短小，却以极简的语言写出由独处、梳妆、见月而至情感自疑的心理过程。全词取传统闺怨题材，以“窗”“夜”“轻眉”“明月”等古典意象营造幽静而清冷的氛围，结尾却以一句极具现代口语色彩的“谁是谁的谁？”陡然转折，使传统的闺中相思进一步深入到对情感关系、身份与归属的追问。古典意境与现代心理语言相互碰撞，是本词最鲜明的艺术特色。

首句： 窗又夜，浴后画轻眉。

“窗又夜”极其简练。“夜”只是时间，而一个“又”字却使这个夜晚具有了重复性和漫长感。它暗示这样的夜已经不止一次，眼前之夜不过是又一次独处，又一次等待，又一次难以排遣的心事。

“窗”也不是一个普通的地点意象。窗是内与外、人与世界之间的界面。窗外是深夜，窗内是独坐的女子，仅仅三个字，便将人物置于一种幽闭而孤寂的情境之中。

“浴后画轻眉”则转入细腻的女性生活。浴后本是放松、闲适的时刻，却又特意画眉。“画眉”天然带有为人而饰、悦己亦悦人的意味，因此这一个动作背后隐含着一个没有说出的潜台词：她仍在等待某个人。

而“轻眉”中的“轻”字也很有意味。动作轻柔，心事却沉重；外在的从容与内心的惆怅形成反差，使人物的情绪没有直接宣泄，却更加含蓄。

三、四句： 明月不知心上事，为何凌空照人悲。

这里由室内转向窗外，由人转向月。

“明月”是中国古典诗词中最常见的相思意象之一，但本词没有顺着传统写“对月思人”，而是反过来向明月发问：“你既然不知道我的心事，为何还要高悬天空，照见我的悲伤？”

“明月不知”运用了拟人的写法。月本无知，词人却责问它“不知”，实际上并非真的期待月亮回答，而是借月抒写自己的孤独。她无法向所思之人诉说，于是只能对着月亮发问。

“凌空”二字也很重要。月在高空，人处地面，一高一低之间形成了遥远的空间距离。月光可以照见人，却无法真正理解人的心事，于是“明”反而成为一种反衬：

月越明，人的悲意越清晰；夜越静，心事越无处躲藏。

“为何”则使情绪从单纯的伤感进一步转为怨问。表面上是在问月，实际上是在问自己的处境：为什么偏偏又是这样的夜？为什么仍然要为这个人悲伤？为什么明明无人知晓自己的心事，却偏偏被月光照得无所遁形？

而“照人悲”又有一层含蓄：月亮并没有制造悲伤，它只是把原本藏在心里的悲伤照了出来。

全词最突出的转折，在最后一句： 谁是谁的谁？

这一句几乎是整首词的“词眼”。

如果按照传统闺怨的写法，通常会落到“思君”“怨君”“盼君”之类的明确情感关系上；这里却没有点明“君”是谁，反而连续使用三个“谁”，将原本明确的情感关系彻底悬置。

“谁是谁的谁”，首先是在问：我是谁？你是谁？我与你究竟是什么关系？

进一步说，它甚至是在追问：我为什么要为你悲伤？你是否真正属于我？我又是否真正属于你？

因此，结尾已经不再只是传统意义上的“思而不得”，而进入了更深一层的情感自省。人物从“想念一个人”，走到了“怀疑这段关系本身”。

三个“谁”的重复尤其有意味。第一个“谁”似乎指向“我”，第二个“谁”指向“你”，第三个“谁”却把前两个“谁”之间的关系本身也变成了疑问。于是，词中最初那个似乎确定的“思念对象”，到了结尾反而变得模糊不清。

这也解释了为什么结尾采用现代口语式的表达反而有效。

前面的“窗、夜、眉、明月、凌空”都是典型的古典意象，营造的是传统闺怨词的审美氛围；最后突然出现“谁是谁的谁”，语言一下子从古典转入现代，形成明显的陌生感。这种语言上的“破”并没有破坏全词的意境，反而将传统闺怨中含蓄的心理活动直接推到了现代人的情感意识之中。

全词的情绪也因此形成了清晰的递进：

“又”是重复的孤独；
“画眉”是无言的等待；
“明月”是无法倾诉的对象；
“为何”是压抑不住的怨问；
“谁是谁的谁”则是对感情本身的怀疑。

所以，这首词真正写的并不只是“闺中之怨”，而是一个人在深夜独处时，从等待一个人，到怀疑一段关系，再到反问自身情感归属的心理变化。

全词最妙之处，正在于最后没有给出答案。

因为“谁是谁的谁？”本身就是答案缺席后的状态：当一段感情已经无法确认彼此的身份与归属时，连“我为什么悲伤”都成了一个需要重新追问的问题。

月照的是人，真正被照见的却是心；而心中最后留下的，不再只是相思，而是对“我与你究竟是谁”的追问。
```
