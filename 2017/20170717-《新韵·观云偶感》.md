# 《新韵·观云偶感》
```
青山上必有云停，人世间天命怎争？
无可奈何吾最恨，江湖落魄遇一生。
```

# 赏析
```
起句"青山上必有云停"以自然现象起兴——青山的峰顶必有流云停驻，这是一种自然而然、不可违逆的规律。由此引出下句"人世间天命怎争"——人世间的命运就如同山上之云一样，岂是人力能够争夺改变的？由自然之理过渡到人生之叹，借物起兴的手法运用纯熟。

后两句直抒胸臆。"无可奈何吾最恨"一句最为痛切——诗人最痛恨的不是逆境本身，而是面对逆境时的"无可奈何"即那种无力反抗、无从改变的憋闷。"江湖落魄遇一生"中"遇一生"三字极为独特，将人生看作是一次被动的遭遇——不是我在活，而是我遇见了这一生。全诗由观云触发对命运的思考，从青山的自然法则到人世的无奈落魄，层层深入，情感愤懑而语言克制，是一首颇具人生感慨之作。
```
