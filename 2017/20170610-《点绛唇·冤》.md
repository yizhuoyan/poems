# 《点绛唇·冤》
```
不觉经年，枕边冤落几多泪。
西风无谓，狂扫人憔悴。
长空少情，冷看千山媚。
入夜睡。心疼难退，梦里哪一位？
```
>> 写于20170610

# 赏析
```

这首《点绛唇·冤》写的是一种经年累积、夜深难解的“冤”。全词由“枕边泪”起笔，由近及远写西风、长空、千山，又在下片重新收回到“入夜睡”的内心世界，最终以“梦里哪一位？”作结。景物越写越开阔，人的心事却越收越深，形成一种天地广大而人心孤寂的意境。

“不觉经年，枕边冤落几多泪。”开篇“不觉经年”写时间的悄然流逝。“经年”说明这份心事已经绵延许久，而“不觉”又使这种漫长带上一层恍惚：岁月已经走远，心中的旧事却似乎仍未过去。“枕边”是极私密的空间，白日里能够遮掩的情绪，到了夜深人静之时便再也无从躲藏。“冤”字尤其重要，它不只是“怨”，更含有受伤、委屈、无从申诉的意味。因此“冤落几多泪”，写的不是一时伤感，而是长期积压、难以排遣的委屈。一个“几多”，又把泪水写成了无法计数的积累。

“西风无谓，狂扫人憔悴。”西风本是自然之物，却被赋予了人的冷漠。“无谓”写其不问、不顾，任凭人的悲苦存在而无动于衷；“狂扫”则使西风从普通景物变成了一种强烈的外在力量，仿佛岁月和命运不断从人的身上扫过，使人更加憔悴。这里的西风已经不仅仅是秋日之风，也隐约具有外部世界冷眼旁观的意味。

“长空少情，冷看千山媚。”视野由西风进一步推向长空、千山，天地骤然开阔。然而空间越大，词中的情感反而越冷。“少情”与前面的“无谓”相照应，天地仿佛始终保持着一种冷漠的距离。“千山媚”本来是极美的景象，但偏偏置于“冷看”之后，于是形成强烈反衬：千山越美，人的内心越显得孤寂；外界越有美景，越无法抚平内心的疼痛。一个“媚”字也因此不只是写山色之美，更成为照见人心的反光。

下片“入夜睡。心疼难退，梦里哪一位？”突然由天地收回到自身。“入夜睡”写身体终于进入睡眠，而“心疼难退”却表明真正的心事并没有随睡眠消失。“退”字将“疼”写得仿佛有形有势，本应渐渐退去，却始终不肯离开，于是“难退”便成为全词情感积累后的集中爆发。

最后的“梦里哪一位？”是全词最含蓄也最有余味的一问。表面上是在问梦中出现的是哪一个人，实际上所问的并不一定只是某个人，也可以是某段往事、某种关系，甚至是记忆中的自己。它追问的其实是：这经年的“冤”究竟因谁而起？这迟迟不退的心疼究竟系于谁？词没有给出答案，也不需要给出答案。正因为“哪一位”始终无法确定，前面的泪、憔悴与心疼才获得了更深的余韵。

全词以“不觉经年”写岁月已远，以“心疼难退”写旧事未消，最终落在“梦里哪一位”的无解之问上。其深处所写的，并非单纯的悲，而是经年不散的委屈，以及无法追索、无法排解的心疼。整首词景大而情深，语淡而意浓，最后一问尤见余味。
```
