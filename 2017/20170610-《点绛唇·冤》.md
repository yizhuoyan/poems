# 《点绛唇·冤》
```
过往十年，枕边冤落几多泪。
西风无谓，狂扫人憔悴。
长空少情，冷看千山媚。
入夜睡。心疼难退，梦里哪一位？
```
>> 写于20170610

# 赏析
```
词题单一个"冤"字，奠定了全篇的基调——不是哀怨，不是悲伤，而是被辜负、被错待的冤屈之感。"过往十年，枕边冤落几多泪"以反问出之，十年的委屈与泪水凝于"几多"二字，枕边落泪的场景极具画面感。

"西风无谓，狂扫人憔悴"以无情西风喻世态炎凉，风无所谓地狂吹，人憔悴地凋零。"长空少情，冷看千山媚"更进一层——天空寡情，冷眼旁观千山献媚，大自然的冷酷与人心的冷遇相映照。末句"梦里哪一位"以疑问收束全篇，将冤屈推向更深的茫然——心疼得无法退去，可是梦里的那个人，又是哪一个？是旧人还是新人？此一问，道尽了情感错付后的迷惘与自嘲。全词借景抒情、由外及内，语言锋利、情感饱满。
```
