# 《新韵·清晨步行偶感》
```
晨步入城东，朝霞映碧空。
云中多少事，尽付待长风。
```
>> 写于20170709

# 赏析
```
"晨步入城东"叙事简洁清爽，点明时间与动作——清晨出门，向东而行。次句"朝霞映碧空"以朝霞与碧空的鲜明色彩描绘清晨气象，画面开阔明朗，令人心旷神怡。

后两句由景入思。"云中多少事"——看着天边的云霞，心中涌起无数思绪。云是缥缈的、变幻的，正如那些纷繁复杂的人间事。"尽付待长风"以洒脱之笔收束——将所有的烦忧与挂念，全部托付给浩荡长风。"尽付"二字有一种斩断的决绝，"待长风"又带着一份从容的等待——让风去处理吧，我不再过问。全诗前两句写景、后两句写心，由晨步之平常小事升华为豁达超脱的人生境界，简明自然而意境开阔。
```
