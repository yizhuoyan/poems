# 《如梦令·四年》
```
四年共经风雨，一路不曾分离。
斜阳落西时，莫问是否能娶。
期许，期许，别要太多彩礼。
```
>> 写于20170605

# 赏析
```
这是一首在词牌《如梦令》的框架下以幽默诙谐笔调写就的爱情词。首句"四年共经风雨，一路不曾分离"正笔写情——四年的相守与共，感情基础扎实深厚，语气坦然而真诚。

第三句"斜阳落西时，莫问是否能娶"开始转入调侃——夕阳西下之际，不要追问"能不能娶我"，既是拖延战术，也是撒娇式的回避。叠句"期许，期许"遵循词牌格律，以期待的口吻制造节奏。末句"别要太多彩礼"是全词的"包袱"，将浪漫的爱情话题陡然拉回柴米油盐的现实，大俗之中有大趣。全词在传统词牌中注入现代生活气息，将求婚这件大事以轻松幽默的方式表达出来，既见词人之俏皮，也见两人关系中那种可以"说笑"的亲密。用典雅的词牌写日常的调侃，雅俗相映成趣。
```
