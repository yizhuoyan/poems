# 《新韵·望嘉陵江》
```
命里真无莫跪求，且酬他志也风流。
伤悲苦痛一时意，绿水青山万古秋！
```

# 赏析
```
起句"命里真无莫跪求"斩钉截铁——命中注定不属于你的东西，不要跪地乞求。"跪求"二字极具画面感，与"莫"字连用，传达出一种刚毅清高的骨气。次句"且酬他志也风流"一振——既然求不得，不如去实现自己的志向，"风流"二字赋予这种选择以潇洒和光彩。

后两句的对比将全诗推向高潮。"伤悲苦痛一时意"——所有的悲伤与痛苦不过是一时之间的情绪波动，终会过去；"绿水青山万古秋"以永恒的绿水青山作结——个人的悲欢在大自然的亘古不变面前是多么渺小短暂。一个"万古秋"将时空无限拉长，将眼前的烦恼彻底稀释。全诗四句，由否定到肯定、由暂时到永恒、由人间到自然，层层递进，格局阔大，读来令人心胸为之一宽。这既是对嘉陵江的观感，也是人生智慧的凝聚。
```
