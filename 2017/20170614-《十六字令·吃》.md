# 《十六字令·吃》
```
吃，别怪如今肉难失。
白开水，也长二分脂。
```

# 赏析
```
这是一首令人忍俊不禁的谐趣词。首字"吃"以一字领起全篇，在《十六字令》的格律中虽属常规，但此处的"吃"字短促有力、开门见山，直指全词的主题要害。次句"别怪如今肉难失"以调侃的口吻自我辩解：不要怪我减不了肥。

末句"白开水，也长二分脂"以夸张手法制造笑点——连喝白开水都能长二两肉，用极度荒诞的表述来抒发减肥失败的无奈。全词化用古典词牌写当代日常，将"喝凉水都长肉"的现代俗语变成诗意表达。以文雅之体写俚俗之事，本身就构成了强烈的喜剧张力。小小一首十六字令，既有古典词牌的韵律之美，又有现代生活的烟火气息，读来让人会心一笑。
```
