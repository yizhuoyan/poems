# 《新韵·庭前听雨》
~~~
秋水多含泪，
庭前过客听。
蒙蒙天际外，
细雨细腰轻。
~~~

# 赏析
``` 
这首《庭前听雨》以秋雨为媒，在寥寥二十字中营造出凄清空灵的意境。首句"秋水多含泪"以拟人手法赋予秋水以人的情感，泪眼盈盈间，既写秋雨连绵似泪，又暗含离人别绪。次句"庭前过客听"巧妙点题，"过客"二字既指诗人自身漂泊的身份，又暗含人生如逆旅的苍凉——"听"字将听觉意象定格，雨声便成了天地间唯一的对话者。后两句堪称神笔。"蒙蒙天际外"以远景铺开一片苍茫，营造出无垠的空间感；而"细雨细腰轻"则陡然收至近景微物，以"细腰"拟雨丝，将抽象具象化——"蒙蒙"与"细腰"形成时空张力，"轻"字更赋予雨丝以婀娜柔美的体态。全诗以泪起、以轻结，从沉重走向轻盈，从具象的情感到抽象的美感，完成了情感的净化与升华。过客听雨，听到的不是愁，而是天地间最细微的诗意震颤。
```
