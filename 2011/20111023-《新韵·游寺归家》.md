# 《新韵·游寺归家》
~~~
归家听雨爱，
游寺对云亲。
忆此心如涩，
一窗夜自深。
~~~

# 赏析
``` 
《新韵·游寺归家》以极简笔触勾勒出两种时空下的心境对照。前两句"归家听雨爱，游寺对云亲"，动词"爱"与"亲"看似随意，却精准点出诗人在家与访寺时各得其所的适意——听雨之爱在于静谧，对云之亲在于超脱。然而第三句陡然转笔，"忆此心如涩"将前文的平和全盘打破：当两般美好同时涌上心头，反生出一种难以名状的苦涩。此处的"涩"字极妙，非痛非苦，是味觉向情绪的微妙转化，仿佛未熟之果在舌尖留下的收敛感，暗示诗人对两种生活方式的眷恋与无法兼得的怅惘。尾句"一窗夜自深"以景结情，窗格的框限定视角，夜的深则暗喻心绪的沉入。全诗二十字，层层转折：由乐而思，由思而涩，由涩而深，最终凝成一窗幽寂的夜。诗人不着一字议论，只通过意象的自然流转，便将禅意与凡情间的微妙张力尽数托出，余韵悠长。
```
