# 《新韵·彩云湖登高》
~~~
万木催山势，
双崖落径深。
目归天地尽，
梦里亦无人。
~~~
>> 写于20110325

# 赏析
``` 
《新韵·彩云湖登高》以极简笔墨勾勒出宏阔孤绝的意境。首句"万木催山势"，一个"催"字力透纸背——林木葱茏，仿佛在推涌山势向上生长，化静为动，赋予自然以蓬勃的生命力。次句"双崖落径深"，视角由仰视转为俯探，小径在双崖间垂直坠落，"深"字既写空间之幽邃，也暗示行者内心的孤寂与茫然。

第三句"目归天地尽"，目光追逐天际线直至尽头，视野推向无限，却以"归"字收束，暗示天地之大竟无处可寄——这是一种茫然四顾后的精神回缩。末句"梦里亦无人"如惊雷骤落，将现实的孤独推入梦境深处：清醒时无人相伴，连梦中也无故人可寻。"亦"字尤为沉痛，意味着孤独已渗透到意识的每一层褶皱。

全诗由外景而内境，由白日而梦境，层层递进。前两句以"万木""双崖"铺陈山水之壮，后两句以"无人"劈入心灵之寂，形成了强烈的张力。二十字间，登高者形单影只的苍凉、天地悠悠的浩叹、心神无可依凭的荒芜，尽在其中。这种"以景结情，以空写实"的手法，深得中国古典山水诗的精髓，堪称现代新韵诗中的佳作。
```
