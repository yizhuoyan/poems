# 《新韵·负一人》
~~~
酒醉枝头月，
梦幽枕上痕。
平生无憾事，
只是负一人。
~~~
>> 写于20111002

# 赏析
``` 
《新韵·负一人》以极简之笔写极深之情。首句"酒醉枝头月"将醉意与月影交织，营造出朦胧孤寂的意境，仿佛醉眼望月，月亦悬于枝头摇曳。次句"梦幽枕上痕"由室外转入室内——"痕"字精妙，既是枕上泪痕，也是旧梦残留的印记，虚实相生，引人遐想。后两句"平生无憾事，只是负一人"是全诗点睛之笔。前句豁达洒脱，似可了无牵挂地告别平生；后句一个"只是"陡然转折，举重若轻，将千钧之重的亏欠化为轻描淡写的一叹。这种"以轻写重"的手法，比直抒胸臆更显沉痛——平生所有的坦荡与无悔，在"负一人"面前瞬间崩塌。全诗语言洗练，对仗工稳，情感层层递进，于收束处爆发出惊人的张力，令人掩卷怅然。
```
