# 《新韵·游动步公园有感》
~~~
清风细柳丝，
溪水小虫吱。
石径铺秋叶，
白云卧远思。
~~~
>> 写于20110812

# 赏析
``` 
《新韵·游动步公园有感》以白描手法勾勒出一幅清幽淡远的秋日游园图。前两句"清风细柳丝，溪水小虫吱"，从视觉与听觉两个维度展开——风拂柳丝是柔美的动态，溪水伴着虫鸣是空灵的声响，一动一静间尽显自然生机。后两句"石径铺秋叶，白云卧远思"，笔锋由实转虚，"铺"字写出秋叶满径的萧疏之美，"卧"字赋予白云人格化的闲适与悠然，更以"远思"二字点题，将眼前景与心中情悄然勾连，使物境升华为意境。全诗严守《中华新韵》，平仄相谐，对仗工稳（清风对溪水，细柳对小虫），炼字精准又不失自然。二十字之间，声色兼具、远近交错、动静相生，既有唐人绝句的含蓄凝练，又透出几分现代人的闲适与哲思，读来如饮清茶，余韵悠长。
```
