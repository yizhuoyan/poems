# 《新韵·与韩波兄相逢于广州》

```
偶然相聚十年后，把酒言欢又一回。
八九人生难惬意，可于兄语两三杯。
五陵年少非吾命，七尺之躯志可追。
明月匆匆寒夜去，残星几点伴君归。
```
>> 写于20180825

# 赏析
```
这首赠友之作情感真挚、结构完整。首联交代聚会的缘起——"偶然"二字道出人生际遇的不可预期，十年后重逢，把酒言欢，一个"又"字包含了岁月沧桑与重逢的欣慰。

颔联感叹人生多有不如意，但对兄倾诉、共饮几杯便是慰藉。"八九"极言人生愁苦之多，与"两三"形成数字上的对比。颈联自勉——世袭的富贵荣华不是自己的命数（五陵年少），但七尺男儿自有可追之志，格调由感慨转向励志。尾联写告别——明月匆匆西沉，寒夜将尽，几点残星伴君归去。由相聚的热烈到离别的清冷，以景结情，留下几分不舍与牵挂。全诗在"聚"与"别"、感慨与自励之间找到了平衡，语言明朗，情意深长。
```
