# 《新韵·冬游五彩滨江公园》
```
人眠草上江吞日，日照江心草逗人。
闭眼风香听鸟问，此冬偷换几分春？
```
>> 写于20181105

# 赏析
```
这首小诗充满了冬日暖阳下的闲适与机趣。首句以回环往复的修辞手法写景——"人眠草上江吞日，日照江心草逗人"，人、草、江、日四个意象在两句中交错出现，形成一种近乎回文的精巧结构。前一幅画面是江吞落日，后一幅是日照江心，所有意象在回环中流转，赋予画面动态感。

后两句由视觉转入听觉与嗅觉。"闭眼风香听鸟问"——闭目感受风中花香，侧耳听鸟儿啁啾发问。末句"此冬偷换几分春"以拟人手法写冬去春来的悄然变化，"偷换"二字俏皮灵动，仿佛是冬天悄悄藏起了一部分、换入了春天的气息。全诗前两句以精巧的文字游戏写景，后两句以轻松的口吻抒情，将冬日游园的惬意与对春日将至的喜悦表达得趣味盎然，读来令人莞尔。
```
