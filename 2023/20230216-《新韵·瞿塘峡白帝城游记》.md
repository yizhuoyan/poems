# 《新韵·瞿塘峡白帝城游记》

>> 初游瞿塘峡，千年乌木，有种落缝，风吹雨淋，日久成芽，奇之，做诗为念。写于20230216
```
瞿塘白帝久相近，刘备难闻李杜诗。
绝壁纤夫拖索处，夔门铁炮用兵时。
书中好汉爱争霸，台下猕猴喜抢食。
万载长江多旧事，千年乌木一新枝。
```

# 赏析
```
《新韵·瞿塘峡白帝城游记》表面写瞿塘峡、白帝城的游览见闻，真正的构思却在于“时空错位”。全诗前三联不断把不同时代、不同空间中的人物与场景并置：瞿塘峡与白帝城虽然地理相近，刘备却不可能听到后世李杜之诗；绝壁上曾有纤夫拖索，夔门又曾经战火用兵，同样是不同历史时段的场景叠印；书中的英雄还在争天下，现实台下的猕猴却只顾抢食。到了尾联，诗人再把视野推向万载长江与千年乌木，在无数旧事之后，突然写出“一新枝”，使全诗最终落到时间流逝与生命新生的对照上。

“瞿塘白帝久相近，刘备难闻李杜诗。”首联先写地理上的“近”，继而写时间上的“远”。瞿塘峡与白帝城相距不远，自古便“相近”；然而刘备所处的是三国时代，李白、杜甫却是数百年后的诗人，因此刘备即便身在白帝城，也终究“难闻李杜诗”。“闻”既有听闻之意，也带有知闻、领略之意。“久相近”与“难闻”一近一远，使空间与时间发生错位，也由此开启全诗的构思方式：眼前同一片山水，实际上叠着多个无法同时存在的历史时代。

“绝壁纤夫拖索处，夔门铁炮用兵时。”颔联继续这种时空错位，而且不再写历史人物，而是让不同历史场景共处于同一峡江空间。“绝壁纤夫拖索处”，眼前看到的是绝壁，却联想到昔日纤夫沿江拖索的劳作；“夔门铁炮用兵时”则又转入战争年代，夔门成为兵争之地。“处”写空间，“时”点时间，两句看似都在写同一片山峡，实际上对应的是不同历史阶段：一处是纤夫劳作的江运时代，一时是铁炮轰鸣的战争年代。山水本身没有移动，时代却不断更迭，于是同一处峡谷被历史的不同切片层层覆盖。

“书中好汉爱争霸，台下猕猴喜抢食。”这一联把这种错位推进得更加鲜明，也更加诙谐。“书中”与“台下”首先是空间上的错位：英雄存在于书中，猕猴却活跃在现实的观演现场；更重要的是时间与世界的错位——书中的好汉仍在古代或文学想象中的乱世里争夺天下，眼前的猕猴却只关心手中的食物。于是“争霸”对“抢食”，宏大的英雄战争与琐碎的现实欲望并置在一起，仿佛古代传奇与今日游览在同一刻相遇。一个“喜”字还特意把猕猴写得极其专注，而这种现实中的“抢食”恰恰消解了“好汉争霸”的庄严感，形成全诗最突出的幽默反差。

“万载长江多旧事，千年乌木一新枝。”尾联由前面的层层错位转入对时间本身的凝视。“万载长江”承载了无数过去的事情：人物、劳作、战争、传说，都随着江水而成为“旧事”。但诗人并没有停留在怀古之中，视线忽然落到一株极具体的乌木上。千年乌木本身就是漫长时间的凝结，而经过风吹雨淋、种子落缝、生根发芽，最终又长出“一新枝”。“千年”与“一新”形成强烈反差，前者指向岁月的漫长与历史的陈旧，后者却指向正在发生的生命更新。

因此，全诗实际上形成了一条由“错位”走向“更新”的时间线：首联是刘备与李杜的时代错位，颔联是纤夫与战争的历史场景错位，颈联则是书中英雄与台下猕猴的文学世界、现实世界错位；前三联不断把不同时间、不同空间的人事压缩到同一幅瞿塘峡画卷中。到了尾联，所有这些“旧事”最终汇入长江，而诗人的目光却从浩瀚历史中抓住了“千年乌木一新枝”这一细小而鲜活的生命现象。

全诗最有意味的地方，也正在“旧”与“新”的最后相逢。诗人初游瞿塘峡，看到的不只是古迹与传说，而是一个被无数时代反复书写的空间；然而真正让他惊奇、并最终写入诗中的，却是一根从千年乌木上重新生出的新枝。历史不断成为过去，山水始终还在，而生命又在古老事物上重新萌发。于是这首游记诗最终超出了“怀古”，在层层时空错位之后，落脚于一个很小、却极有生命力的“新”字。
```
