# 《新韵·夏日江边夜游有感》

```
一水东流终入海，世间百载尽成尘。
万家灯火连天地，几点孤星透古今。
宇宙茫茫何问道？众生渺渺怎安身？
但听风里无悲喜，拂动江边夜钓人。
```

# 赏析
```
此诗气象宏阔，思致深沉。首联以"一水东流"起兴，引出人生不过百年终归尘土的主题，水入海与人生尘形成对照——自然永恒而个体短暂。颔联"万家灯火连天地，几点孤星透古今"以万家灯火写人间繁华、无边无际，以几点孤星写宇宙时空的深邃苍茫，上下对举，意蕴丰厚。

颈联连发两问——"宇宙茫茫何问道？众生渺渺怎安身？"这是面对浩瀚宇宙与渺小人生时最根本的追问，语气中有迷茫亦有求索。尾联没有正面作答，而是以"但听风里无悲喜，拂动江边夜钓人"收束——风声无悲无喜，只是静静地吹拂着江边的夜钓人。这平静的画面即是答案：天地不仁，万物自化，与其追问不如安住于当下。全诗将个人夜游的感悟升华为对宇宙人生的终极叩问，在沉静的夜色中归于淡然。
```
