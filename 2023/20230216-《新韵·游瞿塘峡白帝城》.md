# 《新韵·游瞿塘峡白帝城》

```
瞿塘白帝久相近，刘备难闻李杜诗。
绝壁纤夫拖索处，夔门铁炮用兵时。
书中好汉爱争霸，台下猕猴喜抢食。
万载长江多旧事，千年乌木一新枝。
```
>> 初游瞿塘峡，千年乌木，有种落缝，风吹雨淋，日久成芽，奇之，做诗为念。写于20230216

# 赏析
```
此诗游瞿塘峡、登白帝城，将历史与眼前景融为一炉。首联开篇便跨越千年——"刘备难闻李杜诗"，白帝城同时承载了三国英雄（刘备托孤）与唐代诗人（李白"朝辞白帝"、杜甫夔州诗）的记忆，两个不同时代的标志性人物在此相遇，时空交错感强烈。

中二联从历史纵深转向具体场景：绝壁之上纤夫拉索的痕迹仍在，夔门关前铁炮犹记当年用兵；而现实中的猕猴却只知争抢食物，与书中争霸的好汉形成有趣的对照——这是对英雄叙事的一种解构。尾联"万载长江多旧事，千年乌木一新枝"是全诗的点睛之笔——千古长江见证了多少风云往事，而一根千年乌木的缝隙中竟生出新芽。"一新枝"是生命对时间的胜利，在沧桑感中注入了希望与生机，使整首诗不落消沉。
```
