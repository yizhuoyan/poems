#《新韵·云阳龙缸观雪》

>> 春节与妻驾车至云阳龙缸景区，正逢下雪。写于20230207

```
天公挥大笔，漫写世间白。
一划千江止，轻勾万树开。
蘸云平地厚，抹雾远山皑。
钤印乾坤静，听风岁月来。
```

# 赏析
```
《新韵·云阳龙缸观雪》赏析

这首诗写春节与妻同游云阳龙缸，恰逢降雪，却没有把雪简单写成自然景物，而是把整个雪中山川想象成一幅由“天公”挥笔完成的巨幅水墨画。全诗的构思核心是一个“画”字：首句提出“挥大笔”，接下来便依次出现“划”“勾”“蘸”“抹”“钤印”等一整套书画动作，使风雪、江河、树林、平地、远山、天地都成为画面中的对象。到最后“钤印乾坤静，听风岁月来”，画面从视觉彻底转入听觉与时间感，前面所有的绘画动作也在“钤印”处完成封笔。作品真正写出的，是一场大雪如何把现实山水暂时变成了一幅静穆、辽阔而近乎超然的天地长卷。

一、“天公挥大笔，漫写世间白”：雪落成画，先定全篇格局

首联一开始就没有从“雪”本身落笔，而是从“天公”落笔。

“天公挥大笔”，把天空拟作一个巨大的画家；“大笔”尤其重要，它一下把视野从通常的“看雪”提升到“看天地作画”。

紧接着“漫写世间白”，“漫”既有遍布之意，也带着一种挥洒自如的意味。雪不是一处一处地下，而是铺天盖地，把整个世间统一成白色。

“写”是这一句的诗眼，也是全诗总领性的字。

因为如果只是说“天公降雪”，后面的“划、勾、蘸、抹、钤印”便无法形成完整结构；而有了“写”，整场雪就被赋予了书画创作的逻辑。

更妙的是“世间白”。

它并没有具体指出某一座山、某一片树，而是先把雪的覆盖范围写到“世间”。于是全诗从一开始就取得了宏阔尺度：不是写眼前局部落雪，而是在写整个世界被重新着色。

二、“一划千江止，轻勾万树开”：用画法写雪景，用动词改变山河状态

颔联是全诗最富创造力的一联。

“一划千江止”，首先把“划”从绘画动作转化成山河景象。

如果按照字面看，似乎只是一笔划过；但在诗中的画面里，这一笔同时也是冰雪对江河、溪流的覆盖，使原本流动的水面呈现出凝止之态。

因此“止”字极有力量。

雪落之前，江流是动的；雪落之后，天地仿佛忽然安静下来。一个“止”不仅写视觉上的凝滞，也直接把全诗的声音和节奏压低，为后面的“乾坤静”埋下伏笔。

而“千江”与“大笔”相呼应，继续扩大规模。天公一划，不是画一条江，而是“千江”。

下一句“轻勾万树开”更加有趣。

“勾”仍然是绘画动作，而“轻”字与上句的“一划”形成轻重变化：前一句大笔一划，后一句轻轻勾勒。

“万树开”则不是通常意义上的花开，而是雪覆树枝之后，枝干、树冠的轮廓被重新勾勒出来。雪使原先杂乱的树木获得了清晰、明亮的轮廓，仿佛一笔笔被白色重新描绘出来。

这里的“开”也很耐品。

它没有写“万树白”，而写“万树开”，于是雪景不再只是覆盖与遮蔽，反而产生了某种“显形”的效果。白雪越厚，树的枝干、结构与层次反而越突出，整个林木像在画面上舒展开来。

这样，“止”与“开”又构成了一组很漂亮的反差：

江因雪而“止”，
树因雪而“开”。

雪同时完成了凝固与显现。

三、“蘸云平地厚，抹雾远山皑”：墨色层次由近及远

颈联继续沿用绘画语言，但画面开始出现明确的空间层次。

“蘸云平地厚”中，“蘸”是一个非常巧的字。

画笔蘸墨，本来需要墨汁；这里却写“蘸云”。天空中的云仿佛成了画笔所蘸取的颜料，而大雪便由此铺到平地上。

“平地厚”写的是雪的积深，却没有直接说“雪厚”，而是通过“蘸云”把雪写成从天上取来的白色颜料。

这样一来，雪与云之间建立了绘画意义上的联系：

云是颜料的源头，
平地是落笔的纸面。

再看“抹雾远山皑”。

“抹”与“蘸”同样是画法，但“抹”比“勾”更加朦胧、宽泛。它不是勾勒轮廓，而是大面积地铺染。

而这里的对象是“远山”。

这与上一句的“平地”形成空间上的推进：

平地在近处，
远山在远方。

近处是厚厚的积雪，远处则被雾与雪共同晕染成一片皑皑。

“皑”字单独落在句尾，使远山的视觉效果非常纯粹：轮廓不再锐利，而是被雪雾洗成一片洁白。

于是颈联其实完成了一次由近到远的镜头推移：

平地之雪厚重，
远山之雪朦胧。

一个“厚”，一个“皑”，不仅是色彩与质感的变化，也是空间层次的变化。

四、“钤印乾坤静，听风岁月来”：封笔之后，雪景进入时间

尾联是全诗真正的收束，也是整个“天公作画”构思的完成。

“钤印乾坤静”最关键。

前面已经有“挥大笔”“写”“划”“勾”“蘸”“抹”，到这里终于出现书画作品完成后的最后一道程序：钤印。

因此，“钤印”不是普通的比喻，它实际上意味着天公已经完成这幅天地大画。

而钤印后的结果是“乾坤静”。

这个“静”既是雪后真实的环境感受，也是对颔联“一划千江止”的回收。

前面只是“千江止”，到这里已经扩大为“乾坤静”。

由局部的静，变成整个天地的静。

但真正高妙的是最后一句：

“听风岁月来。”

按照一般的雪景写法，到这里完全可以继续写视觉景色；诗却突然从“看”转向“听”。

前面写的是一幅画，到了这里画面仿佛已经静止，而诗人的感知却没有停止。

“风”本来是流动的、无形的声音；雪后的天地越静，风声反而越清晰。

而“岁月来”又将风声从当下引向时间。

这里的“来”很有意味。不是说人在回忆岁月，也不是说岁月逝去，而是仿佛在这片雪后的寂静中，岁月顺着风声缓缓来到耳边。

于是全诗的时间感也在最后一刻打开：

开始是“漫写世间白”，写的是这一场雪；
中间写江、树、平地、远山；
到了末句，却忽然让人在风声中听见“岁月”。

一场具体的大雪，因此从短暂的天气现象，转化成了一次关于时间的感受。

而“钤印”与“听风”之间还有一个很漂亮的构思转换：画已经封存，视觉已经定格，但时间并没有停止。乾坤可以静，岁月仍然在来。

这也使“静”获得了更深一层的意味——它不是世界真的停止，而是人在雪后的寂静中突然感受到时间本身。

结语

这首诗最完整的构思，是以“天公作画”为骨架，把雪景中的一切变化转换成“挥、写、划、勾、蘸、抹、钤印”这一套书画动作。雪因此不只是落在山川之上，而像是一位巨大的画家重新描绘天地。

真正精彩的地方在结尾：画面已经“钤印”，乾坤已经“静”，诗却不再继续看，而开始“听”。于是视觉上的雪景最终转化为听觉中的风声，又由风声抵达“岁月”。全诗也由一场雪，完成了从山水之美到时间之感的最后一转。
```
