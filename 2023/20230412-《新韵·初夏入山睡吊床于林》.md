# 《新韵·初夏入山睡吊床于林》

```
无情烈日多情树，小半斜光大半阴。
穿叶凉风催倦意，好偷清梦满山林。
```

# 赏析
```
此诗写夏日林中吊床小憩，笔调轻松惬意。"无情烈日多情树"以拟人对仗起笔——太阳是"无情"的，炙烤大地；而树木是"多情"的，张开浓荫庇护。这一组拟人将夏日最常见的树荫纳凉场景写出了别样的趣味。"小半斜光大半阴"以精确的比例感描摹林间光影——阳光透过叶隙只洒下星星点点，大部分仍是清凉的树荫，观察入微。

后两句"穿叶凉风催倦意，好偷清梦满山林"——穿林而过的凉风带着催眠的魔力，让人在这山林之中偷得一个清凉的梦。"偷"字用得俏皮，仿佛这段清闲时光是从忙碌人生中"偷"来的。末句"满山林"将个人的梦境与整片山林融为一体，颇有"万物与我为一"的逍遥。全诗写夏日纳凉的闲适与满足，从景到情一气呵成。
```
