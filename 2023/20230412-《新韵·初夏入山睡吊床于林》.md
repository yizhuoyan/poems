# 《新韵·初夏入山睡吊床于林》

```
无情烈日多情树，小半斜光大半阴。
穿叶凉风催倦意，偷吾清梦满山林。
```
>> 写于20230412

# 赏析
```
一、 逐句赏析
首句：无情烈日多情树

理解：初夏的太阳酷热难耐，仿佛对人间毫无怜悯之情；而山中的树木却枝叶繁茂，像多情的卫士一般撑开绿荫，给人以庇护。
赏析：开篇即用拟人手法，且对比极为强烈。“无情”与“多情”对举，将自然景物赋予人的性格。烈日的“无情”反衬出树木的“多情”，一贬一褒之间，诗人对山林的喜爱之情跃然纸上。这也是诗人选择“入山”避暑的缘由。
次句：小半斜光大半阴

理解：躺在吊床上，只看到一小部分阳光透过枝叶缝隙斜射进来，而绝大部分空间都被浓密的树荫所遮蔽。
赏析：这一句极具画面感，是对首句“多情树”的具体化描写。两个数量词“小半”与“大半”的对比，精准地勾勒出林间树冠交织、光影斑驳的视觉效果。“斜光”点明了时间的推移，阳光穿透树叶的缝隙洒下碎影，既写出了夏日的清凉感，又带有一种静谧的光影美。这也暗含了诗人躺在吊床上仰望视角的独特性。
第三句：穿叶凉风催倦意

理解：微凉的清风穿过树叶的缝隙吹拂过来，催生了人心中的倦意，让人昏昏欲睡。
赏析：由视觉转向触觉。前两句写光与影，这一句写风与感。“穿叶”二字写出了风的轻柔和林间的幽静，风不是呼啸而来，而是蹑手蹑脚地穿过树叶。“催”字用得极为传神，初夏山林的凉风就像一首温柔的安眠曲，一点点化解了世俗的疲惫，将人推向梦乡。这里的“倦意”并非指身体劳累，而是一种身心放松后的慵懒与惬意。
尾句：偷吾清梦满山林

理解：这山中的清风与树林，仿佛偷走了我的清梦，让它弥漫、散落在这整片山林之中。
赏析：这是全诗最妙的一句，境界顿开。诗人不说自己梦见山林，而是说风（或山林）把梦“偷”走了，而且“满山林”都是。一个“偷”字，俏皮生动，写出了梦境的甜美与不知不觉——梦得太沉，仿佛被大自然窃取了一般。“清梦满山林”更是将无形的梦境有形化、空间化，梦境与山林融为了一体。此时，诗人已经化身为自然的一部分，物我两忘，达到了一种极度空灵、澄澈的禅意境界。
二、 艺术特色
拟人与对比的精妙运用 诗中多处使用对比与拟人：“无情”对“多情”、“小半”对“大半”。这些对比不仅使句式工整灵动，更赋予了大自然以人情味。而“催倦意”、“偷清梦”的拟人化动作，让风与林都变得顽皮可爱，充满生机。
视角的细腻转换 短短四句，视角不断切换：从宏观的“日与树”的客观描写，到微观的“光与阴”的仰视观察；再转入“凉风”的触觉感受；最后宕开一笔，升华为“梦满山林”的奇妙想象。层层递进，过渡自然。
化实为虚，物我交融 前三句皆是实写（烈日、树、光、阴、风），最后一句由实入虚，用“偷”与“满”字，将个人的小我之梦放大至整座山林。梦的边界被打破，诗人的身心彻底融入了初夏的山林之中，意境深远。
```
