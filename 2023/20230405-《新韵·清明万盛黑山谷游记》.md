#《新韵·清明万盛黑山谷游记》
>> 清明节与妻友游黑山谷，吾独行至峡谷中忽有所感，遂作诗以记。写于20230405

```
正是清明天朗日，黑山谷里好逢春。
花先叶草争幽味，鸟与虫溪赛禅音。
满目枝摇红入绿，长风云动古同今。
谁知寒武亿年后，万丈峡中吾一人。
```

# 赏析
```
《万盛黑山谷游记》以清明时节的黑山谷春游为背景，前六句铺写花草鸟虫、溪流枝叶、长风云动的春日胜景，色彩明丽，声息繁富；结尾两句却突然将时间推向“寒武亿年”，空间收束于“万丈峡”，最终落到“吾一人”。全诗由春景而山河，由山河而古今，由古今而自我，在明媚的春日游赏中写出面对亿年天地时的生命感与时间意识。

首联： 正是清明天朗日，黑山谷里好逢春。

“清明”“天朗日”“逢春”共同营造出明净、舒朗而富有生机的氛围。“好逢春”既写时令与景物，也写游人的欣悦：恰逢清明晴日，走入黑山谷，正与一片蓬勃春色相遇。首联从明亮的天空落到幽深的山谷，既交代时间、地点，也为全诗奠定了清新明快的基调。

颔联： 花先叶草争幽味，鸟与虫溪赛禅音。

这一联由视觉转入嗅觉和听觉，写山谷万物竞相呈现生命之美。“花先叶”点出早春景象，花已先于繁叶绽放；“草争幽味”则将草木人格化，仿佛幽谷中的花草都在争相散发自己的幽香。

下句尤其传神：鸟与虫溪赛禅音。

鸟鸣、虫声、溪流声交织在一起，本来是繁复的自然声响，却以“禅音”概括其幽静、空灵的整体感受。这里的“禅”并非无声，而恰恰是万物各自发声，却彼此相融，形成一种天然的宁静。一个“赛”字更使静谧之中带有活泼的生命气息。

颈联进一步展开视觉空间：

满目枝摇红入绿，长风云动古同今。

“满目枝摇红入绿”写近处春色。“红入绿”不是简单罗列红花绿叶，而是写枝条摇曳之间，红色仿佛融入层层绿意之中，使色彩具有流动感。“满目”则扩大了视野，让整个山谷都笼罩在红绿交织的春意里。

“长风云动古同今”则由近景推向高远，从眼前春色进入天地时空。“长风”“云动”使画面骤然开阔，而“古同今”开始将自然景观与时间意识连接起来：眼前的风云虽然属于今日，却又仿佛与遥远古代同在。至此，诗意已经不再局限于“游春”，而开始触及自然跨越古今的永恒性。

尾联：谁知寒武亿年后，万丈峡中吾一人。

全诗的境界在这里陡然提升。

“寒武亿年”不是泛泛地说久远，而是将时间尺度推向地球生命演化的深远历史；“万丈峡”则将空间尺度推向极深、极险、极宏阔的境地。亿年之久与万丈之深，在最后共同衬托出一个极小的“吾一人”。

“吾一人”首先是游览情境中的独行之感：在幽深宏大的峡谷之中，诗人独自置身其间。但它又不止于写“独游”。当“吾一人”与“寒武亿年”“万丈峡”并置时，便产生了更深的生命感受——漫长的地质时间与宏大的自然空间面前，人的个体何其短暂而渺小。

尤其值得注意的是，前六句写的是一个充满生命声息的世界：花、草、鸟、虫、溪、枝、风、云，无不在动，无不在发声；到了结尾，却突然归结为“吾一人”。这种由“万物之盛”转入“一人之微”的收束，使全诗从写景自然转入自我观照。

因此，“吾一人”并不是单纯的孤独，而是一种人在亿年天地面前突然意识到自身存在的瞬间。正因为人的生命短暂，能够在这片经历亿年沧桑的山谷中与春天相遇，眼前这一刻才显得格外珍贵。

全诗的结构也因此呈现出清晰的层层推进：

清明春日 → 黑山谷春色 → 万物之声 → 风云古今 → 寒武亿年 → 万丈峡中一人。

它从“春”写到“山”，从“山”写到“古今”，最终从天地回到自身。前六句写天地之盛，最后一句写人之微；而正是在这种巨大的尺度反差中，形成了全诗最深的诗意。

这是一首以春色为表、以山河为骨、以时间为纵深、以生命自觉为落点的游记诗。一场清明春游，最终写成了一个人在亿年天地之间对自身存在的凝视。
```
