# 鼓励语音生成 —— 教学提示词

> 用途：教会一个 AI 模型/开发者，如何为「卷卷」系列儿童游戏生成中文鼓励语音音频。
> 交给模型时直接说：**"按本提示词实现鼓励语音生成工具，并生成指定文案的语音文件。"**
> 本方法全程离线、无版权风险、可重复执行。

---

## 一、任务目标

生成一套中文鼓励语音，供触屏儿童游戏播放。要求：

- 语音内容见 §三
- 格式：WAV / PCM / 16kHz / 16-bit / 单声道（与现有动物语音保持一致，Web Audio 可直接解码播放）
- 生成后合并为一个 **Audio Sprite（音频雪碧图）**：单文件 `praise.wav` + 清单 `praise.json`（记录每段 `{id:{start,duration,end}}`），播放时用 Web Audio `BufferSourceNode.start(when, offset, duration)` 按偏移取段
- 保留每段独立 WAV 作为源文件，便于日后修改文案后重跑

## 二、技术方案：Windows 本地 TTS（首选）

在线免费 TTS（Google Translate TTS / StreamElements / ResponsiveVoice / tts-api 等）多被限流或需 API key，**不要依赖**。首选 Windows 自带的 SAPI 语音合成，离线、免费、稳定：

- 语音：**Microsoft Huihui Desktop**（zh-CN 中文女声）
- 调用方式：PowerShell + .NET `System.Speech.Synthesis.SpeechSynthesizer`
- 若系统没有 Huihui（用 `Get-InstalledVoices()` 检查），选择任一 zh-CN 声音

### 核心 PowerShell 生成脚本（生成单个词/句）

```powershell
Add-Type -AssemblyName System.Speech
$synth = New-Object System.Speech.Synthesis.SpeechSynthesizer
$synth.SelectVoice('Microsoft Huihui Desktop')   # 若无则改用其他 zh-CN 声音
$synth.Rate = 0                                   # 0=正常语速；给幼儿可 -1
$fmt = New-Object System.Speech.AudioFormat.SpeechAudioFormatInfo(
    16000,                                       # 采样率 16kHz
    [System.Speech.AudioFormat.AudioBitsPerSample]::Sixteen,  # 16bit
    [System.Speech.AudioFormat.AudioChannel]::Mono)           # 单声道
$synth.SetOutputToWaveFile('praise.wav', $fmt)
$synth.Speak('你好，卷卷！')
$synth.Dispose()
```

批量生成：把文案放进数组循环 `SetOutputToWaveFile` + `Speak`，每个文案一个文件（文件名=语音 id）。

## 三、需要生成的语音（卷卷鼓励语，共 9 条）

| id | 文案 | 用途 |
|----|------|------|
| `hello` | 你好，卷卷！ | 首次进入主菜单 |
| `start` | 我们开始吧！ | 进入关卡/开始游戏 |
| `praise_1` | 卷卷真棒！ | 做对时随机鼓励 |
| `praise_2` | 卷卷好厉害！ | 做对时随机鼓励 |
| `cheer` | 卷卷加油！ | 鼓励/激励 |
| `correct` | 答对了！ | 判断正确 |
| `retry` | 再试一次！ | 做错时柔和提示 |
| `win` | 过关啦！ | 关卡/回合完成 |
| `wow` | 哇，真厉害！ | 惊喜/成就 |

> 文案可扩展（如"再来一个！""真聪明！"），保持"永远鼓励、无责备"的基调。

## 四、合并为 Audio Sprite

用 Node.js 写合并脚本（零依赖，用内置 `fs`）：

```js
const fs = require('fs');
const path = require('path');

const GAP_MS = 50;                       // 段间静音缓冲，防串音
const srcDir = process.argv[2];          // 单个 WAV 所在目录（按文件名排序）
const outBase = process.argv[3] || 'praise';
const outDir = path.dirname(srcDir);

function parseWav(buf) {
  let o = 12, fmt = null, data = null;
  while (o + 8 <= buf.length) {
    const id = buf.toString('ascii', o, o + 4);
    const size = buf.readUInt32LE(o + 4);
    if (id === 'fmt ') fmt = { channels: buf.readUInt16LE(o + 10), sampleRate: buf.readUInt32LE(o + 12), bits: buf.readUInt16LE(o + 22) };
    else if (id === 'data') data = buf.slice(o + 8, o + 8 + size);
    o += 8 + size + (size % 2);
  }
  return { fmt, data };
}

const files = fs.readdirSync(srcDir).filter(f => f.endsWith('.wav')).sort();
let fmtRef = null, chunks = [], segs = [];
for (const f of files) {
  const { fmt, data } = parseWav(fs.readFileSync(path.join(srcDir, f)));
  if (!fmtRef) fmtRef = fmt;
  if (fmt.sampleRate !== fmtRef.sampleRate || fmt.channels !== fmtRef.channels || fmt.bits !== fmtRef.bits) {
    throw new Error('格式不一致: ' + f);
  }
  segs.push({ id: f.replace(/\.wav$/, ''), data });
  chunks.push(data);
}

const bytesPer = fmtRef.channels * fmtRef.bits / 8;
const gap = Buffer.alloc(Math.round((GAP_MS / 1000) * fmtRef.sampleRate * bytesPer / 2) * 2, 0);
const merged = Buffer.alloc(chunks.reduce((a, c) => a + c.length, 0) + gap.length * (segs.length - 1));
const manifest = { format: { sampleRate: fmtRef.sampleRate, channels: fmtRef.channels, bits: fmtRef.bits, pcm: true }, gapMs: GAP_MS, file: outBase + '.wav', segments: {}, totalDuration: 0 };

let pos = 0;
for (let i = 0; i < segs.length; i++) {
  const start = pos / bytesPer / fmtRef.sampleRate;
  const dur = segs[i].data.length / bytesPer / fmtRef.sampleRate;
  manifest.segments[segs[i].id] = { start: +start.toFixed(4), duration: +dur.toFixed(4), end: +((start + dur).toFixed(4)) };
  segs[i].data.copy(merged, pos); pos += segs[i].data.length;
  if (i < segs.length - 1) { gap.copy(merged, pos); pos += gap.length; }
}
manifest.totalDuration = +(merged.length / bytesPer / fmtRef.sampleRate).toFixed(4);

const h = Buffer.alloc(44);
h.write('RIFF', 0, 'ascii'); h.writeUInt32LE(36 + merged.length, 4); h.write('WAVE', 8, 'ascii');
h.write('fmt ', 12, 'ascii'); h.writeUInt32LE(16, 16); h.writeUInt16LE(1, 20);
h.writeUInt16LE(fmtRef.channels, 22); h.writeUInt32LE(fmtRef.sampleRate, 24);
h.writeUInt32LE(fmtRef.sampleRate * bytesPer, 28); h.writeUInt16LE(bytesPer, 32);
h.writeUInt16LE(fmtRef.bits, 34); h.write('data', 36, 'ascii'); h.writeUInt32LE(merged.length, 40);

fs.writeFileSync(path.join(outDir, outBase + '.wav'), Buffer.concat([h, merged]));
fs.writeFileSync(path.join(outDir, outBase + '.json'), JSON.stringify(manifest, null, 2));
console.log('OK', outBase + '.wav', manifest.totalDuration + 's');
```

运行：`node merge-sprite.js <wav目录> praise`

## 五、关键注意事项

1. **"卷卷"是多音字**：昵称（卷发的小女孩）应读 `juǎn juǎn`，但 TTS 可能读成 `juàn juàn`（试卷的卷）。处理方式：
   - 生成后用系统播放器试听确认
   - 若读错：改用**同音近意写法**或**替换为"宝宝"**（`宝宝真棒！`），或手动微调文案
   - 项目里同时保留一套 `*_alt`（宝宝版）备份供对比，**不参与合并**
2. **WAV 而非 MP3**：MP3 编码有 pre-roll 延迟与填充字节，按偏移截取会错位；WAV 是 PCM，偏移逐采样精确。除非有可靠 MP3 编码工具，一律用 WAV
3. **Audio Sprite 是时间定位不是裁剪**：播放 = 在总文件上按 `offset + duration` 取段，`start(when, offset, duration)`，不是视觉切图
4. **替换素材**：以后某句文案改了就重生成单个 WAV，再重跑合并脚本，其余不动

## 六、交付物与验收

输出到游戏目录 `assets/audio/`：
- `praise/` 目录：9 个独立 WAV（源文件）
- `praise.wav`：合并单文件
- `praise.json`：清单（9 段，无重叠、无越界，`end ≤ totalDuration`）

验收：
- [ ] 每个 id 文案与 §三 表一致，试听发音清晰、无破音
- [ ] "卷卷"读音为 juǎn（或已确认替代方案）
- [ ] praise.json 各段无重叠、总时长与 wav 一致
- [ ] 可用任意播放器逐段试听（按 start 播放 duration）
- [ ] 若游戏里集成：`playPraise(id)` 能正确取段播放，与游戏音效互不干扰

## 七、备用方案（如无 Windows）

- 用 Python `pyttsx3`（底层也是 SAPI/espeak）+ 相同合并逻辑
- 或任何提供 WAV/PCM 输出的本地 TTS；合并脚本不变
- 不要用需联网授权/收费的在线 TTS
