
#《新韵·夜深独归》

------
~~~
虚空孤一月，
寂寂照人归。
急步惊邻吠，
遥传几犬回。
~~~
>> 写于20140908

# 赏析
```
"虚空孤一月"起笔便营造出空旷寂寥的夜空背景——天宇茫茫，唯有一轮孤月高悬。"孤"字既是月之状态，亦是人之心境。"寂寂照人归"以叠词"寂寂"强化静谧氛围，月光无声地照着夜归人，如一位沉默的陪伴者。

后两句以动写静——"急步惊邻吠"，急促的脚步打破夜的沉寂，惊起邻家犬吠；"遥传几犬回"写犬吠之声此起彼伏、远远近近地应和回荡，生动勾勒出深夜街巷的声景。一个"急"字暗示夜归人急于归家的心情，而"遥传"与"回"则写声音在寂静中的扩散与回荡。全诗前两句以视觉写静，后两句以听觉写动，动静相生。那一声声犬吠从近及远，又仿佛从远处传回，将夜行中那种孤独感反衬得更加鲜明。
```
