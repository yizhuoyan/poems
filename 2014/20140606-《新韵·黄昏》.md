# 《新韵·黄昏》
~~~
黄昏漫寂意，
夜近静人思。
犬吠虫鸣绕，
平生在此时。
~~~
>> 写于20140606

# 赏析
```
"黄昏漫寂意"，开篇便以"漫"字写出寂寥如潮水般弥漫扩散，将黄昏特有的苍茫感表现得极为准确。"夜近静人思"写夜色渐近，纷扰的思绪反而安静下来——人在黄昏时的"静"，不是空洞的沉寂，而是内心被放大的觉知。

后两句"犬吠虫鸣绕"以听觉细节勾勒黄昏的声景，犬吠与虫鸣交织，写尽乡野黄昏的日常气息。末句"平生在此时"如禅宗顿悟一般——那狗吠的那一声、虫鸣的那一瞬，整个人生竟浓缩于此。全诗前两句写"静"，后两句以声音反衬静，末句以哲学顿悟收束。在平常的黄昏中捕捉到生命体验的巅峰瞬间，于平凡处见深刻，是此诗最动人之处。
```
