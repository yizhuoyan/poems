# 《新韵·美梦》
~~~
连日周公怨，终怜赐见卿。
温香失复醒，冷泪见天明。
似坠花边露，如诗雨后虹。
人生多美事，愿入梦之中。
~~~
>> 写于20140412

# 赏析
```
开篇以"周公"入诗，古雅有趣——连日抱怨梦神不公，终于开恩赐得梦中一见，"怨"与"怜"将抽象的命运拟人化，同时也写出思念之切、相见之难。次联写梦醒后的失落："温香失复醒"写梦中温存尚在而人已醒来，"失复醒"三字层层递进，先失而后醒，双重的失落感；"冷泪见天明"以泪眼望着天色渐明，冷与暖、夜与昼的对比，写尽梦去后的凄凉。

三联连用两个比喻描摹梦境之美——"似坠花边露"写梦的晶莹易逝，"如诗雨后虹"写梦境的美好斑斓。末联"人生多美事，愿入梦之中"上升到对人生与梦境的思考：世间美事虽多，却不及梦中的相见。全诗由求梦、得梦、失梦、忆梦到恋梦，层次分明，情感饱满。
```
