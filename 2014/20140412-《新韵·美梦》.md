# 《新韵·美梦》
~~~
连日周公怨，终怜赐见卿。
温香失梦醒，冷泪见天明。
似坠花边露，如诗雨后虹。
人生难美事，昨夜恍惚中。
~~~
>> 写于20140412

# 赏析
```
这是一首情感深挚、意境凄美的五言诗。全诗以“梦”为线索，写尽了思而不得的怅惘、梦中相见的欣喜以及梦醒时分的落寞，最后升华为对人生无常的哲思。以下为您作详细的理解与赏析：
一、 逐句解读
首联：“连日周公怨，终怜赐见卿。”
解读：连日来我苦苦思念，甚至连主管梦境的周公都埋怨我求梦太频，终于他心生怜悯，让我在梦中见到了你。
赏析：起笔交代了梦境的背景。“连日周公怨”反向落笔，不直言自己多么渴望入梦，而是说连周公都嫌弃我求梦太频，将极度的思念表现得幽默又心酸。“终怜”二字，透出一种苦尽甘来的庆幸感，“赐见卿”则将心上人视若珍宝，梦中相见仿佛是上天莫大的恩赐。
颔联：“温香失梦醒，冷泪落天明。”
解读：梦中你温软的香气还萦绕在侧，却因梦醒而骤然失去；清晨醒来，只有冰冷的泪水伴随天明落下。
赏析：这一联是全诗的情感转折，也是最为动人的一笔。“温香”是梦境的虚幻留存，“失”字写出了美梦破灭的猝不及防；“冷泪”是现实的残酷映照。“温”与“冷”的强烈对比，将梦中相聚的缱绻与醒来后独守空房的凄凉刻画得入木三分。梦境越美，醒来越痛。
颈联：“似坠花边露，如诗雨后虹。”
解读：这场美梦，就像花边即将坠落的露珠一样短暂，又像雨后初晴的彩虹那样美丽而不可触摸。
赏析：此联用两个绝美的比喻来具象化“美梦”。“花边露”极言其短暂与脆弱，美丽只在一瞬，转瞬即逝；“雨后虹”极言其绚烂与虚幻，可望而不可即。这两者都是世间极美却极不长久之物，恰好对应了“美梦”的特质——美得令人心醉，却又无法挽留。
尾联：“人生难美事，昨夜恍惚中。”
解读：人生在世，本来就很难有完美无憾的事情，那份美好，也只能存在于昨夜那恍惚的梦境之中了。
赏析：由梦及人生，完成主题的升华。“难美事”是看透世事的喟叹，呼应了前文的失落；“恍惚中”则带着一种如幻如真的迷离感。现实太苦，美事难求，唯有在梦的恍惚中才能得到片刻慰藉。这是一种无奈的妥协，也是一种深刻的悲哀。
二、 艺术特色
虚实相生，对比鲜明
诗的前半部分写“入梦”与“梦醒”，是虚景与实景的交替；后半部分写“露”与“虹”，是比喻中的虚实。特别是颔联“温香”与“冷泪”的对比，以梦中的极暖反衬现实的极寒，使情感的张力达到了顶峰。
遣词凝练，扣题紧密
全诗紧扣“美梦”二字。梦前是“怨”，梦中是“怜”，梦醒是“失”，梦后是“冷”，回想是“恍惚”，情感脉络清晰，字字皆由心血凝成。
意象凄美，境界空灵
诗人选取了“花边露”“雨后虹”这两个极具古典美和易碎感的意象，将抽象的梦境和怅惘的情绪化作具体的画面，营造出一种清幽、空灵、哀婉的意境。
三、 总体评价
《美梦》是一首披着唯美外衣的伤情诗。它名为“美梦”，实写“残缺的人生”。诗人借一场短暂的美梦，抒发了对逝去感情（或求而不得之人）的深切怀念，以及对人生“好梦难圆、美事难全”的无奈与释然。
读此诗，仿佛看到一个人在清晨微光中独坐，脸上还带着梦里的余温，眼角却已凝结成冰冷的泪滴。它触动了人类共通的情感体验——越是美好的东西，往往越如露如电，抓不住，留不长，只能留在昨夜的恍惚中，化作一生的意难平。
```
