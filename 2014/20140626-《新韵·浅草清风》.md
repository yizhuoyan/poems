# 《新韵·浅草清风》

~~~
浅草清风里，
斜光叶下阴。
背依相闭眼，
天地只一人。
~~~
>> 写于20140626

# 赏析
```
前两句以清风、浅草、斜光、叶阴四个意象构建出一幅静谧的夏日午后图景，光线在树叶间斑驳洒落，气温柔和，一切恰到好处。"浅""清""斜""阴"四个形容词精准捕捉了这个时刻的质感——宁静、清凉、私密。

后两句写人的姿态与感受。"背依相闭眼"一句写两人背靠背、同时闭眼，这个姿势既有亲密又有独立——背靠是互相支撑，闭眼是各自沉浸；"天地只一人"则是这种状态下的极致感受：天地茫茫万千世界，此刻心中眼中，却只有一个人。全诗以景铺垫、以人点题，氛围营造极为成功。在"浅草清风"这样微小的自然场景中，却迸发出"天地只一人"这样宏大的情感宣言，以小见大、以轻写重，读来动人心弦。
```
