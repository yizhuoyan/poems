
# 《新韵·花上月一轮》
~~~
眼闭思随远，
天涯定有人。
清风它自去，
花上月一轮。
~~~

# 赏析
```
首句"眼闭思随远"，以闭眼这一动作启动思绪的远行——视觉关闭，内在的思念反而挣脱束缚飘向远方。次句"天涯定有人"语气坚定，"定"字传达出一种不容置疑的确信：天涯海角，一定有那么一个人在。这既是自我安慰，也是深情独白。

后两句不写思念如何，却宕开一笔写自然之景。"清风它自去"——清风自顾自地离去，不问人情；"花上月一轮"——唯有那一轮明月静静照在花枝之上。以客观景语收束主观情语，清风无情而月光有意，一切思念都凝练在花与月交汇的静谧画面中。前两句直抒胸臆，后两句以景结情，深得古典诗歌"兴"之妙法。语言清新淡雅，意境空灵澄澈，是一首"只可意会"的佳作。
```
