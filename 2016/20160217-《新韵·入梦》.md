# 《新韵·入梦》
~~~
凝日还西后，
隔窗伴夜时。
盼君多入梦，
怜我久相思。
~~~
>> 写于20160217

# 赏析
```
首句"凝日还西后"写凝望夕阳西沉直至最后一缕光消失，"凝"字出神——诗人久久凝视落日，仿佛要将那一刻凝固，不舍昼夜的更替。"隔窗伴夜时"写夜幕降临后，独坐窗前与夜为伴，一个"隔"字暗示与外界隔绝的状态。

后两句直抒胸臆："盼君多入梦"——思念至极，只能将重逢的希望寄托于梦境；"怜我久相思"以一个"怜"字道尽相思之苦——"久相思"不止是时间的累积，更是情感的煎熬，末句以请求的口吻说出：请你怜惜我这份长久的思念，到我的梦中来吧。全诗前两句写独处的时间与空间，后两句写情感的核心诉求。由沉静的白描到直白的告白，由"凝"的克制到"盼"的迫切，情感层层加温，是一首真挚动人的相思之作。
```
