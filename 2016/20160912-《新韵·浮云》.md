# 《新韵·浮云》
~~~
别处红烛暖，
衾边泪痕深。
浮云难入梦，
世上已无人。
~~~
>> 写于20160912

# 赏析
```
"别处红烛暖"以追忆起笔，红烛的暖光勾勒出离别时的场景——烛光是温热的，人心却是凉的，暖与冷之间形成隐晦的张力。"衾边泪痕深"陡然切回当下，枕边泪痕深重，"深"字既指泪水的痕迹深刻，亦暗示流泪之久、悲伤之深。从"红烛暖"到"泪痕深"，一段往事凝于两个画面。

"浮云难入梦"以浮云喻思念中的那个人——轻薄无形的云，缥缈不定，连入梦都如此艰难。末句"世上已无人"以决绝之语收束全篇：不是"无一人"，而是"已无人"——那唯一的一个已经不在了，这世界之于我，如同空无一人。此句与"红烛暖"遥相呼应，从昔日温暖到如今的虚无，反差巨大。全诗由回忆中的一帧画面到枕边的悲恸，由浮云的不可触及到世界的空荡，层层加深，情感浓度极高。
```
