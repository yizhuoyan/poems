# 《新韵·候灯》

~~~
临窗生远绪，
近夜起相思。
候尽灯一盏，
双痕梦醒时。
~~~

# 赏析
```
"临窗生远绪"写临窗远眺，思绪如丝般飘向远方——窗是内外之间的媒介，也是思念的起点。"近夜起相思"以"近夜"点明时间推移，夜色渐浓则相思渐起，夜幕与思念同步降临，情景交融。

后两句写等待的过程与结果。"候尽灯一盏"是全诗最富画面感的句子——灯油燃尽、灯芯将灭，一盏守候的灯见证了从夜初到深夜的漫长等待。"候尽"二字既有时间的耗尽，亦有耐心的透支。"双痕梦醒时"中"双痕"暗指两行泪痕，梦中短暂的相聚以醒来时的泪痕告终。全诗以"候"为眼——临窗是候，近夜是候，灯盏是候的见证，双痕是候的结果。二十字中，空间、时间、物象、情感层层递进，写尽了一个人彻夜等待的孤寂与最后的心碎。
```
