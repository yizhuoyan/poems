#《新韵·小轩窗》
~~~
雨静夜初凉，
风黑泥有香。
楼台昨夜月，
应照小轩窗。
~~~
>> 写于20160805

# 赏析
```
"小轩窗"三字典出苏轼《江城子》"小轩窗，正梳妆"，天然带着悼亡与怀旧的底色。首句"雨静夜初凉"写雨后初霁、夜色微凉，空气中透着洗净后的清冽。次句"风黑泥有香"别出心裁——"风黑"以颜色写风声，将不可见的风赋予质地与色彩，想象力独特；"泥有香"则从嗅觉捕捉雨后泥土的芬芳，粗粝中透着清新。

后两句"楼台昨夜月，应照小轩窗"——昨夜的楼台月色，此时应当正照在那扇小窗之上。"应照"二字是推断也是期许，是回忆也是想象。月光下的小轩窗，既是苏轼词中梳妆的旧梦，也是诗人心中那个特定的、承载着美好记忆的所在。全诗由眼前的雨后夜景出发，引向对往昔的遥想，以月光为媒介将今昔贯通，含蓄蕴藉，余韵绕梁。
```
