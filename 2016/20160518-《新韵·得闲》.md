# 《新韵·得闲》
~~~
终日奔波苦，
得闲且忆君。
此生归旧梦，
迟了美人心。
~~~

# 赏析
```
"终日奔波苦"起句便写尽生活的常态——终日为生计奔波的疲惫与苦涩扑面而来。次句"得闲且忆君"是难得的喘息时刻，在忙碌的缝隙中，思念悄然浮现。"且"字有一种"总算可以"的意味——忙时无暇思念，只有得闲之时才能放任自己想你，平添几分无奈。

后两句是痛彻心扉的反思。"此生归旧梦"写回首一生，仿佛一切都归于旧日的梦境中——过去的时光如梦般虚幻而不可追回。"迟了美人心"是全诗最沉痛的一句——"迟了"二字表达了辜负与错过：或许是没有及时表白、或许是未能兑现承诺、或许是让心上人等待太久。全诗由日常奔波中的片刻闲暇切入，不期然触发了内心最深处的愧疚与遗憾，语言朴素而情感极其真挚。
```
