# 《新韵·盼梦》
~~~
枕上留一梦，
多逢雨夜时。
今秋天不爱，
长是月空枝。
~~~

# 赏析
```
"枕上留一梦"——一个"留"字意味深长，像是在枕上刻意存留着一场残梦，不愿它消散。"多逢雨夜时"写这样的梦总在雨夜造访，雨夜与梦境有一种天然的关联——雨声助眠，但也催生思念的梦。前两句写梦的可贵与梦境的来之不易。

后两句的转折令人意外。"今秋天不爱"——这个秋天，上天似无情意，不肯赐予好梦或温暖。"不爱"二字直白而沉痛。末句"长是月空枝"以景语收结：抬眼望去，总是那一轮冷月照着光秃秃的枝桠。繁花落尽、枝叶凋零，只剩月光徒然照在空枝之上——"空"字既是枝头之空，亦是心中之空。全诗前两句盼梦，后两句梦碎。从"留一梦"到"月空枝"，从期待到失望，情感脉络清晰而动人。
```
