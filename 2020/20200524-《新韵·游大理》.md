# 《新韵·游大理》
```
矗矗苍山横百里，相倾洱海任浮云。
风吹浪起层层玉，日照波翻点点金。
月卧峰巅千载雪，花摇城内几朝人？
我非世上悲秋客，却抱一愁古至今。
```
>> 写于20200524

# 赏析
```
这首《新韵·游大理》是一首格调雄阔而又寄寓深沉哲思的七言律诗。诗人以现代新韵入诗，既遵循了近体诗严谨的格律与对仗，又融入了开阔的现代视野。全诗巧妙化用大理著名的“风花雪月”四景，由远及近、由景入情，从对壮丽山水的赞美升华为对历史与生命永恒命题的叩问。

逐联赏析
首联：宏阔起笔，山水相依
“矗矗苍山横百里，相倾洱海任浮云。”

赏析：起句气势磅礴。“矗矗”极言苍山之高耸挺拔，“横百里”写其连绵不绝的恢弘体量；次句“相倾”二字拟人化，写出了苍山与洱海依偎相伴的深情，“任浮云”则赋予山海一种超然物外、坐看云卷云舒的淡泊与从容。首联以大写意的手法勾勒出大理山水的大格局，意境高远。
颔联：工笔绘景，光色交辉
“风吹浪起层层玉，日照波翻点点金。”

赏析：此联转入工笔细描，对仗极为工整。诗人抓住洱海在风与日照下的动态美感：“风吹浪起”将翻卷的白浪比作“层层玉”，显其洁白温润；“日照波翻”将阳光下的碎波比作“点点金”，显其明亮璀璨。
一“玉”一“金”，冷暖色调交相辉映；“层层”与“点点”叠字生动，极具画面感与节奏感。同时，此联暗含了大理四景之“风”（下关风）。
颈联：巧融四景，探问古今
“月卧峰巅千载雪，花摇城内几朝人？”

赏析：这是全诗的诗眼与转折点，兼具意象之美与哲思之深。
意象上：将大理四景中的“月”（洱海月）、“雪”（苍山雪）、“花”（上关花）天衣无缝地嵌于一联之中，与颔联的“风”凑齐了完整的“风花雪月”。“月卧”二字用得极静、极传神，写出了月落雪峰的安详。
哲理上：诗人通过“千载雪”与“几朝人”的对比，拉开了时间的纵深感——自然之雪历经千年而不泯，古城之花虽岁岁摇曳，城内的主人却已不知更迭了多少朝代。此处以自然的永恒反衬人生的短暂与历史的沧桑，意蕴深远，隐隐有陈子昂《登幽州台歌》与苏轼《赤壁赋》的时空苍凉感。
尾联：宕开一笔，情思深沉
“我非世上悲秋客，却抱一愁古至今。”

赏析：尾联由景入情，点明主旨。诗人开篇自陈“非悲秋客”，声明自己并非伤春悲秋、无病呻吟的庸俗文人，紧接着以“却抱一愁”陡然一转。
这里的“一愁”，并非个人身世之悲，而是承接颈联而来的“古今之愁”——是对“逝者如斯夫”的生命喟叹，是对浩瀚宇宙与沧海一粟的深刻自省。这一笔收束得沉郁顿挫，余音绕梁。
艺术特色总结
构思精巧，四景齐备：诗人不着痕迹地将大理“风、花、雪、月”四大胜景化入颔联与颈联之中，景中有诗，诗中有画。
时空交织，由实入虚：前四句偏重于“空间”的铺陈（山、海、浪、光），后四句转向“时间”的叩问（千载、几朝、古今），层次分明，格局宏阔。
音律明快，对仗严谨：全诗遵循新韵，朗朗上口；中两联对仗工整精当，既有动静对比，又有色泽相称，展示了扎实的近体诗功底。
这是一首“游而不浮、景中含理”的优秀行旅诗，将大理的壮美风光与文人的宇宙情怀完美融合。
```
