# 《新韵·游大理》
```
矗矗苍山横百里，相倾洱海任浮云。
风吹浪起层层玉，日照波翻点点金。
月伴峰巅千载雪，花摇城内几朝人？
我非世上悲秋客，却抱一愁古至今。
```
>> 写于20200524

# 赏析
```
这首七言律诗以大理苍山洱海为背景，却在壮美风景的铺陈中悄然埋下一条幽深的情感暗流，最终在尾联爆发出震撼人心的时空之叹。

首联以“矗矗”叠词起势，苍山如巨人横亘百里，洱海则悠然“任浮云”舒卷。一刚一柔，一静一动，勾画出天地不言而自美的宏大格局。“任”字尤妙，赋予浮云以自由，也暗示自然超脱于人间悲欢的永恒姿态。

颔联聚焦光影变幻，“风吹浪起”本可壮观，诗人却取“层层玉”之细腻；日照波光，本可辉煌，却著“点点金”之琐碎。这种由宏入微的视角转换，暗示诗人并非单纯赞叹山河壮丽，而是在细节中捕捉稍纵即逝的美——玉碎金散，恰似美好事物的易逝性，为尾联之“愁”埋下伏笔。

颈联转入时间维度。“月伴峰巅千载雪”将视线拉向永恒——月光与雪峰构成天地间最恒久的组合；而“花摇城内几朝人”则猛然将镜头切回人间——花开花谢依旧，赏花之人却已更迭“几朝”。空间上的“峰巅”与“城内”，时间上的“千载”与“几朝”，形成强烈对照：自然以千年为刻度，人生却以朝代匆匆丈量。

正是在这层层铺垫下，尾联如孤峰突起。“我非世上悲秋客”明确拒绝传统文人对季节的敏感哀愁，但紧接着“却抱一愁古至今”，这“愁”便不再是个人际遇的感伤，而是面对苍山千载、洱海万古时，猛然察觉自身渺小如朝露的宇宙乡愁。陈子昂“前不见古人，后不见来者”的孤绝在此复现，只是更含蓄、更内敛——诗人将这份天地悠悠的终极叩问，轻轻藏进“一愁”二字，却让全诗从风景诗升华为存在之思。

这首诗的精妙处在于：所有风景描写都是铺垫，所有壮美都反衬出人的渺小，所有永恒都刺痛着短暂的生命。当诗人抱紧那“古至今”的愁绪时，他怀抱的其实是整个人类面对无限时空时的共同困惑——这愁，因此轻如微风中的花影，又重如苍山不化的积雪。
```
