# 《新韵·游大理》
```
矗矗苍山横百里，相倾洱海任浮云。
风吹浪起层层玉，日照波翻点点金。
长望峰巅千载雪，幽思城内几朝人？
我非世上悲秋客，却抱一愁古至今。
```

# 赏析
```
首联以"矗矗"叠词状苍山之巍峨，"横百里"写其绵延之势；"相倾洱海任浮云"以"倾"字写苍山如倾身向着洱海，将山水之间的依恋写得极具深情。颔联对仗极工——"风吹浪起层层玉，日照波翻点点金"，风起时湖面层层如碧玉，阳光下波光点点似碎金，视觉色彩鲜明，"层层"与"点点"叠用有韵律之美。

颈联从壮阔的眼前景转向深邃的历史感——"长望峰巅千载雪"，千年不化的苍山雪是时间的见证；"幽思城内几朝人"——大理城内曾有过多少朝代的人来来去去？由空间之广转入时间之深。尾联"我非世上悲秋客，却抱一愁古至今"是情感的最大高潮——诗人自谓并非伤春悲秋之人，却在此山水之间感受到一种贯穿古今的愁思。这种"愁"超越了个人际遇，是面对永恒山水与短暂人生时的苍茫之感。
```
