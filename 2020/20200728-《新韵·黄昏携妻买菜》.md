# 《新韵·黄昏携妻买菜》
```
天旷蓝如海，云轻荡若舟。
众生多苦短，方外总烦忧。
老朽思空相，娇妻讨肉馐。
谁知明日事，今晚酒猪头！
```
>> 写于20200728

# 赏析
```
天旷蓝如海，云轻荡若舟。
黄昏时分，天空广阔无垠，湛蓝如海；几缕薄云轻盈飘荡，仿佛水中行舟。起笔便勾勒出一幅宏阔而悠然的黄昏天际图，“蓝如海”写其深广，“荡若舟”写其灵动，视野高远，心境也随之舒展。

众生多苦短，方外少烦忧。
由眼前天地之恒常，忽然转入对人生的慨叹——世间众生，生命苦多乐少，时光短暂易逝；而超脱尘世的方外之境，大约少有这般扰攘烦忧吧。这一联是情绪的转折，从天地的“无垠”对比人生的“苦短”，透出淡淡的苍凉与出世之思，为后文埋下伏笔。

老朽思空相，娇妻讨肉馐。
上句“老朽”自指，说自己虽有心向佛，思慕诸法空相；下句“娇妻”却忽而扯回人间烟火，拉着诗人要买肉食。这一联妙在“思空相”与“讨肉馐”的并置，一个高渺，一个俗常，对比间生出十足的幽默与温暖。出世之念再真诚，也敌不过身边人一句实在的烟火要求。

谁知明日事，今晚酒猪头！
末联是诗人对自己心思的自我调侃与最终决断：明日如何、方外如何，谁说得准呢？今晚且要酒要肉，痛快吃一顿猪头肉！口语化的结尾，洒脱不羁，将前文的苍凉与哲思通通化入一碟猪头肉、一杯浊酒之中，归于具体而微的现世欢愉。

全诗从高远之景起笔，转入人生慨叹，再折回夫妻日常的琐碎对话，终以痛快淋漓的世俗享乐收束。笔法松弛有度，情感转折自然，在禅意与烟火之间找到了一个俏皮的平衡点。诗人并不故作超脱，也不沉溺于伤怀，而是坦然地、欣然地接受了生活的“当下性”——所谓诗与远方，有时就藏在一盘猪头肉的热气里。语言朴白如话，却因内在的张力而显得意味深长，是典型的“淡而有味”之作。
```
