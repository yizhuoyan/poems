# 《新韵·西北游》

```
荒山盖草点牛羊，冷日低云影虎狼。
四顾无花无树木，风光奇异异南方。
```
>> 写于20201221

# 赏析
```
这是一首写西北风光的纪游诗。首句"荒山盖草点牛羊"——"盖"字写枯草如毯覆满荒山，"点"字写牛羊星星点点散布其间，以"盖"之满与"点"之疏形成对比。次句"冷日低云影虎狼"——西北的太阳清冷无温，云层低垂，山石的阴影在地上投出虎狼般的形状，用"虎狼"形容嶙峋怪石的剪影，既写实又透着苍凉肃杀之气。

后两句以南方人的视角发出感慨："四顾无花无树木"——环顾四周不见繁花与绿树的踪影，直白地写出西北地貌与南方迥异的特征；"风光奇异异南方"——"异"字重复使用，强调这种差异带来的视觉冲击与心理感受。全诗以简笔勾勒出西北高原的苍茫景观，无一处雕琢，却精准捕捉了大西北独特的荒凉之美，在对比中透露出诗人对故土的隐隐思念。
```
