# 《新韵·黄昏买菜有感》
```
天旷蓝如海，云轻荡若舟
人生一甲子，天地几悠悠
妻猝言馋肉，娇娇两盼眸
千秋身后事，今晚酒猪头
```
>> 写于20200728

# 赏析
```
此诗妙在"大"与"小"之间的巨大落差所带来的张力与趣味。首联写景——天空如海、白云如舟，是诗人黄昏行路时的抬头所见，画面开阔疏朗。颔联由景入思——人生不过一甲子，而天地悠悠无穷，"几悠悠"以反问语气表达了对时空无限的感慨，格调庄重而深沉。

颈联突然急转直下——"妻猝言馋肉，娇娇两盼眸"，妻子猝不及防地说想吃肉，带着娇憨期盼的眼神。从"天地悠悠"的哲思到"馋肉"的日常，这种切换极具戏剧性和生活气息。尾联进一步升华这种反差——管什么千秋万代身后之名，今晚只需买酒和猪头！"千秋身后事"与"今晚酒猪头"的对举，既有看破红尘的旷达，又有知足常乐的烟火气。大俗大雅之间，诗人找到了日常生活最质朴的诗意。
```
