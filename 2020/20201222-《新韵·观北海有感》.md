# 《新韵·观北海有感》
```
一线分天水，千银叠浪滨。
赤足沙里痒，老脸有风亲。
碧海开胸臆，白云沁我心。
此中豪迈意，万古到如今。
```

# 赏析
```
首联写远眺海景——"一线分天水"以极简的线条勾勒海天相接处的地平线，"千银叠浪滨"以"千银"喻层层叠叠的白色浪花涌上海滨，画面壮阔而富有层次。颔联的笔触突转为轻松幽默的细节——"赤足沙里痒"写赤脚踩在沙滩上的细微触感，"老脸有风亲"以拟人手法写海风亲吻面颊，"亲"字将无形的风写得亲昵可人，而"老脸"一词的自嘲又透露出诗人的诙谐。

颈联重归庄重——碧海开阔了胸襟、白云沁润了心灵，碧海与白云同时作用于外在与内在。尾联"此中豪迈意，万古到如今"将个人的感慨上升到亘古的维度——面前这片海，万古以来便是如此浩瀚，而此刻的豪迈之情，与千年之前凝望同一片海的人心意相通。全诗将壮阔、幽默、哲思熔于一炉，是一首层次丰富的观海之作。
```
