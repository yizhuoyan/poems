
# 《新韵·午后入林》
```
林声净耳千阶静，
一水争流两岸分。
漫步惊飞丛里鸟，
归巢闲话是何人？
```
>> 写于20200407

# 赏析
```
"林声净耳千阶静"——松涛泉响，声声入耳，反而洗去了尘世的喧嚣，"净耳"一词用得新颖，将听觉体验提升为一种精神上的净化。"千阶静"写石阶层层延伸、山林层层寂静，空间感与静谧感同步铺展。"一水争流两岸分"以"争"字写溪水的活泼，打破了前句的静，动静相生。

后两句转写人的活动与发现。"漫步惊飞丛里鸟"以人的闯入打破林中的宁静，惊起一群飞鸟，画面生动鲜活。末句"归巢闲话是何人"最为巧妙——鸟儿归巢后叽叽喳喳，仿佛在闲话家常，诗人不禁笑问：你们在议论谁呢？将鸟鸣拟作"闲话"，以天真的口吻将整首诗的意趣推到最高点。全诗由入林到惊鸟再到听鸟语，层层推进，充满了发现自然之趣的喜悦。
```
