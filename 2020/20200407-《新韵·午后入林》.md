
# 《新韵·午后入林》
```
林声入耳千阶净，草色随溪两岸分。
漫步惊飞丛里鸟，归巢今夜应嗔人。
```
>> 写于20200407

# 赏析
```
这首诗是一首清幽自然的七言绝句，全诗在写景中融入细腻的心理与情趣。

一、意象鲜明，视听交融
首句“林声入耳千阶净”从听觉入手，以“林声”写风过林梢的飒飒之响，却用“千阶净”转写视觉与触觉——仿佛这声音能涤荡石阶上的尘埃，也洗净人心中的杂念，是一种通感式的清新。次句“草色随溪两岸分”则俯视溪流，以“随”字写草色与溪水相依相映，“分”字勾勒出两岸绿意随水势展开的层次感，画面明丽而开阔。

二、动静相生，转折有致
前两句静景铺陈，第三句“漫步惊飞丛里鸟”突然转入动态：诗人悠闲行走，却不意惊起藏身草丛的鸟儿。这一“惊”打破了林间的宁静，也使画面顿时活泼起来。由静而动，由我观景到景因我动，转折自然，富有生趣。

三、拟人收尾，余味悠长
末句“归巢今夜应嗔人”是全诗点睛之笔。诗人不说自己惊扰了鸟，却悬想鸟儿归巢后会在夜里嗔怪、抱怨自己，以“嗔”字赋予鸟儿孩童般的小情绪，既幽默又亲切。这种将自然生物人格化的写法，既流露出诗人对生灵的体贴与歉意，又反衬出他身处此境的闲适与敏感——正因为心静意闲，才会在意一只鸟的“心情”。

四、整体情韵
全诗语言浅近而意趣盎然，既有“千阶净”的空灵，又有“嗔人”的谐趣，体现了诗人与自然亲密相处时的悠然自得，以及在动静交错间对生命细微处的温柔观照。读来仿佛身临其境，余韵袅袅。
```
