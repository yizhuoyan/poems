
#《新韵·登金城山观日台望》

------
~~~
万壑出云海,
千松入九霄。
池边垂钓客，
天地酒今朝。
~~~
>> 写于20120209

# 赏析
```
起笔"万壑出云海"，以"出"字写云海翻涌、群山浮现之动态，气象磅礴；"千松入九霄"，"入"字又写松柏刺破青天之挺拔，一出一入，纵横千里，将登山所见之壮阔尽收笔下。数字"万""千"对举，极言天地之广大。

后两句笔锋陡转，从万里山河收至一方池畔。"池边垂钓客"以闲逸之姿打破前文的雄浑，形成强烈反差。末句"天地酒今朝"是全诗之眼——以天地为酒、今朝为饮，将壮丽山河化作杯中一醉，既有李太白"且须饮美酒，乘月醉高台"的豪逸，又有陈子昂"念天地之悠悠"的苍茫。全诗由宏大到细微、由壮景到心境，收放自如，境界高远，可谓登山诗中的佳作。
```
万壑出云海,
千松入九霄。
池边垂钓客，
天地酒今朝。
~~~
