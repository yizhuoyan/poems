#《新韵·归梦》
```
漫步林荫道，
相依月下街。
归来些许梦，
不愿与卿别。
```
>> 写于20120610

# 赏析
```
前两句以工整的对仗铺陈梦境画面：林荫道上漫步，月下街头相依。两个场景皆寻常却温馨，是记忆中或期许中与爱人共度的美好时光。"林荫道"与"月下街"，白昼与夜晚的意象并置，暗示欢愉绵延终日。

后两句笔锋一转，"归来些许梦"点明前文的美好不过是梦归后的残影，一个"些许"道尽梦醒后的怅惘与不甘。"不愿与卿别"以直白之语收束全篇，朴素真切，不事雕琢。前面所有的温馨场景，其情感内核皆凝聚于这最后一句话——因为不愿分别，所以才有梦中的相聚；因为现实中不能相守，所以才在梦里不愿醒来。全诗以梦写实，以乐写哀，感情真挚浓烈。
```
