# 《新韵·沿湖》

~~~
茂林盛碧水，
盎盎映蓝天。
执手倾心意，
沿湖共陶然。
~~~
>> 写于20120606

# 赏析
```
前两句写景，"茂林盛碧水"以"盛"字勾连林木与湖水，绿意葱茏、水光潋滟；"盎盎映蓝天"以叠词"盎盎"摹写生机洋溢之态，碧水倒映蓝天，上下天光交相辉映，一片澄明开阔。纯用白描，却色彩鲜明，满目清新。

后两句由景及人，"执手倾心意"一个简单的牵手动作，承载了千言万语——无需多言，心意已倾。"沿湖共陶然"以"共"字点出双人同游的温馨，"陶然"二字收束全篇，将沉醉于美景与良伴的双重喜悦凝于一词。全诗前两句浓墨绘景，后两句淡笔写情，情景交融，语言明快而情感饱满，读来如春风拂面。
```
