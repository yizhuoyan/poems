# 《新韵·怀人》
~~~
几口驱寒酒， 
一窗寂寞深。 
常思闺里梦， 
可有去年人？
~~~
>> 写于20120122

# 赏析
```
起笔"几口驱寒酒"，以日常动作切入，酒为驱寒，亦为驱愁。然而酒入愁肠，换来的却是"一窗寂寞深"——"几口"与"一窗"形成量之对比，酒少而寂寞深，愈饮愈觉孤寒。一个"深"字，将寂寞从状态写为空间，如夜气沉沉、满窗皆是。

后两句由实入虚，"常思闺里梦"将思绪引向虚拟的梦境空间。"可有去年人"化用唐崔护"人面不知何处去"之意，却以疑问句出之，更显不确定中的期盼与期盼中的不安。去年之人，今年还在否？此一问，问的是梦中人，亦是心中人。短短二十字，层层递进，由酒及寒、由寒及寂、由寂及思、由思及问，含蓄深沉，余韵悠长。
```
