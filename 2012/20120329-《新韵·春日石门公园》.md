# 《新韵·春日石门公园》

~~~
午后一身暖，心融卧柳石。
鼻间湖吐气，耳后鸟争枝。
春有重归日，人无再见时。
随风花且落，入水已成痴。
~~~

>> 于重庆石门公园*写于20120329

# 赏析
```
首联以"暖"字定调，春日午后慵懒和煦，"心融卧柳石"写身心化入自然之态，物我两忘。颔联以鼻闻湖气、耳听鸟鸣，调动嗅觉与听觉，体物入微——"湖吐气"将静态湖面拟为吞吐呼吸的生命体，想象奇警；"鸟争枝"以动写静，愈显春光喧闹。

颈联陡然一转，从眼前春色跃入永恒之问："春有重归日，人无再见时。"这组对比将自然之循环与人生之单向对举，看似平淡的陈述中蕴含深沉的伤感——年年春归如约，而故人远去不回。尾联"随风花且落，入水已成痴"以落花自喻，随风而逝、逐水而痴，将无常之悲化为意象之美。"痴"字尤妙，既是花痴，亦是人情痴。全诗由乐景入哀思，转折自然，情致深婉。
```
