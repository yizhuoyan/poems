# 《新韵·初见别后》

~~~
初见心如鼓，
强装是故人。
别时无恋恋，
归路有闲云。
~~~
>> 写于20120605

# 赏析
```
"初见心如鼓"，以鼓喻心跳，形象生动——初逢时那份紧张与悸动跃然纸上。"强装是故人"写故作镇定之态，明明心跳如擂，偏要装成老友重逢般从容，将一个少年在心上人面前的矜持与局促描摹得入木三分。

后两句写分别后的心理转折。"别时无恋恋"并非无情，而是刻意表现得洒脱；"归路有闲云"则在不经意间泄露了真实心境——归途之上看云卷云舒，步伐轻快、心境悠然，暗示初见之圆满与内心的雀跃。"闲云"二字既写实景，亦是心象，将那隐约的欢喜寄托于蓝天白云之间。全诗二十字，有初见之悸、伴装之涩、离别之淡、归途之悦，层层推进，收束于一片开阔与恬淡之中，意蕴丰沛而语言极简，深得五绝含蓄蕴藉之妙。
```
