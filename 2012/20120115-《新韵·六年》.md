
# 《新韵·六年》
~~~
偶尔得一算，
别君已六年。
往来多少事，
昨夜落窗前。
~~~
>> 写于20120115

# 赏析
```
这首小诗以"偶然"起笔，轻轻一笔便拉开了六年的时空纵深。"偶尔得一算"，看似漫不经心的一掐指，实则积压已久的情感在这一瞬间被唤醒。"别君已六年"，语气平淡如水，却有千钧之重——时光之流速与思念之绵长尽在此五字之中，无一字言愁，而愁绪已然漫溢。

后两句宕开一笔，从具体的"六年"延展至"往来多少事"，将个人离愁纳入更广阔的时空维度。收束于"昨夜落窗前"，以窗为镜，以夜为幕，将那些纷繁往事收拢到一个静谧的刹那。一个"落"字尤为传神——往事不是涌来、忆起，而是悄然落下，如叶、如雨、如月光，带着无声的重量落在窗前。整首诗由算及感、由远及近、由散及聚，结构精巧而毫无斧凿痕迹，深得绝句"起承转合"之妙。
```
