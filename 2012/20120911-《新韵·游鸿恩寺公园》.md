# 《新韵·游鸿恩寺公园》
~~~
初秋微雨里，一伞入山中。 
水洗千阶净，风吹万桂浓。
相依游大道，携手览高亭。
虽有惜别语，归时处处灯。
~~~

# 赏析
```
首联"初秋微雨里，一伞入山中"以极简之笔勾勒出游山画卷：微雨为幕，一伞之下两人同行，"入"字既写动态，亦暗示渐入佳境。颔联对仗工整，"水洗千阶净"写雨洗石阶之清润，"风吹万桂浓"写秋风送桂香之馥郁——视觉与嗅觉交叠，山水之清气与草木之芬芳扑面而来。

颈联连用两组动作，"相依游大道""携手览高亭"，以复沓笔法强化双人同游的亲密温馨。尾联"虽有惜别语，归时处处灯"最见功力：游兴虽浓终有别时，却以"处处灯"收束——万家灯火将离愁融化在温暖的夜色中，既有依依不舍之情，更有满载美好的圆满归途。全诗由雨入山、由景及情、由游及归，章法井然，情景两得。
```
