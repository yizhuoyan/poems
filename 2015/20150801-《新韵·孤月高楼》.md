# 《新韵·孤月高楼》
~~~
孤月高楼冷，
独酌永夜长。
秋风迎客面，
暖暖桂花香。
~~~
>> 写于20150801

# 赏析
```
"孤月高楼冷"起句便营造出清冷孤寂的氛围：高楼之上，孤月悬空，一个"冷"字将环境之寒与心境之寒融为一体。"独酌永夜长"写对月独饮，长夜漫漫无尽头，"永夜"将时间拉长，孤独在酒杯中发酵。

然而后两句笔锋一转——"秋风迎客面"以拟人手法写秋风仿佛一位知客，迎面而来；"暖暖桂花香"在前两句的冷寂中突然注入"暖"意，秋桂的馥郁芬芳拂过面庞，带来一阵出乎意料的温暖与慰藉。全诗前后形成冷暖对比的审美张力：冷的是月、楼、夜，暖的是风、桂香。独酌之人纵使孤寂，秋风与桂花却不请自来，以自然的温柔对抗人世的凉薄。短短二十字，有独处的清冷，亦有偶遇花香的小小慰藉，情致微妙动人。
```
