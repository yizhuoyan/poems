# 《新韵·犬吠》

```
犬吠出深巷，
清辉入破窗。
无情人万里，
灯下客双行。
```

# 赏析
```
"犬吠出深巷"以听觉切入，深巷中传来犬吠，以声写寂，愈显夜的幽深与空旷。"清辉入破窗"转视觉，清冷的月光穿过破损的窗棂——"破窗"暗示居所的简陋与独居的潦倒。一"出"一"入"，以声音和光线分别从内外两个方向穿透夜的空间。

后两句由景及人。"无情人万里"语带双关——既是说情人远在万里之外的无情，亦暗指远方的无情之人；"灯下客双行"写灯影之下，过客或行人都双双对对。两个意象一远一近、一独一双，形成刺目的对比：远方的"无情人"与灯下的"双行客"，都在反衬自身的孤身一人。全诗四句，前两句铺陈环境之寒，后两句直写心境之寒。语言冷峻克制，情感却不言自明。
```
