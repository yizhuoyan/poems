# 《新韵·小字初约》
~~~
小字初约后，
黄昏只二人。
相依山渐冷，
入夜月如今。
~~~
>> 写于20150514

# 赏析
```
"小字初约后"以含蓄之笔交代缘起——一封用小字写就的书信，开启了第一次相约。"小字"二字既有画面感（娟秀的笔迹），又透着私密的温情。"黄昏只二人"写相会的时间与状态，黄昏朦胧暧昧，天地间仿佛只剩下两个人的世界。

"相依山渐冷"写两人依偎之际，山色渐暗、寒意渐起，时间的流逝通过"渐冷"的体感来呈现；"入夜月如今"以月亮升起收束——夜幕降临，明月悬空，恰如此时此刻此景。"如今"二字将过去的那一夜与当下的阅读时刻贯通——那轮月亮，和现在看到的、想到的，是同一轮。全诗以"初约"到"入夜"为时间线，以山水月色为空间背景，情感含蓄而饱满，于无声处写出初恋的纯净与珍重。
```
