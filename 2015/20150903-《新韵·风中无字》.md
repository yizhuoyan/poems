# 《新韵·风中无字》
~~~
残照天如海，
白云望我长。
风中无一字，
何必入门窗？
~~~
>> 写于20150903

# 赏析
```
"残照天如海"以辽阔意象开篇，夕阳余晖映照的天空如大海般苍茫浩瀚，末日般的壮美。"白云望我长"以拟人之笔写白云久久凝望诗人——人与云对视，画面中有一种奇异的静默和孤独感，"望我长"三字尤为耐人寻味：是云在等我，还是我在看云？

后两句转向内心的叩问。"风中无一字"——风穿过天地却没有携带任何信息，世界对诗人沉默不语。"何必入门窗"以一个看似无理的问句收束：既然天地间没有一句话是给我的，那我又何必走进那门窗之内的人间？此问流露出诗人与世俗生活的疏离感，以及渴望与天地对话却不得的精神困境。全诗名为"风中无字"，实则字字都在风中写就。于无字处看到诗人最难言说的孤独。
```
