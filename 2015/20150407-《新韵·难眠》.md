# 《新韵·难眠》
~~~
长夜频空醒，
孤眠梦扰人。
日高方懒起，
对镜眼角痕。
~~~
>> 写于20150407

# 赏析
```
首句"长夜频空醒"连用"频"与"空"二字——"频"写夜醒次数之多，"空"写每次醒来面对的空虚，长夜漫漫，反复在孤独中惊醒，极具画面感。"孤眠梦扰人"进一步深化：不但睡不着，连仅有的睡眠也被乱梦侵扰，醒与睡都不得安宁。

后两句笔锋转到天明之后。"日高方懒起"写因一夜难眠而迟迟不起，"懒"字里藏着疲惫与消沉。末句"对镜眼角痕"看似冷静的观察，实则蕴含复杂的情绪——眼角细纹是岁月的痕迹，更是辗转难眠的身心印记。全诗以时间为序：长夜→空醒→乱梦→日高→对镜，将"难眠"从夜晚到次日清晨的全过程铺叙完整。不写一句愁，却句句是愁；不写一个情字，而眼角细纹已是无声的答案。
```
