#《新韵·念》
```
一方天地煎人寿，万古江河送水流。
但劝行云多带信，相思几许在渝州。
```

>> 年末夫人浙江出差，甚是想念而作。

# 赏析
```
这首思念之作以大时空起笔，却落脚于最私人的情感。"一方天地煎人寿"——"煎"字用得极其沉重，天地如同一口大锅，人的生命在其中被慢慢煎熬消耗，写出了身处有限空间中的焦灼感。"万古江河送水流"——万古不变的江河日复一日地送走流水，一如时间无情地流逝。前两句写天地之限与时间之迫，为后两句的思念布下了沉重的背景。

后两句笔锋一软——"但劝行云多带信"，将云拟作邮差，央求行云多带书信跨越山水送达爱人手中。"相思几许在渝州"以设问作结：我在这渝州城中，藏了多少相思？"几许"之问，不需要答案，因为思念原本就无从计量。篇末小注"年末夫人浙江出差，甚是想念而作"，点明了此诗的创作背景，更添真挚。前两句的苍茫与后两句的柔情形成了极大反差，张力十足。
```
