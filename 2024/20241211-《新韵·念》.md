#《新韵·念》
```
一方天地煎人寿，万古江河荡世愁。
谁劝行云莫再问，相思几许是杭州。
```

>> 岁暮，夫人赴浙江杭州公出，遥记相思。写于20241211

# 赏析
```
这首《新韵·念》为七言绝句，借岁暮别离、夫人赴杭公出之事，写出一种由个人相思扩展至人生愁绪的苍茫情怀。全诗以“寿、愁、州”押韵，音调悠长，与“相思”“岁暮”的情境相合。

首句“一方天地煎人寿”起笔沉郁。“一方天地”本可指眼前所处的小小空间，也可泛指人生所寄的一隅天地；“煎”字尤为警策，不说岁月流逝，而说天地“煎”人之寿，仿佛人在日常奔波、离合聚散中被光阴慢慢熬煮。一个“煎”字，既有生活的苦涩，也含有年岁渐长、岁暮易感的况味。

次句“万古江河荡世愁”由近而远、由个人而宇宙。“万古”对“一方”，“江河”对“天地”，“世愁”对“人寿”，境界顿然开阔。江河本是亘古流动之物，“荡”字写其波涛，也写其似欲冲刷人世愁苦而终究难尽。上句是人生在天地间受煎熬，下句则是愁绪随万古江河激荡；二句形成内敛与奔涌、微观与宏阔的对照。

“谁劝行云莫再问”笔意一转，由沉思转入对话。“行云”可实指远行之人，也可指漂泊的心绪、难以停驻的时光。一个“谁劝”，带有无人可问、无人能劝的怅惘；“莫再问”则像自我劝解，又分明是欲止不能。此句不直说“我思念你”，而以行云设喻，使离人之行踪与心绪之飘忽相互映照。

末句“相思几许是杭州”点出题旨，也点出地点。妙处在“是杭州”三字：杭州不只是夫人公出的目的地，更仿佛成了相思的归处、相思的尺度与相思的名字。前面铺陈的“人寿”“世愁”“行云”，至此都落到一个具体地名上，使宏阔的感慨回归私人情感；而正因有此前三句的蓄势，“杭州”二字便不只是地理坐标，而带上了浓重的情感温度。

全诗最可赏处，在于其结构上的“大入小、远归近”：起于天地、江河、万古，终于杭州、相思、一人；表面写别思，内里亦有岁暮之感、人生之叹。语言简洁而不直露，尤其“煎”“荡”“行云”“杭州”几个意象与动词，令诗意既苍茫又温柔。
```
