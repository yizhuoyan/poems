#《新韵·念》
```
一方天地系心舟，万古江河两处流。
来去行云焉可载？相思动月满渝州。
```

>> 岁暮，夫人赴浙江杭州公出，遥记相思。写于20241211

# 赏析
```
《新韵·念》赏析

这首诗写岁暮时节，夫人赴杭州公出，诗人独留渝州，遥寄相思。全诗不直言离愁，不铺陈思念之苦，而是以心舟、江河、行云、明月构成一幅辽阔而清寂的抒情图景。前两句写空间阻隔与心有所系，后两句由行云转向明月，让无形的相思最终化为照满渝州的月色。诗中既有天地江河的宏阔，也有夫妻分处两地的细腻情思，情景相融，含蓄而深远。

“一方天地系心舟，万古江河两处流。”首句以“心舟”喻心，将难以捉摸的情感化为可以系泊的舟船。“系”字尤其传神，既有牵系、系念之意，也有将舟系于一处、不愿远离的意味。身处渝州，心却因远行的夫人而有所牵挂，一字之中，既见心有所属，也见情有所依。“一方天地”写眼前所处的一方空间，而“万古江河”忽然将视野拓展到亘古不息的天地之间。“一方”与“两处”相对，“系”与“流”相映：一边是心有所系，一边是江河不息；一边是情感的牵挂，一边是现实的分隔。江河流经不同的地域，也仿佛将相思的两端牵连起来。两句不直接写杭州与重庆相隔遥远，却在天地与江河的对照中，写出了两地相望的空间距离，以及距离之中始终存在的情感联系。

“来去行云焉可载？”这一句由地上的江河转向天空的浮云，以问句写出相思无所寄托的感慨。行云自在来去，看似能够穿越山川、往返两地，却终究无法真正承载人的思念。“载”字承接首句的“舟”，又将诗意从心舟延伸到行云：心中有情，仿佛有舟欲行；眼前有云，似乎可以托付，却终究不能载情远去。行云能够来去，人却未必能够随心相聚；云可以飘过千山万水，却无法替人抵达所思念的那个人。一个反问，使眼前之景转化为心中之叹，也为结句的月色铺垫了情绪。

“相思动月满渝州。”结句最见想象之奇。“相思”本是无形无质的情感，诗人却赋予它撼动明月的力量。一个“动”字，使相思不再只是静静萦绕心头的思绪，而仿佛能够触动天上的月亮，令清辉洒满渝州。末三字“满渝州”则将视线从天际收回故地：诗人身在渝州，月光遍照全城，思念也仿佛随月色充盈天地。前句问行云能否载念，答案并未明说；结句却另辟蹊径，让相思不必借云传递，而直接化作月色，铺满自己所在的城市。云不能载情，月却因情而动，这一转折使结句既有浪漫的想象，也有动人的情意。夫人虽在杭州，诗中却不必明写远方的所在，因为真正需要呈现的，不是远方的景色，而是远方之人如何牵动眼前的一轮明月。

题为“念”，全诗也始终围绕这个字展开，却不着一字直接倾诉思念之苦。心舟有系，江河分流，行云难载，明月因情而动，四句层层递进，将相思从内心的牵挂推向天地间的景象。尤其“动月”二字，以情感改变景物，使结句有了超越写景本身的力量。全诗写的虽是一次短暂的分别，却在万古江河与渝州明月之间，写出了夫妻相思中那份绵长而坚定的牵系。
```
