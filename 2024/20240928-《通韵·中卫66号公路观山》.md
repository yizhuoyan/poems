# 《通韵·中卫66号公路观山》

```
连绵一片山，驰骋入长天。
风起无端处，鱼游亿载前。
列星接日夜，沧海易桑田。
渐渐云千里，悠悠人百年。
```

# 赏析
```
这首诗表面写中卫66号公路上的观山之景，实际上写的是眼前山河背后的亿万年时间。全诗最巧妙的地方，在于没有把“山、风、鱼、星、沧海、云、人”当作彼此孤立的景物，而是让这些意象共同构成一个从眼前到远古、从大地到星空、再从万古回到人的时间坐标。尤其“鱼游亿载前，沧海易桑田”并非泛泛使用“沧海桑田”的成语，而是立足于中卫这片土地本身：今日所见的山地，在遥远地质年代曾经处于海洋环境。于是眼前的山就不再只是山，而成为亿万年地质变迁留下来的现实见证。

一、“连绵一片山，驰骋入长天”：山势本身具有奔腾的生命力

“连绵一片山”首先写眼前的整体山势。

“连绵”把一座座山峰连接起来，使视野中的山不再是彼此独立的个体，而成为一条不断延展的山脉。“一片”又进一步扩大了这种整体感，仿佛目光所及尽是山。

第二句“驰骋入长天”则是全诗开头最有力量的一笔。

“驰骋”本来是极具主动性的动作，用来写山，使山由静景变成了动景。山仿佛正在大地上纵横奔行，一路向上、向远方延伸，最终“入长天”。

这里真正精彩的不是单纯的拟人，而是“驰骋”改变了山的存在方式。

如果只是写山高、山远，仍然停留在视觉描写；写“驰骋”，则让山本身具有了运动感和力量感。于是眼前这片山不是一块静止的背景，而像是正在向天地深处延伸的巨大存在。

而这一“驰骋”，也暗暗为后文打开了时间空间上的纵深。山既然仿佛能够驰向长天，那么诗歌的视野也不再局限于眼前这一刻，而可以继续向更辽阔的天地与更遥远的年代推进。

二、“风起无端处，鱼游亿载前”：从今天的风，追溯这片土地的远古海洋

第三句“风起无端处”把视线由山转向风。

“无端”很有意味。风从哪里来，似乎无法找到一个确定的起点。它没有一个可以被手指出来的源头，于是眼前的风天然带有一种无边无际的空间感。

但真正的构思关键在第四句：

“鱼游亿载前。”

这一句不能只理解成泛泛的“想到远古”。

结合中卫66号公路所在地区的地质背景，这里有明确的现实依据：今日所见的这片土地，在极其遥远的地质年代曾经处于海洋环境。于是诗人眼前看到的并不仅仅是一座今天的山，还可以透过这座山追溯它亿万年前的面貌。

因此，“鱼游”写的其实是这片土地曾经拥有的另一重身份。

今天这里是山，是陆地；
亿载以前，这里曾经是海；
今天眼前可以看见山势，想象中却可以追溯到鱼在这片土地所在之处游动的远古海洋。

这样，“鱼游亿载前”便不是虚构性的远古想象，而是现实地质历史在诗歌中的转化。

“鱼游”二字尤其好。

它没有使用“海存”“海在”这样的静态说法，而是写“游”。一个动作，把亿万年前的生命活动直接带到了眼前。仿佛时间虽然已经过去亿载，但那片古海中的鱼仍在诗句里运动。

而“亿载前”四字，则把眼前的山突然推向了极其遥远的过去。前一句还是“风起”的当下，下一句已经到了亿载以前，时间跨度骤然扩大。

三、“列星接日夜，沧海易桑田”：从天地运行写到大地变迁

第五句“列星接日夜”继续扩大视野。

“列星”使天空进入诗中。群星罗列，昼夜交替，天地仿佛始终处在不停的运行之中。

“接”字尤其传神。它写的不只是星辰存在于天空，而是把“日夜”理解为不断衔接、不断循环的过程。于是，前面的“亿载”不再只是一个遥远的过去，而开始呈现出天地时间连续不断的性质。

第六句“沧海易桑田”则重新落到大地。

放在这首诗的具体背景里，“沧海易桑田”尤其不能只当成惯用成语来解释。

因为第四句已经告诉读者：这片今日可见的山地，在遥远过去曾有海洋环境。“沧海易桑田”于是成为对这片土地真实变化的高度概括。

这里的“易”是全句的核心。

它把一个持续了极其漫长时间的地质过程压缩成一个极简的动词：海洋可以成为陆地，陆地又可以经历新的变迁。亿万年的大地演化，被浓缩成一个“易”字。

于是第四句与第六句实际上构成了全诗最完整的一组照应：

鱼游亿载前，是远古的海洋生命；
沧海易桑田，是亿万年后的天地变化。

一个“鱼游”让远古具体可感，一个“沧海易桑田”把这种变化提升到天地变迁的高度。

到这里，眼前的山已经不再是一处旅游景观，而像是一部被大地保存下来的时间史。

四、“渐渐云千里，悠悠人百年”：从亿万年回到人的一生

最后两句的语调明显缓下来。

“渐渐云千里”写云向远方舒展。

“渐渐”与开头“驰骋”形成鲜明反差。开头的山势奔腾而有力量，结尾的云却缓缓移动；前面是“驰骋”，这里是“渐渐”，全诗的节奏由动转缓。

“云千里”又与“长天”照应。

开头山“驰骋入长天”，结尾云“渐渐”行向千里，空间终于完全打开。到这里，山、天、云已经共同构成一个无限辽阔的天地背景。

最后一句“悠悠人百年”，才真正把视线收回人本身。

“百年”与前面的“亿载”形成最强烈的尺度对比。

亿载以前，鱼曾在这片土地所在之处游动；
亿万年间，沧海变成桑田；
列星运行，日夜相接；
而人的生命不过百年。

但诗句没有因此写成悲叹。

“悠悠”两个字非常重要。

它没有说人生“苦短”，也没有说百年“如梦”，而是以一种平静、舒展的语气接受人与天地之间巨大的时间尺度差异。

“悠悠”既写人的百年，也让人的百年获得了一种从容感。天地可以有亿载，人也有自己的百年。人的生命虽然短于山河岁月，却并不因此失去意义。

结语

这首诗的真正诗眼，不只是“驰骋”，也不只是“亿载”，而是眼前之山与亿万年之间建立起来的联系。“驰骋入长天”写今日山势的宏阔，“鱼游亿载前”则揭开这片土地的远古记忆，“沧海易桑田”进一步把这种真实的地质变迁化为诗意，而“人百年”最终把漫长天地重新折回人的生命尺度。

因此，诗题虽是“观山”，真正所观的却已经不是一座山，而是山中所藏的时间。眼前的山有亿载以前的海洋在其中，今日的人则只是天地长河中短短百年，却也正因此拥有了面对这万古山河、意识到自身存在的一刻。
```
