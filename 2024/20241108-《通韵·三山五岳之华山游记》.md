# 《通韵·三山五岳之华山游记》

```
兴起狂奔八百里，整装开赴四更天。
途中竟遇回程客，路侧还营商户摊。
黑影妖风撕木叶，寒阶铁链入黄泉。
慢攀崖缝灯忽灭，日照方惊万仞边。
```

>> 与妻友4人周五下班后重庆飞西安夜爬华山，凌晨2点到达山底开始攀爬，早上8点登顶北峰，体力所限，未到达其他三峰，坐西峰索道而下。写于20241108

# 赏析
```
这是一首充满现场感的夜爬华山纪行诗。"兴起狂奔八百里"起笔便见豪情——一时兴起便从重庆飞到西安夜爬华山，当代人的"说走就走"跃然纸上。"途中竟遇回程客，路侧还营商户摊"写夜爬之奇特体验——凌晨时分有人已下山而归，山路边的商户仍在营业，可见华山之热闹。

第三联写夜攀之险——"黑影妖风撕木叶"用"妖""撕"二字营造恐怖氛围，"寒阶铁链入黄泉"以"黄泉"形容深不见底的黑暗，既是实写华山千尺幢、百尺峡之险，也渲染了夜爬的心理感受。末联"慢攀崖缝灯忽灭，日照方惊万仞边"最为精彩——在狭窄崖缝中攀爬时头灯忽然熄灭，黑暗中摸索前行；待日出光照，才惊觉自己正悬于万仞绝壁之巅！从黑暗到光明的转换，将惊险与壮美一并呈现，读来令人心潮澎湃。
```
