# 《通韵·三山五岳之华山游记》

```
兴起狂奔八百里，整装直上四更天。
途中竟遇下山客，道左犹营贩水摊。
鬼影妖风撕木叶，危崖铁索探黄泉。
惊心石后灯倏灭，日照方知万仞边！

```

>> 与妻友4人周五下班后重庆飞西安夜爬华山，凌晨2点到达山底开始攀爬，早上8点登顶北峰，体力所限，未到达其他三峰，坐西峰索道而下。写于20241108

# 赏析
```
全诗以“夜爬”为线索，按时间顺序铺陈，从起兴出发到登顶惊魂，再到破晓顿悟，跌宕起伏，扣人心弦。

一、 整体格调与章法
全诗韵脚洪亮，契合华山险峻与攀登者豪迈的气质。结构上起承转合自然流畅：
首联叙事起兴，交代缘由；
颔联写途中见闻，以此衬托山之热闹；
颈联绘景造势，渲染夜爬之惊险；
尾联顿悟收束，于惊恐中见壮阔。
二、 逐联赏析
1. 首联：兴起狂奔八百里，整装直上四更天。
赏析： 开篇颇有豪侠气。“兴起”二字道出诗人随性洒脱的性格，“狂奔八百里”虽是夸张修辞，却也实写出从重庆到华山路途之遥与行程之急。对句“直上四更天”点明时间，夜半攀登，更显兴致之高。
点评： 一个“狂”字，一个“直”字，奠定了全诗昂扬向上的基调，读来有“说走就走”的快意。
2. 颔联：途中竟遇下山客，道左犹营贩水摊。
赏析： 此联转入细节描写，对仗工整（“途中”对“道左”，“遇”对“营”）。诗人夜爬本以为是孤独的探险，却意外发现“下山客”与“贩水摊”。这一景象侧面烘托了华山作为名岳的繁华——即便在深夜，登山者亦络绎不绝，山中商业气息亦存。
点评： “竟遇”二字写出了诗人的意外之感，也为后文的惊险气氛做了一层反衬：前半段尚有人间烟火气，后半段则是惊心动魄的自然险途。
3. 颈联：鬼影妖风撕木叶，危崖铁索探黄泉。
赏析： 此联乃全诗警句，极力渲染夜间华山的阴森与险峻。诗人运用拟人手法，“鬼影妖风”本是夜色中风动树摇之景，用一“撕”字，顿觉风力之劲、声音之凄厉，令人不寒而栗。下句“危崖铁索探黄泉”更是将视觉引向深渊，“探”字极具动感，仿佛铁索如触手般探入冥界，极言其高与险。
点评： 用词炼字功夫了得。“撕”字有力，“探”字传神。将夜爬的心理恐惧外化为具体的意象，读来让人手心出汗，身临其境。
4. 尾联：惊心石后灯倏灭，日照方知万仞边！
赏析： 尾联极具戏剧张力。前句“灯倏灭”制造了瞬间的黑暗与惊恐，配合“惊心石”，将紧张氛围推向高潮。然而笔锋一转，“日照”破晓，豁然开朗。最后一句“方知万仞边”是全诗的点睛之笔：原来昨晚在黑暗中摸索攀爬，不知身在何处，待到天亮一看，才知自己竟身处万仞绝壁之侧！
点评： 这种“先险后壮”的处理手法非常巧妙。如果是白天攀登，看到万仞绝壁或许不敢迈步；正是黑夜遮蔽了视觉的恐惧，才成就了登顶的壮举。结尾既写出了华山的雄奇，也寓含了“无畏前行，方见真章”的哲理。
三、 总结点评
这首七律不仅是一篇优秀的游记诗，更是一幅生动的夜行图。
炼字精准： 如“撕”木叶、“探”黄泉，字字珠玑，极具表现力。
氛围营造极佳： 从热闹的贩水摊瞬间切换到阴森的妖风鬼影，最后以壮丽的日照收尾，情绪节奏掌控得当。
意境深远： 结尾的“方知”二字，包含了登山者的后怕与自豪，余味悠长。

```
