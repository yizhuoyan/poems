# 《新韵·再游钓鱼城》

```
岁月易消人易老，楼台长望水长东。
昔时戏览石墙上，檑砲枪叉弩与弓。
今日深思荒土下，儿孙夫父弟和兄。
千年万载兴亡替，白骨生民名姓空！
```
>> 写于20240120

# 赏析
```

《新韵·再游钓鱼城》是一首借重游古战场遗址，感悟人生易逝、历史兴亡与生民命运的怀古诗。诗人从岁月流逝、江水东去写起，由昔日观览城墙兵器的轻松心态，转向今日对战争遗迹的深沉思索，最终将目光投向千年兴亡之中的白骨与生民，感叹无论死者还是生者，都可能在漫长的历史中失去姓名。全诗由个人感怀到历史追问，再到对人类共同命运的思考，情感层层深入，体现了诗人对战争、生命与历史记忆的深刻感悟。

首联“岁月易消人易老，楼台长望水长东”，以人生短暂与江水长流构成鲜明对照。“岁月易消”写时光流逝，“人易老”写生命衰变；“楼台长望”与“水长东”则将视线引向眼前的古城与东流之水。两个“易”字，表现人生的短促与无常；两个“长”字，则写出江水奔流、岁月绵延的恒常感。楼台虽历经兴替而留存，江水仍自顾东流，身处其间的人却终究难逃衰老。诗人由重游引发的感触，既是对自身年华的感叹，也是对古城所承载的漫长历史的感知，为全诗奠定了苍凉而深沉的基调。

颔联“昔时戏览石墙上，檑砲枪叉弩与弓”，将笔锋转向古城遗存。钓鱼城因南宋末年的宋蒙战争而闻名，城墙及其军事遗迹见证着当年激烈的攻防。诗人回忆昔日游览时，曾以较为轻松的心态观赏墙上的檑、砲、枪、叉、弩、弓等兵器。“戏览”二字尤其值得注意：它与后面的“深思”形成鲜明对照，写出诗人两次游览之间的心境变化。昔日所见，或许只是古迹的形制与战争的痕迹；今日重游，眼前的兵器却使诗人进一步思索它们曾经指向的生命代价。古迹没有改变，改变的是观者对历史的认识。诗人不再止于观看兵器，而是开始追问兵器背后的人，以及战争结束之后留下的命运。

颈联“今日深思荒土下，儿孙夫父弟和兄”，既是全诗的思想转折，也是理解全诗结构的关键。前句的“昔时戏览石墙上”与此句的“今日深思荒土下”，构成今昔相对：一边是过去的观览，一边是今日的沉思；一边是地面之上的城墙与兵器，一边是荒土之下可能埋藏的累累白骨。视线由墙上转向地下，诗人的思考也由战争的外在遗迹深入到战争中的生命。

“儿孙夫父弟和兄”则将抽象的战争伤亡还原为具体的人伦关系。那些埋骨荒土的人，曾经是别人的儿孙、丈夫、父亲、兄弟；他们并不是与人世毫无关联的无名躯体，而是各自家庭中不可替代的亲人。一个人死去，不只是一个生命的消失，也意味着某个家庭失去儿子、丈夫、父亲或兄弟。诗人没有直接铺写战场的血腥，而是以亲属身份的罗列，让读者看到白骨背后曾经存在的亲情、责任与生活。由此，怀古不再仅仅是对战争往事的追忆，而成为对战争中普通人的命运与生命价值的深切体恤。

这一联与前后句之间，还存在值得特别指出的扇面对结构。扇面对又称隔句对，基本形式是四句中第一句与第三句相对、第二句与第四句相对。诗中的“昔时戏览石墙上”与“今日深思荒土下”相互呼应，“檑砲枪叉弩与弓”与“儿孙夫父弟和兄”则构成另一组跨句对应。

这两组对应不仅是形式上的安排，更承载着全诗重要的思想转换。第一组以“昔时”对“今日”，以“戏览”对“深思”，以“石墙上”对“荒土下”，写出时间、心境与空间视角的多重变化。第二组则以兵器对亲属，以战争的工具对人间的亲情关系：檑、砲、枪、叉、弩、弓，代表着战争的物质与武力；儿、孙、夫、父、弟、兄，则代表着普通人的身份、亲情与人伦。兵器曾经陈列于城墙之上，而它们所关联的生命，可能早已埋入荒土之下。两组对应相互映照，使城墙上的战争遗物与荒土下的人伦悲剧建立起深刻联系。诗人不只是由兵器想到死亡，更是由战争之物想到战争之人。扇面对的结构因此与诗意融为一体，推动全诗从观看历史走向理解生命。

尾联“千年万载兴亡替，白骨生民名姓空”，将前面的思考提升至更广阔的历史层面。“千年万载”写时间之悠远，“兴亡替”揭示历史中朝代更迭、盛衰相继的循环。无论战争发生于何时，无论胜败双方曾经拥有怎样的志向、荣耀与功业，都无法阻止岁月继续流转。历史不断更替，而身处其中的无数普通人，终究可能被时间淹没。

尤其需要注意的是，“白骨”与“生民”在这里是并列的两个对象，“名姓空”则共同落在二者身上。它并非单纯感叹死者化为白骨之后无人知晓姓名，而是将死者与生者同时纳入历史的无常之中：白骨已经失去生命，其姓名也可能无从考证；生民虽然仍在世间生活，在千年万载的兴亡更替面前，也未必能够留下姓名、事迹与踪影。死亡固然使个体消逝，然而即使活着，也不意味着能够被历史记住。这里的“空”，不仅指肉身消亡，更指个人姓名与生命痕迹在漫长历史中的湮没。

如此理解，“白骨生民名姓空”便不仅是悼念死者，也是对历史书写与个体存在的深沉追问。王朝的兴亡可以成为史书中的篇章，将帅的功过也可能被后人反复评说，但组成历史的无数普通人，却往往无法留下姓名。他们曾经活过，有自己的家庭、亲人和人生，却可能在历史的长河中不留痕迹。诗人将“白骨”与“生民”并举，正是把这种被历史消隐的处境从死者扩展至生者，使全诗的感叹由战争伤亡进一步深化为对所有普通人生存与记忆命运的思考。

从整体结构看，全诗的推进十分清晰。首联写人生易老、江水长流，建立起时间与生命的对照；颔联追忆昔日观览兵器的情景；颈联借扇面对照昔日与今日、兵器与亲属，将思想引向战争中的生命代价；尾联再从死者与生者共同面对的姓名湮没，推及千年万载的历史兴亡。尤其是中间四句，形式上的隔句相对与意义上的层层深入相互配合，成为全诗由景入史、由史及人的核心部分。

《新韵·再游钓鱼城》的深意，不止于感慨人生短暂，也不止于凭吊古战场中的亡者，而是借古城遗迹反思战争与历史：兵器曾经彰显战争的激烈，亲属关系则揭示每一个生命背后的人间牵挂；而当千年万载的兴亡相继过去，死者化为白骨，生者也可能无名，个体的姓名与生命痕迹终究难敌历史的消磨。诗人重游钓鱼城，最终看到的已不只是古城的军事遗存，而是战争与时间之下共同的生民命运。全诗以“白骨生民名姓空”作结，意境苍茫，感慨深沉，既有怀古诗对兴亡无常的传统体悟，也有对普通人生存价值与历史记忆的深切关怀。
```
