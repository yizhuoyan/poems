# 《新韵·再游钓鱼城》

```
岁月易消人易老，楼台长望水长东。
昔时戏览石墙上，檑砲枪叉弩与弓。
今日深思荒土下，儿孙夫父弟和兄。
千年以降无中外，百姓从来名姓空！
```
>> 写于20240120

# 赏析
```
一、 整体意境与情感递进
首联：“岁月易消人易老，楼台长望水长东。”
开篇即奠定苍凉悲壮的基调。两个“易”字道出人生须臾，两个“长”字写出自然永恒。登楼远眺，嘉陵江水奔流不息，与钓鱼城千秋凛然的历史形成映照。个人的渺小与历史的厚重在此刻碰撞，引出下文对古战场的追忆。

颔联与颈联：“昔时戏览石墙上……今日深思荒土下……”
这四句是全诗的核心，诗人将昔日游客般“戏览”兵器的心态，与今日“深思”荒土下亡魂的沉重进行对比。钓鱼城曾阻挡横扫欧亚的蒙古铁骑36年，蒙哥汗命丧城下，32位守将自刎殉节。诗人不再着眼于宏大的“独钓中原”史诗，而是将目光投向了战争中最残酷的代价——无数家庭的破碎与平民的牺牲。

尾联：“千年以降无中外，百姓从来名姓空！”
结句如洪钟大吕，振聋发聩。“无中外”三字将钓鱼城之战从单一的宋元政权更迭，扩展为整个人类历史上放之四海而皆准的战争悲剧。王侯将相或许名留青史，但真正填满“荒土”的，是那些无名无姓的“儿孙夫父弟和兄”。这两句拔高了全诗的立意，充满了超越时代的悲悯情怀。

二、 对仗艺术深度赏析
本诗在格律对仗上极具匠心，尤其是颔联与颈联并未采用传统的“各自为对”（即颔联上下句对仗、颈联上下句对仗），而是采用了古典诗词中高级的**“扇面对”（又称隔句对）与“句内自对”**相结合的复合对仗结构。

1. 绝妙的“扇面对”结构
诗人将颔联与颈联作为一个整体进行跨联对仗，即第一句对第三句，第二句对第四句：

第一组对仗（时间、动作与空间）：

昔时戏览石墙上（句3） ↔ 今日深思荒土下（句5）
词性分析：“昔时”对“今日”（时间名词对举）；“戏览”对“深思”（副词+动词，心态对比）；“石墙”对“荒土”（名词，战场遗迹对战后坟茔）；“上”对“下”（方位词）。
艺术效果：通过时空与心态的错位，展现了诗人认知境界的升华。墙上的兵器是冷冰冰的展品，而土下的亡魂才是沉重的历史。
第二组对仗（物象与人伦）：

檑砲枪叉弩与弓（句4） ↔ 儿孙夫父弟和兄（句6）
词性分析：句中“檑、砲、枪、叉、弩、弓”皆为古代兵器（名词）；“儿、孙、夫、父、弟、兄”皆为家庭人伦称谓（名词）。“与”对“和”为连词。
艺术效果：这是全诗最惊艳的一组对仗。七个冰冷的杀器，对应七个温暖的血亲。兵器的堆砌越密集，越显出战争的残酷；而每一个称谓背后，都是一个被战争撕裂的家庭。这组对仗以极度工整的形式，呈现了极度残酷的内涵。
2. 精工的“句内自对”与“叠字呼应”
除了跨联的扇面对，全诗在句法和字词的呼应上也极为讲究：

句内自对：
“檑砲枪叉”与“弩与弓”在句内形成两组兵器的自对；
“儿孙夫父”与“弟和兄”在句内形成两组人伦的自对。
这种节奏感极大地增强了列举的压迫感，仿佛战死者层层叠叠，不计其数。

首尾的叠字呼应：
首联“岁月易消人易老，楼台长望水长东”，用“易……易……”与“长……长……”的复沓句式，营造出时光流逝的无可奈何。
尾联“千年以降无中外，百姓从来名姓空”，虽未用叠字，但“无”与“空”在语义上形成强烈的虚空感，与首联的“易消”首尾呼应，让整首诗笼罩在一种苍茫的历史虚无感与悲悯感之中。

总结
这首诗最大的成功在于“以小见大，以器写人”。在对仗上，诗人打破了常规中二联的对仗模式，用扇面对将“兵器”与“人伦”强行并置，形式上的工整与内容上的撕裂产生了巨大的张力。诗人游钓鱼城，不写帝王将相的丰功伟绩，独写荒土之下无名的“弟和兄”，展现了极高的格局与深沉的人文关怀。
```
