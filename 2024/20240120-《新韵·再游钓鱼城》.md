# 《新韵·再游钓鱼城》

```
岁月易消人易老，楼台长望水长东。
昔时遍览石墙上，船炮城楼箭与弓。
今日细思荒土下，儿孙夫父弟和兄。
千年以降史年里，百姓从来名姓空！
```

# 赏析
```
钓鱼城是南宋抗蒙的历史名城，此诗为故地重游之作。首联以岁月与江水的永恒对比人事的易逝——"岁月易消人易老，楼台长望水长东"，连用两个"易"与两个"长"，形成生命短暂与自然永恒的强烈对照。

中间两联以"昔时"与"今日"对举：昔时游览看到的是城墙上的船炮箭弓等战争遗迹，那是宏大叙事中的历史；而今日细思荒土之下埋着的，是无数"儿孙夫父弟和兄"——是活生生的普通人，是某个家庭的父亲、兄弟、儿子。这种从"物"到"人"的视角转换，使全诗的情感骤然沉重起来。尾联"千年以降史年里，百姓从来名姓空"是振聋发聩的慨叹——千年史册中，普通人的名字从未留下过痕迹。全诗借钓鱼城之游，发出了对战争中无名者的深切悲悯。
```
