# 《新韵·再游钓鱼城》

```
岁月易消人易老，楼台长望水长东。
昔时戏览石墙上，檑砲枪叉弩与弓。
今日深思荒土下，儿孙夫父弟和兄。
千年万载兴亡替，白骨生民名姓空！
```
>> 写于20240120

# 赏析
```
这首《再游钓鱼城》是一首情感沉郁、立意深刻的怀古之作。全诗以“再游”的视角切入，将个人的生命感悟与沉重的历史沧桑感交织在一起，没有停留在对钓鱼城抗蒙历史的简单歌颂上，而是将笔触探入到战争背后无数普通百姓的命运之中，极具悲悯情怀与批判精神。


一、 整体意境与情感脉络赏析
首联：“岁月易消人易老，楼台长望水长东。” 起笔即写时间与空间的宏大与无奈。“易消”“易老”写人生之短暂，“长望”“长东”写自然之永恒。诗人站在钓鱼城的楼台之上，望着滚滚东流的嘉陵江，个人的迟暮之感与历史的沧桑之叹融为一体，奠定了全诗苍凉沉郁的基调。
颔联与颈联： 这是全诗的核心部分，通过今昔、物我的对比，展现了战争残酷的本质（下文详述）。
尾联：“千年万载兴亡替，白骨生民名姓空！” 结句如洪钟大吕，振聋发聩。诗人跳出了钓鱼城的具体史实，上升到对整个人类历史规律的哲学反思。“兴亡替”是帝王将相的博弈，而代价却是“白骨生民”。千载之后，王朝的更迭化为史书上的寥寥数语，而无数为此付出生命的普通百姓，连名字都未曾留下。一个“空”字，道尽了底层人民在历史洪流中的悲剧命运，力透纸背。
二、 对仗角度的深度赏析（全诗的匠心所在）
这首诗在结构上最出彩的地方，在于其打破常规的“扇面对”（隔句对），以及颔联、颈联内部精妙的句内自对与词性工对。

1. 绝妙的“扇面对”（隔句对）
在传统的七律中，通常是颔联上下句相对（第三句对第四句），颈联上下句相对（第五句对第六句）。但这首诗却运用了高难度的**“扇面对”（又称隔句对），即第一句对第三句，第二句对第四句**：

第一句（颔联上）：昔时戏览石墙上
第三句（颈联上）：今日深思荒土下
这两句形成了完美的工对：
*   时间对：“昔时” 对 “今日”
*   状态对：“戏览”（带着游客的轻松心态游览） 对 “深思”（怀着沉重的心情反思）
*   动作对：“览” 对 “思”
*   事物对：“石墙”（坚固的军事防御工事） 对 “荒土”（掩埋死者的荒野黄土）
*   方位对：“上” 对 “下”

第二句（颔联下）：檑砲枪叉弩与弓
第四句（颈联下）：儿孙夫父弟和兄
这两句同样形成了极具震撼力的工对：
*   名词列锦：“檑、砲、枪、叉、弩、弓” 对 “儿、孙、夫、父、弟、兄”。全是名词叠列。
*   连词相对：“与” 对 “和”。
*   意象对立：上句是杀人的武器，下句是活人的亲情。

2. “扇面对”带来的艺术张力
诗人为什么要采用这种隔句对的复杂结构？

如果按常规对仗，写成“昔时戏览石墙上，今日深思荒土下”和“檑砲枪叉弩与弓，儿孙夫父弟和兄”，虽然也对仗，但气势和情感的冲击力会大打折扣。

采用扇面对后，诗人将**“昔时的空间（墙上）”与“今日的空间（土下）”相对，将“冰冷的兵器”与“鲜活的性命”相对。这种错综复杂的对仗结构，产生了一种强烈的时空交错感和命运荒诞感**：

当年游客在石墙上把玩的“檑砲枪叉弩与弓”，其下面掩盖的、其历史上真正吞噬的，正是荒土之下的“儿孙夫父弟和兄”。墙上的杀器越锋利，土下的白骨就越众多；墙上的游览越轻松，土下的深思就越沉重。

这种对仗不仅仅是文字游戏，而是服务于思想表达的利器。它将“物（兵器）”与“人（百姓）”并置，深刻地揭示了战争的残酷本质：历史上的每一次攻防、每一次兴亡，无非都是用“檑砲枪叉弩与弓”去绞杀“儿孙夫父弟和兄”。

3. 首尾的呼应与对仗元素
除了中间两联的扇面对，首尾两联也蕴含着对仗的因子：

首联“岁月易消人易老”中有“岁月”与“人”的隐对，“易消”与“易老”的句内自对。
尾联“千年万载”对“白骨生民”，虽然不是严格的工对，但“千年万载”（帝王视角的宏大时间）与“白骨生民”（底层视角的微小空间）形成了强烈的意象反差，与中间两联的对仗遥相呼应。
三、 总结
《再游钓鱼城》是一首兼具形式美与思想深度的佳作。诗人巧妙地运用了**“扇面对”**这一特殊对仗手法，打破了常规的阅读预期，使得“昔”与“今”、“上”与“下”、“兵器”与“人命”在错综的结构中产生了剧烈的碰撞。

全诗不写钓鱼城之战的具体壮烈，却写出了所有战争背后的终极悲剧。在“名姓空”的叹息中，这首诗超越了普通的怀古诗，成为了一曲哀悼苍生、反思历史暴力的千古悲歌。
```
