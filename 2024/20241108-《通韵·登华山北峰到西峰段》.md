# 《通韵·登华山北峰到西峰段》

```
金锁关前留万锁，苍龙岭上踏千秋。
此身忽感寄天地，大美山河撞泪流。
```
![](images/huashan.jpg)

# 赏析
```
这首七绝以华山上两处著名险隘——金锁关与苍龙岭为背景，写登临绝顶时的心灵震撼。"金锁关前留万锁"——金锁关上层层叠叠的同心锁是无数游人对爱情与愿望的寄托，一个"留"字既写实景，也暗含了人世情感的累积与沉积。"苍龙岭上踏千秋"——苍龙岭如龙脊般狭窄险峻，行走其上，脚下是千年风雨侵蚀的岩脊，"踏千秋"将个人的一步与千年的地质时间重合，时空感陡然放大。

后两句由景入情："此身忽感寄天地"——在华山之巅忽然感到自身不过是天地间短暂寄居的过客，有一种庄子"天地者，万物之逆旅"的旷达与渺小；"大美山河撞泪流"——"撞"字极有力，山河之美不是慢慢沁入，而是猛地撞击心扉，令人热泪盈眶。全诗由景到心、由外到内，写尽了面对壮丽山河时那种难以言表的感动。
```
