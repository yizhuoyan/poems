# 《通韵·七夕与妻徒步》

```
周六七夕日，秋高徒步天。
已行十几里，似过九重山。
薄雾连高木，微寒透汗衫。
沿途松果落，隔叶鸟声闲。

山隐道明寺，始修洪武年。
僧人八九位，房殿六七间。
素食无标价，多少随客缘。
酸梅消暑水，遍赠不言钱。

再向天坑去，翻山过草田。
日中白路烫，坑内碧空圆。
满座公车挤，身疲过道眠。
归家无不适，次日腿皆残
```
>> 此事颇趣，留诗以记写于20240810

# 赏析
```
这是一首以叙事笔法写成的纪游诗，记录了七夕节与妻子徒步郊游的全过程。全诗分为三段，层次清晰。

第一段写山中徒步：秋高气爽、薄雾微寒，"已行十几里，似过九重山"以夸张写长途跋涉之感，松果落、鸟声闲两处细节写出了山间幽静的自然气息。

第二段至道明寺："僧人八九位，房殿六七间"用数字勾勒寺庙的简朴，而素食随缘布施、酸梅汤免费赠客的细节，则写出山中僧人的古道热肠，令人心暖。

第三段下天坑、归途："日中白路烫"写正午炎热，"坑内碧空圆"写天坑奇观。末二句"归家无不适，次日腿皆残"以自嘲口吻收束，用幽默化解一路的疲惫，让人忍俊不禁。全诗以游记散文式的章法入诗，叙事详尽、细节生动、语言轻松，将一次平凡的徒步写得妙趣横生，而夫妻同游的温情也在字里行间自然流露。
```
