#《新韵·2024中元赏月》

```
正是清凉夜，当然赏月中。
蝉林吹喜乐，蛙地闹年丰。
虽有万千寿，偏娇此刻情。
古今秋月客，共尽酒一盅。
```

# 赏析
```
中元节在传统认知中是"鬼节"，此诗却写月夜的清凉喜乐，跳出俗见，别具一格。首联"正是清凉夜，当然赏月中"以轻松自然的口气直入主题——"当然"二字带着一种理所当然的坦然，月如此美，为何不赏？

颔联写秋夜之声景："蝉林吹喜乐"拟蝉鸣为吹奏喜乐，"蛙地闹年丰"拟蛙声为庆贺丰年——蝉与蛙皆以拟人手法赋予喜庆色彩，使中元之夜充满了人间烟火的欢悦，而非常见的阴森。颈联"虽有万千寿，偏娇此刻情"将瞬间的感受置于生命的长期语境中——纵有漫长岁月，此时此刻的情感最是珍贵。尾联"古今秋月客，共尽酒一盅"举杯邀古人，与历代所有中秋望月之人共饮一杯，将个人的情怀融入亘古的月色之中。全诗以乐写节，通篇洋溢着赏月饮酒的畅快，在中元题材中独树一帜。
```
