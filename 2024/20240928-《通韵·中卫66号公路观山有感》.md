# 《通韵·中卫66号公路观山有感》

```
连绵一片山，驰骋入长天。
风起无端处，鱼游亿载前。
列星接日夜，沧海易桑田。
渐渐云千里，悠悠人百年。
```

# 赏析
```
此诗写驾车行驶在西北公路上的所见所感，格局宏大，哲思深远。首联"连绵一片山，驰骋入长天"以"驰骋"二字兼写车行与山势——车在飞驰，山峦也仿佛在天地间奔腾。"起"句"风起无端处"写西北旷野中不知从何处吹来的长风，苍茫无际；"鱼游亿载前"笔锋突转——眼前的群山在亿万年前曾是汪洋，鱼群就在此处游弋。以地质时间切入，极具张力。

颈联"列星接日夜"写星辰日夜轮转，"沧海易桑田"化用典故，将宇宙变迁浓缩为六个字。尾联"渐渐云千里，悠悠人百年"以两组叠词收束——云是千里绵延的"渐渐"，人是百年须臾的"悠悠"，云之悠长与人之短暂形成对照，与前文"鱼游亿载"遥相呼应。全诗以极短的篇幅，容纳了天、地、山、海、星、云、人，在时空的双重维度中展开，是一首气象万千的纪游佳作。
```
