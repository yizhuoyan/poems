# 《新韵·观荷》 

```
一池香淡当风近，
几朵娇羞见我欢。
闭眼深吸莲叶上，
开心飞入彩云间。
```
>> 写于20210716

# 赏析
```
这首观荷诗一反传统咏荷的孤高清冷之调，充满了明快的喜悦与天真的趣味。"一池香淡当风近"——微风拂过，一池淡淡的荷香随风飘近，"淡"字把握住了荷香清幽不过分浓郁的特色。"几朵娇羞见我欢"以拟人手法写荷花——几朵盛开的荷花宛如害羞的少女，见到诗人竟流露出欢喜之情，赋予荷花以人的情感与神态。

后两句写诗人自身的愉悦反应："闭眼深吸莲叶上"——闭上双眼，俯身贴近莲叶深深呼吸，将荷香尽情纳入肺腑；"开心飞入彩云间"——这份畅快让心绪如飞鸟般直入彩云之巅。前一句的动作刻画真实而投入，后一句则以夸张的手法将内心的欢喜推向极致。全诗语言清新明快，诗人与荷花之间形成了一种亲切的互动，人与自然的和谐交融跃然纸上。
```
