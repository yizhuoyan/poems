# 《新韵·七年无痒》
```
七载烟云一瞬间，
三生缘定又何年？
从来寂寞千秋事，
得遇佳人只羡仙。
```

>> 谨以此诗送给我亲爱的夫人。

# 赏析
```
诗题"七年无痒"化用"七年之痒"的俗语而反其意用之——走过七年婚姻，非但不痒，反而情深意笃，立意已然动人。首句"七载烟云一瞬间"以"烟云"喻岁月飘忽，七年光阴快如弹指，有"逝者如斯"的慨叹。

次句"三生缘定又何年"以"三生"的佛家轮回概念与之对举——七年在人间已是漫长，在三生石上却不知是哪一世注定的姻缘。第三句"从来寂寞千秋事"宕开一笔——自古以来，寂寞便是贯穿千年的永恒主题。末句"得遇佳人只羡仙"化用"只羡鸳鸯不羡仙"之典而翻新：红尘中遇见了你，连天上的神仙都变得令人羡慕。全诗由时间的短暂感慨到缘分的深远追寻，再落到人间烟火的温暖归宿，情感层层递进。附注"谨以此诗送给我亲爱的夫人"，更显情真意切。
```
