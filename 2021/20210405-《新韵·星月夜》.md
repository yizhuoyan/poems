# 《新韵·夜月夜》
```
迢迢星夜月中天， 
草木一秋人百年。 
多少不甘黄土下， 
无名无姓正长眠。
```
>> 写于20210405

# 赏析
```
《星月夜》是一首表面写星月秋夜，实则感叹人生短暂、生命无常与芸芸众生最终归于无名的五言绝句。全诗由天地之远写到草木之秋，由草木写到人生，再由人生写到那些带着“不甘”而归于黄土的无名者，视野逐层收拢，情绪也由清冷渐入苍凉。尤其结尾“不甘”与“无名无姓”的强烈反差，使这首诗超越了一般的伤秋叹老，而触及了普通生命被时间湮没的深层悲凉。

“迢迢星夜月中天”起笔极为开阔。“迢迢”写夜空的遥远无际，“月中天”写月悬高天的澄澈静寂。星月所代表的，是一种远远超越人的生命尺度的宇宙时间。人在这样的夜空之下，天然显得短暂而渺小。首句看似只是写景，其实已经悄然埋下了全诗关于人生的感喟。

“草木一秋人百年”紧承上句，以草木与人生对照。“草木一秋”是自然生命的一次荣枯，“人百年”则是一生的长度。看似一秋与百年相去甚远，但放在无尽的星月长夜之前，二者其实都不过是短暂一瞬。“秋”因此也不再只是季节，更成为生命由盛而衰、终归消歇的象征。这一句看似平淡，却把“物之短”与“人之短”并置起来，使前两句形成一种宏阔而清冷的生命意识。

第三句“多少不甘黄土下”是全诗情感真正下沉之处。“多少”二字使笔触由抽象的“人”落到无数具体而又无法辨认的生命。“不甘”更是全诗最有力量的情感字眼。它意味着这些人并非无欲无求地离去，而是曾经有过理想、愿望、执念和未竟之事，只是最终都被死亡截断。这里的“黄土”并不仅仅是坟墓的代称，它还意味着生命最后不可逃避的归宿。一个“下”字，把“人百年”的人生长河骤然压进地下，形成极强的沉坠感。

而“多少不甘”与末句“无名无姓”之间，存在着极深的反差。活着的时候，人有自己的愿望，有自己的故事，甚至有很多“不甘”；死去以后，却可能连这个人的名字、姓氏和曾经存在过的痕迹都无人知晓。“不甘”写的是生命曾经有过的重量，“无名无姓”写的却是这种生命最终可能留下的空无。于是诗真正悲凉的地方，不仅是“人会死”，而是很多人怀着未竟的人生离去，甚至连他们曾经“不甘”过，都没有人能够见证。

“无名无姓正长眠”因此成为全诗最沉的一笔。“无名无姓”并非简单地把同一个意思重复两次。“名”偏于一个人的个体身份和社会记忆，“姓”又牵涉血缘、家族与来处。名与姓并举，实际上是从个人与家族两个层面同时写“无所辨认、无所系属”。它与上一句的“多少”遥相呼应：正因为是芸芸众生中的“多少人”，最终才更容易湮没于时间深处，连姓名都不为人所知。

其中“正”字尤为传神。它并不只是“正在”的语法虚词，而具有一种极强的现场感和确认感。仿佛诗人在仰望星月之时意识到：就在此刻，世间正有无数曾经心怀不甘的人，已经沉入黄土，默默长眠。“正”使“不甘”与“长眠”同时成立——他们不是释然之后才长眠，而是带着曾经的不甘，正在长久的沉寂之中。于是“心有不甘，身已长眠”便成为全诗最锋利的情感张力。

“正长眠”也因此不同于“已长眠”或“永长眠”。“已”强调事情已经发生，“永”强调死亡的永恒，而“正”则把镜头凝固在此时此刻，让这种无人知晓的死亡具有一种正在发生的现实感。星月仍在，草木仍会一秋一秋地荣枯，人间仍然往来不息，而那些无名无姓的人，却正在黄土之下沉沉长眠。天地如此辽阔，人生如此短暂，个体如此不甘，而最终又如此寂静。

全诗最大的力量，正在于它没有直接议论人生苦短，也没有刻意渲染死亡，而是先写星月之远，再写草木之秋，继而写人的百年，最后落到“多少不甘”与“无名无姓”。从宇宙到生命，从生命到众生，从众生到被遗忘的人，层层深入。结尾看似平静，实则将前面所有的苍凉都压进“正长眠”三个字里。

《星月夜》写的并不只是“人生无常”，更是那些曾经认真活过、曾经心有不甘，却最终无名无姓地消失于岁月中的普通人。星月长明，而人生不过百年；人有万般不甘，终归黄土长眠。这种以极静之景写极深之悲的方式，使全诗具有一种克制而悠长的苍凉。
```
