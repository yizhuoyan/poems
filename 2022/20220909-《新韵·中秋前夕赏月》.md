#《新韵·中秋前夕赏月》
​
```
​十四已圆十五月，
中秋将至躲云遮。
将来过去万千夜，
天上人间独一颗。
```

>> 写给亲爱的夫人写于20220909

# 赏析
```
中秋前夕赏月，却不写皓月当空，而写月"躲云遮"，别有趣味。首句"十四已圆十五月"，农历十四的月亮已如十五一般圆满，暗合"人月两团圆"的期盼。次句"中秋将至躲云遮"以拟人手法写月亮像调皮的孩子一样躲进云层，"躲"字让全诗的氛围一下子轻松俏皮起来。

后两句从眼前的月延伸到时间与情感。"将来过去万千夜"——在无穷的时间和无数个夜晚之中，"天上人间独一颗"——无论天上还是人间，都只有这独一无二的一轮明月，也只有独一无二的那一个人。表面写月，实则以月喻人，呼应了篇末的题赠"写给亲爱的夫人"。全诗前两句写景带趣，后两句抒情藏深，将中秋赏月的温馨与对爱人的深情完美融合，言简意深，含蓄动人。
```
