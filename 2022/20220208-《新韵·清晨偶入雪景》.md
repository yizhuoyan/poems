# 《新韵·清晨偶入雪景》  

```
大地盖白衾，高枝戴羽巾。
鼻间出气剑，脚下踩清音。
行至半坡处，回头唯履痕。
可知成景后，吾乃第一人。
```

# 赏析
```
此诗写清晨踏雪，从视觉到触觉到听觉，全方位描摹雪中行路的体验。首联以拟人手法写雪景——大地盖上了白棉被，树枝戴上了羽毛围巾，"盖"与"戴"赋予静态雪景以活泼的生命气息。颔联写人体感受——"鼻间出气剑"以"剑"喻呼出的白气在冷空气中凝结成线，奇警有力；"脚下踩清音"写出雪地特有的咯吱声，"清音"二字将脚步声转化为听觉上的美感。

颈联忽生意境——走到半坡回头看，雪地上只有自己一行脚印。"唯履痕"三字写尽天地之间一人的孤寂与完整。尾联"可知成景后，吾乃第一人"不无骄傲地宣告：我是这场雪后的第一个到访者。既有开辟者的自豪，也有人与自然独处的私密喜悦。全诗以畅快的节奏和新鲜的意象，将一次寻常的雪中漫步写得意趣盎然。
```
