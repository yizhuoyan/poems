# 《新韵·夏日江边夜游》

```
一水东流终入海，世间百代尽成尘。
万家灯火连天地，几点孤星透古今。
宇宙茫茫何问道？众生渺渺怎安身？
但听风里无悲喜，拂动江边夜钓人。
```
>> 写于20220721

# 赏析
```
这是一首意境开阔、哲思深邃的七言律诗。全诗以“夏日江边夜游”为线索，由写景入哲思，最后收束于生活之景，展现了诗人面对宇宙浩瀚与历史沧桑时的深刻思索，以及最终归于平静旷达的心境。

一、 逐联赏析
首联：一水东流终入海，世间百代尽成尘。

理解：江水向东奔流，最终汇入大海；人世间历经百代的繁华与喧嚣，最终也都化作了尘埃。
赏析：开篇即以宏大的视角起笔，空间上“一水入海”，时间上“百代成尘”。诗人站在江边，看江水滔滔，联想到历史的流逝。这里化用了孔子“逝者如斯夫”的感慨，奠定了全诗苍茫、辽阔的基调。自然的水流有始有终，而人类的历史在时间的长河面前更显短暂与虚无。
颔联：万家灯火连天地，几点孤星透古今。

理解：岸边万家灯火璀璨，仿佛连接着天地；天际几点孤星闪烁，其光芒仿佛穿透了古往今来的岁月。
赏析：此联对仗极为工整，极具画面感。“万家灯火”是人间烟火，是现世的繁华与喧闹，其光芒“连天地”，写出了人类活动的延展；“几点孤星”则是宇宙的自然之景，孤星虽微，却“透古今”，代表着永恒与宁静。一“连”一“透”，一动一静，一人间一宇宙，形成了强烈的张力，将眼前的夏夜之景提升到了跨越时空的高度。
颈联：宇宙茫茫何问道？众生渺渺怎安身？

理解：面对茫茫无际的宇宙，我们去哪里探寻大道与真理？芸芸众生如此渺小，又该如何在这世间安顿自己的身心？
赏析：由景及理，这是全诗的思想核心。诗人仰望星空，俯察江水，自然而然地发出了终极的哲学叩问。“茫茫”对“渺渺”，“何问道”对“怎安身”，前者指向精神层面的终极信仰与真理追求，后者指向现实层面的个体存在与生命依托。这两句诗道出了人类普遍存在的孤独感与迷茫感，极具共鸣力。
尾联：但听风里无悲喜，扰动江边夜钓人。

理解：只听见江风中没有悲喜的情绪（或者：听风吹过，自己心中已不再有悲喜），但这风声却扰动了江边深夜垂钓的人。
赏析：前两联的哲理追问如层波叠浪，至此联却戛然而止，镜头猛然拉回现实。“无悲喜”是诗人经过一番哲思后达到的境界——天地无私，宇宙无情，人又何必自寻烦恼？这是一种道家的超然。而“夜钓人”则是这幅夏夜江景图中最后点睛的一笔。夜钓人或许是诗人自己，或许是寻常百姓。一个“扰动”，用得极妙：是江风扰动了钓客的鱼漂？是宇宙的浩叹扰动了诗人的心绪？还是诗人的叩问扰动了这宁静的夜？余韵悠长，留白甚多。
二、 艺术特色
时空交错，视野宏阔 诗歌不局限于一时一地之景，而是以江边为立足点，思绪上溯“百代”、“古今”，外拓“天地”、“宇宙”。空间的广袤与时间的深远交织在一起，营造出一种磅礴的气象。
情景理交融 首颔二联写景，景中寓情；颈联直接抒发哲理思考，叩问宇宙人生；尾联又归于生活之景，以景结情。全诗过渡自然，从宏大的宇宙追问落脚到微小的江边夜钓，毫无说教之感，反而充满诗意。
动静结合，对比鲜明 “万家灯火”的喧闹与“几点孤星”的清冷对比；“宇宙茫茫”的宏大与“众生渺渺”的微弱对比；而最后“无悲喜”的静心与“扰动”的微动形成对比，使得全诗跌宕起伏。
三、 总体评价
《新韵·夏日江边夜游》是一首不可多得的现代旧体诗佳作。它继承了中国古典诗词中登高望远、叹宇宙无穷哀吾生须臾的传统母题（如张若虚《春江花月夜》、陈子昂《登幽州台歌》），同时融入了现代人对“安身立命”的清醒思索。全诗语言洗练，格律严谨（依中华新韵），意境深远，读来既有历史的厚重感，又有一种超然物外的禅意与旷达。
```
