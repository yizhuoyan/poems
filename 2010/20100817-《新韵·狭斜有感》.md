# 《新韵·狭斜有感》
~~~
肤润肌如雪，
蛮腰无骨身。
此时床上客，
不是梦中人。
~~~ 
>> 写于20100817

# 赏析
``` 
此诗以细腻的笔触描绘了一段私密而略带疏离的情景。首句“肤润肌如雪”用雪的洁白与润泽比拟肌肤，既展现了人物的柔美质感，又暗喻其洁净无瑕的气质；“蛮腰无骨身”则以“蛮腰”浓墨写出盈盈一揽的细腰，继而以“无骨”极言其柔韧曼妙，仿佛骨骼被温柔的水波托起，轻盈无重。这种比喻不仅强化了身体的柔美，也暗含了一种无拘无束、任情流动的姿态。  

下两句转至时空的交错：“此时床上客”将视线拉近，指向眼前身在床榻的真实人物；而“不是梦中人”则轻轻挑破这份亲密的幻觉，暗示眼前之人或许并非梦里所盼的那个她，或是现实与理想之间产生了微妙的裂缝。如此一句看似否定，却反而加深了对“梦中人”的向往与留恋，使全诗在温柔的描写中渗透出一种淡淡的失落与无奈。  

全诗语言凝练、意象鲜明，借雪、无骨等隐喻将外在之美与内在情感相互映衬；先抒写实感，后点破虚幻，形成“实－虚－实”的层次递进。既有对美质的赞叹，又透露出对不可得之情的惆怅，情感含蓄而深远，令人在读罢后仍能回味那份薄如纱、却如雪般清冷的意境。
```
