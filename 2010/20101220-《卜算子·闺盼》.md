#《卜算子·闺盼》

```
乳燕小窗飞，光景芳闺午。
新浴香熏百事无，帘卷莲花步。

石亭印桐疏，木叶听风故。
素手轻拾落地花，时向门前路。
```

# 赏析
``` 
《卜算子·闺盼》不着一“盼”字，却通篇写“盼”。全词从午间闺景写起，以乳燕、小窗、新浴、莲花步铺陈明丽闲适的氛围；下片转入桐疏、木叶、落花，季节悄然流逝，最后以“时向门前路”收束。词中人物始终没有直言心事，而是让景物、动作和时间替她说话，写出一种含蓄而绵长的等待。

“乳燕小窗飞，光景芳闺午。”开篇明快而有生机。“乳燕”带着新春气息，“小窗飞”写燕子轻盈飞入，使静谧的闺中顿生动态。一个“飞”字，也暗含人与燕子的反差：燕子能够自由往来，而闺中人却只能身处小窗之内。“芳闺光景午”则写午间阳光明丽、闺中安静，一派闲适景象。表面无忧无虑，实际上正为下文的“盼”蓄势。

“新浴香熏百事无，帘卷莲花步。”由写景转入人物。“新浴香熏”写沐浴后的清润与芬芳，“百事无”看似只是闲适无事，实则耐人寻味：若真是百事皆无，为何下文总要向门前望去？因此“百事无”与结句暗中形成反差——百事皆无，唯有一事始终萦心。

“帘卷”是一个极有意味的动作。帘子卷起，视线便由闺内伸向窗外；“莲花步”则写女子缓缓而行，轻盈而雅致。她没有说自己在等待什么，却已经从室内走向了等待的方向。

下片“石亭印桐疏，木叶听风故。”时间和意境由春日的明丽转入秋日的清寂。“桐疏”写梧桐叶渐少，石亭之上留下疏淡的树影，季节的变化由此悄然显现。

“木叶听风故”是全词最精巧的语句之一。“故”取旧、往昔之意，“风故”即从前的风、昨日的风。木叶今日尚在，却仿佛能够听见昔日吹过的风。这里并不是简单地“听风”，而是把现在的木叶与过去的风联系起来，造成一种奇妙的时间错位：今日之物，听昨日之声；眼前之景，却承载着从前的时光。

于是一个“故”字，使普通的秋景获得了时间的纵深。风本来吹过便无踪无迹，但在诗意之中，过去的风仿佛仍然留在木叶之间。对于闺中人而言，这也暗暗对应着她所等待的对象——人虽在今日，心却仍牵系着从前。

“素手轻拾落地花，时向门前路。”这一联把人物重新带回眼前。“素手”写人物的清雅，“轻拾”写动作的细微克制。花已经落地，她却一朵一朵轻轻拾起。“落地花”不仅是眼前之景，也自然带出花落、春去、青春易逝的意味。她似乎是在拾花，实际上也像是在挽留已经逝去的时光。

最后“时向门前路”点明全词真正的情感所在。“时”不是一次，而是不时、时时；她一边拾花，一边仍会望向门前。门前并没有写人，甚至没有写“归”字，但一条“门前路”已经足以让读者感受到等待的对象。

全词因此形成一条隐约的时间与情感线索：乳燕初飞，是春；桐叶渐疏，是秋；花从盛开到落地，是时间；而从始至终未曾改变的，是向门前望去的目光。

“百事无”与“时向门前路”前后照应：表面上百事皆无，内心却始终有一事未了。全词不直写相思，不明言等待，却以景写时、以动写情，以“故”牵过去，以“门前路”望将来，在春秋流转之间写出一个“盼”字的漫长与深情。
```
