#《卜算子·闺盼》

```
乳燕小窗入，芳闺光景午。
梦醒新浴香汗无，卷帘莲花步。

石阶印桐疏，西风戏落木。
素手拾尽落花处，回眸门前路。
```
# 赏析
``` 
这首《卜算子·闺盼》以细腻笔触描绘闺中女子午后生活，将静谧的时光与潜藏的情思融为一体。上半阕先写醒后动作：乳燕飞入小窗，点出夏初时节；梦醒新浴，身香汗消，卷帘而起，步履如莲花般轻盈。这里的“乳燕”“莲花步”不仅刻画环境幽雅，更以动态生命感衬托女子的清适与灵动。

下半阕转写足下景致：石阶上桐叶影子疏落，西风戏弄残叶。素手拾尽落花，却不经意回眸门前路。尤妙在“拾尽”与“回眸”的转折——看似专注捡花的动作，实则目光已超越当下，落花被一寸寸拾起，视线却延伸向远方的路途。全词未直述愁思，却以“香汗无”（沐浴后的清爽）与“落花处”（零落的残英）形成温度与色彩的对比，暗含身心的微妙变化。末句“回眸门前路”如点睛之笔，将闺中闲适推向远方的牵挂，恰似无声水波，润物无声却随处可见。

全词恰似一幅淡彩工笔画：动静相生（燕入风戏）、刚柔并济（素手莲步），用最凡俗的午后瞬间，承载着最深沉的情意。它不言愁而愁自见，正是晏殊派小令“以景寄情”的典范——落花不是被随意踏碎，而是被素手一一拾起，这份细致的呵护，恰是相思最敦厚的注脚。语言浅而意深，读来如春风拂面，回味方觉袖香犹在。
```
