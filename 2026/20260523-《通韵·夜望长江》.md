# 《通韵·夜望长江》

```
江水望东流，人间不尽愁
贪嗔痴怎去，爱欲恨恒留
造化有其道，星河无彼秋
少餐多早寐，漫步自悠悠

```

# 赏析

```
这首《通韵·夜望长江》是一首意境开阔、哲理深邃的五言律诗。诗人以“夜望长江”为切入点，由景及情，由情入理，最终落脚于一种旷达随缘的生活态度。全诗起承转合自然流畅，既有传统诗词的沉郁顿挫，又兼具现代通韵的清朗明快，更巧妙融合了佛家的超脱与道家的自然，读来令人抚卷长思。以下为逐联赏析与整体解读：

一、 逐联赏析

首联：江水望东流，人间不尽愁
   起笔破题，情景交融。 诗人夜间伫立江畔，眼见江水滔滔向东奔流不复返。这一景象极易触动人心中的时光之叹与身世之悲。“东流”不仅是自然之景，更隐喻着时光的消逝与命运不可逆转的洪流。下句直抒胸臆，以“不尽愁”对仗“东流”，将千古文人的共同感慨道出——江水无穷尽，人间的悲愁亦无穷尽。此联大有李煜“问君能有几多愁，恰似一江春水向东流”的余韵，奠定了全诗深沉厚重的基调。

颔联：贪嗔痴怎去，爱欲恨恒留
   承接愁绪，直指人心。 诗人没有停留在泛泛的“愁”上，而是向内挖掘，探寻“不尽愁”的根源。此联借用佛教概念，“贪、嗔、痴”乃人生三毒，是痛苦的源头；“爱、欲、恨”则是凡尘中人最强烈的情感羁绊。“怎去”与“恒留”构成强烈的张力：理智上想要摆脱三毒的纠缠，但情感上爱欲与恨意却如影随形。这一联将人类内心的挣扎写到了极致，充满了无力感与悲剧色彩，对仗工整，字字千钧。

颈联：造化有其道，星河无彼秋
   笔锋一转，境界全出。 既然人间愁苦如此深重，有无解脱之法？诗人将视线从内心的纠结重新投向浩瀚的宇宙。大自然（造化）自有其运行的规律，不因人的意志而转移；天上的星河璀璨永恒，根本不存在人世间那种草木凋零的“秋天”。这里的“秋”是衰败、悲凉与死亡的象征。“无彼秋”三字极妙，以宇宙的永恒与无情，反衬出人世悲欢的渺小与徒劳。面对浩瀚星空，个人的贪嗔痴恨仿佛微尘，此联意境从苦闷一跃而为壮阔，带有浓厚的道家顺应自然、齐物论式的宇宙观。

尾联：少餐多早寐，漫步自悠悠
   以俗入雅，举重若轻。 经历了前六句的宏大叙事与深刻哲思，诗的结尾却出人意料地落回了最平凡、最琐碎的日常。“少餐多早寐”看似是长辈般的世俗叮咛，甚至带有一丝自嘲的幽默，实则蕴含着极高的生活禅意——既然天地有道而人欲难除，既然宇宙无秋而人生苦短，那么何须执着于宏大的解脱？少吃一点，早点睡觉，保养好这具皮囊，在漫漫长夜中“漫步自悠悠”，这本身就是一种最朴素的超越。“自悠悠”与首联的“东流”相呼应，江水悠悠是天道，漫步悠悠是人心，最终达到了一种随遇而安、当下即是的大自在。

二、 艺术特色

1.  大起大落，张弛有度
    全诗的情感曲线极富戏剧性：首联的悲沉（大起）——颔联的纠结苦痛（极紧）——颈联的旷达超脱（大落）——尾联的平淡恬静（极松）。这种从宏观宇宙到微观肠胃的跳跃，不仅不显突兀，反而有一种“看山还是山”的禅宗顿悟感，举重若轻，韵味悠长。

2.  佛道交融，哲思深邃
    颔联用佛家义理剖析烦恼的根源，颈联用道家思想观照宇宙的永恒，尾联则用儒道合一的“知天命”与“养生”来指导生活。三家思想在诗中融汇贯通，化理入景，理不碍情。

3.  语言质朴，对比强烈
    全诗没有生僻的典故和华丽的辞藻，语言近乎白话（特别是尾联），却极具穿透力。前半首“流、愁、留”押平声韵，音调低回绵长；后半首“道、秋、寐、悠”在顿挫中走向开阔。星河的“无秋”与人间的“多愁”，哲理的“高”与生活的“低”，形成了极具张力的审美效果。

总结

《通韵·夜望长江》是一首兼具厚度与温度的佳作。它没有停留在传统的伤春悲秋里顾影自怜，而是以一种通透的目光审视了人世间的苦难与本相。最终，诗人用一句“少餐多早寐，漫步自悠悠”完成了对人生终极困境的消解——所有的贪嗔痴恨，所有的宇宙浩渺，最终都要回归到好好吃饭、好好睡觉的具体生活之中。 这种在看透生活本质后依然热爱生活、顺其自然的旷达，正是此诗最动人的灵魂。
```
