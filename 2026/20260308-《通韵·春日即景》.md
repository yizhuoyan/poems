# 《通韵·春日即景》

```
油菜开心满地招，新妆桃李尽相邀。
风挠嫩蕊枝枝笑，蜜诱憨蜂朵朵挑。
还有野花拦路久，除非巧语赞她娇。
东君切记多节俭，莫使明春不够交。
```
>> 写于20260308

# 赏析
```

这首诗以春日百花争艳为背景，以生动活泼的拟人手法，描绘了一幅热闹、俏皮而富有生活情趣的春日图景。诗中花木有情，春风有趣，蜜蜂憨态可掬，野花甚至会“拦路撒娇”。全诗不以深沉取胜，而以一个“趣”字贯穿始终，在轻松诙谐的语言中表现诗人对春光的喜爱与珍惜。

首联“油菜开心满地招，新妆桃李尽相邀”，写春花初盛的热闹景象。“开心”既写油菜花盛开之态，又赋予花朵人的情绪；“满地招”更将大片油菜花写成热情招手的主人。“新妆桃李尽相邀”则进一步拟人化，桃李仿佛换上春日新妆，争相邀请游人前来观赏。“招”与“邀”两个动词，使原本静态的花木顿时活了起来，也奠定了全诗轻快欢悦的基调。

颔联“风挠嫩蕊枝枝笑，蜜诱憨蜂朵朵挑”，继续将春景写得灵动可爱。“挠”字用得极有趣味，春风吹拂花蕊，本是自然景象，诗人却写成春风故意逗弄花朵，于是嫩蕊“枝枝笑”。一“挠”一“笑”，将风与花之间写出了顽童般的互动。下句转写蜜蜂，“蜜诱憨蜂”，仿佛花蜜有意诱惑憨态可掬的小蜜蜂；“朵朵挑”写蜜蜂穿行花间、逐朵采蜜的情状，画面感十足。花、风、蜂在诗中彼此呼应，使春天呈现出一种欢快的生命律动。

颈联“还有野花拦路久，除非巧语赞她娇”，是全诗最富情趣的一联。野花本来只是路旁随处可见的自然景物，诗人却写成了一个娇俏而任性的女子，竟然“拦路”不让人通过，非要听几句好话夸赞自己的娇美不可。“拦路”写花之繁茂，“除非巧语赞她娇”则将这种繁茂进一步人格化，赋予野花以撒娇、爱听赞美的性情。至此，春花已经不再只是供人观赏的景物，而仿佛成为一路上主动与诗人嬉闹的朋友。

尾联“东君切记多节俭，莫使明春不够交”，在诙谐中收束全篇。“东君”即春神，诗人忽然对这位掌管春天的神明提出忠告：今年的春花开得如此铺张，可要节省一些，千万不要把春光用得太过，以至于明年没有足够的春色可“交”。这里将春光想象成一种有限的财富，把自然界的繁花盛景写成了仿佛需要精打细算的“花销”，构思新奇而幽默。“不够交”三个字尤其富有生活气息，仿佛春神每年都承担着按时交付春色的任务，令人会心一笑。

全诗最突出的艺术特色，是大量运用拟人手法，将无生命的自然景物写出了人的情绪、动作和性格。油菜会“开心”，桃李会“相邀”，春风会“挠”，花蕊会“笑”，蜜蜂憨态可掬，野花还会撒娇拦路，连春神东君也仿佛成为可以打趣的熟人。由此，整个春天不再是一幅静止的风景画，而变成了一个充满性情、声音和互动的春日世界。

这首诗还有一层可爱的惜春之意。尾句表面上是在和东君开玩笑，实际上却透露出诗人对春光的珍惜。正因为喜欢眼前繁盛的春色，才会担心春光被“用”得太多，甚至希望东君节俭一些，好让来年依然有足够的春花可赏。于是，诙谐的语言背后，藏着一颗热爱自然、珍惜春光的心。

全诗由花木写到风蜂，由风蜂写到野花，再由野花写到东君，层层推进，情趣不断加浓，最后以一个出人意料的“节俭”作结。它没有刻意雕琢深奥的哲理，而是用轻松、俏皮的笔调，把寻常春景写出了鲜活的人情味。

可以说，这是一首以“趣”写春、以“笑”写春、以生活化的想象写春的作品。花有情，风有性，蜂有态，东君也有了人间烟火气。春光之美，便在这些轻巧而俏皮的笔触中，自然而然地流淌出来。

```
