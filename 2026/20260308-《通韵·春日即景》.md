# 《通韵·春日即景》

```
油菜开心满地招，新妆桃李尽相邀。
风挠嫩蕊枝枝笑，蜜诱憨蜂朵朵挑。
还有野花拦路久，除非巧语赞她娇。
东君切记多节俭，莫使明春不够交。
```

# 赏析
```
这是一幅热热闹闹的春日百花图，万物拟人、妙趣横生。"油菜开心满地招"——油菜花像开心的小孩挥着手满田招摇；"新妆桃李尽相邀"——桃花李花如化了新妆的美人互相邀约，春天的花会就这样开始了。

颔联"风挠嫩蕊枝枝笑，蜜诱憨蜂朵朵挑"——风像顽皮的手去挠花蕊的痒痒，逗得花枝笑弯了腰；"憨蜂"一词写蜜蜂胖乎乎的憨态，被花蜜诱惑着一朵一朵地挑拣。颈联"还有野花拦路久"写路旁的野花拦住了去路，非得赞美她的娇美才肯放行——这是多么天真可爱的想象！尾联"东君切记多节俭，莫使明春不够交"像对春神的叮嘱：省着点用春天的美，别把明年的份额也用完了。全诗通篇拟人，将春日繁花写得活泼俏皮、热闹非凡，充满童趣与对春光的热爱。
```
