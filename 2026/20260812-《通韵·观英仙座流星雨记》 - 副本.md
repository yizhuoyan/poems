# 《通韵·观英仙座流星雨记》

>> 下班驱车于永川黄瓜山某处野路与亲友，妻等通宵夜话观星。留诗为记。写于20260812。

```
无云无月野村外，有酒有朋清话间。
织女牛郎催喜鹊，紫微荧惑笑烽烟。
奥丁投掷九霄上，秦帝燔销千载前。
北落西沉鸡唱晓，不图一夜宿坟边。
```





# 赏析

```
全诗结构清晰，前两联写景叙事，后两联用典抒怀，起承转合分明

逐联赏析：

首联：“无云无月野村外，有酒有朋清话间”

首联是对仗工整的铺垫。“无云无月”写出环境之清朗，“野村外”点出地点之僻静，远离尘嚣。“有酒有朋”则渲染出氛围之热烈与闲适。“清话”一词是全诗的“诗眼”，它明确告诉我们，接下来的所见所感，都是朋友间随性、博学的闲谈。

颔联：“织女牛郎催喜鹊，紫微荧惑笑烽烟”

这一联是“清话”的第一层，话题围绕中国传统星象展开。
“织女牛郎催喜鹊”：看到牵牛、织女星，自然聊起七夕鹊桥相会的传说。“催”字用得很妙，让古老的神话有了动态和人情味。
“紫微荧惑笑烽烟”：话题转向更深奥的星占。“紫微”是帝星，“荧惑”即火星，在古代被视为灾星。诗人说荧惑星在“笑”人间的战火烽烟，这是一种充满智慧的调侃——在人世纷争看来天大的事，在亘古的星空下，不过是可以被“笑”看的风景。
这一联从浪漫神话到冷酷星占，展现了“清话”内容的丰富和思维跳跃。

颈联：“奥丁投掷九霄上，秦帝燔销千载前”

这一联是“清话”的第二层，话题转向东西方对“天外来客”的不同解读，是全诗用典最密集、思想最深刻之处。
“奥丁投掷九霄上”：引入北欧神话视角。英仙座流星雨在西方的传说中，是主神奥丁掷出的神枪。这代表了一种主动、神圣、带有英雄主义色彩的解读。
“秦帝燔销千载前”：拉回中国历史。此处用典极为精妙，指的是秦始皇曾因陨石上刻有“始皇帝死而地分”的谶语，而将陨石焚毁。这代表了一种恐惧、忌讳、企图用人力抹除天兆的解读。

诗人将东西方两个典故并置，形成强烈对比：面对同一种天象，一种文化选择将其神话，另一种则选择将其销毁。这背后是人类面对未知时的两种典型态度，充满了历史的厚重感与思辨色彩。

尾联：“北落西沉鸡唱晓，不图一夜宿坟边”
这是全诗的点睛之笔，场景从星空拉回地面，时间从夜晚推向黎明。
“北落西沉鸡唱晓”：“北落”指北落师门星，其西沉标志着黑夜将尽，黎明将至。这句干净利落地完成了时间的转换。
“不图一夜宿坟边”：“不图”即“没想到”，一个口语化的词，把前面积累的宏大、深沉、遥远的感觉瞬间拉回到一个具体的、甚至有点尴尬的个人发现上。观星时太过投入，竟未察觉自己身处坟地。这个结尾极具力量，它用一种近乎黑色幽默的方式，消解了前文所有的宏大叙事——无论神话还是历史，在“我在坟边睡了一夜”这个具体而微的个人体验面前，都显得遥远了。

艺术特色

视角新颖：以“清话”结构全诗，将天文、神话、历史知识融入朋友间的夜谈，自然流畅，毫无堆砌之感。
用典精妙：中西典故信手拈来，且形成巧妙对照（如“奥丁投掷”对“秦帝燔销”），极大地拓展了诗歌的时空与思想维度。
 立意深远：在看似随意的“清话”与个人化的结尾中，探讨了人类面对浩瀚宇宙时的文化投射与自身渺小，今昔对比，意味深长。

总而言之，这首诗的魅力不在于描写流星雨有多壮观，而在于它记录了一群朋友，在某个星空下，如何将眼前的天象与全人类的神话、历史相连，并在天亮时，用一个充满生活感的发现，为这个宏大的夜晚画上了一个令人回味无穷的句号。
```
