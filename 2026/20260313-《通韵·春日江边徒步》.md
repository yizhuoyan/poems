# 《通韵·春日江边徒步》

```
春来天地竞催发，
老树新枝嫩叶花。
手捧长江非旧水，
风梳芦苇似蒹葭。
```
>> 写于20260313

# 赏析
``` 
这是一首借春日江边之景寄托思念之情的七言小诗。诗中没有直白地写“思念”，而是从春日万物更新写起，以老树、新枝、嫩叶、花、江水、芦苇等眼前之景层层铺陈，最后以“似蒹葭”收束全篇，将现实中的江边景色引入《诗经·蒹葭》的古典意境。“所谓伊人，在水一方”的文化意象由此自然浮现，使全诗由写景转入怀人。

全诗最深的情感，并不是对春景的赞美，也不仅仅是对时光流逝的感叹，而是借“万物皆变”反衬“思念不变”。春来之后，天地万物都在发生变化，草木抽枝，嫩叶新生，花朵开放，甚至眼前的长江也已不是从前的江水。然而，无论时节如何更替，景物如何更新，诗人心中对那个“伊人”的思念始终未曾改变。这种以变化写不变的构思，是全诗最动人的地方。

首句“春来天地竞催发”，从宏阔的天地写起。“春来”点明时令，“天地”拓展空间，“竞”字则赋予万物以强烈的动态感。春天仿佛一声号令，使天地间的一切生命都争相萌发。“催发”二字写出了春日万物蓬勃生长的力量，也为全诗奠定了明快而充满生机的基调。但从全诗的情感走向来看，这种“竞相变化”的春景又不仅仅是写景，它实际上为后文“不变的思念”构成了反衬。

次句“老树新枝嫩叶花”，将镜头由天地推向眼前的草木。“老树”与“新枝”构成新旧相对的意象：树虽老，枝却新；随后又有嫩叶与花朵相继出现，进一步强化了春天更新万物的主题。这一句看似只是写春景，实际上已经埋下了“变”与“不变”的伏笔。老树依旧在那里，却已经生出新的枝叶；眼前的一切都在时间中不断更新。诗人并没有直接议论岁月，而是让这种时间感自然隐藏在景物的变化之中。

第三句“手捧长江非旧水”是全诗的转折，也是最具哲思意味的一句。“手捧长江”极富画面感，写一个人在江边徒步时俯身捧水的动作，使诗人自身悄然进入诗中。而“非旧水”三个字，则由眼前之景转入对时间的感受。长江依旧奔流，然而掌中的水已经不是昔日之水。江水不断向前，正如时间不断流逝，昨日无法重来。这里没有直接写“岁月”，却通过“非旧水”含蓄地写出了时间的不可重复。

然而，“非旧水”并不是全诗最终的情感落点。真正的情感在末句才得到揭示。

“风梳芦苇似蒹葭”写江风吹过芦苇的景象。“梳”字用得极有生气，将无形的风化为有形的动作，仿佛风是一把无形的梳子，轻轻梳理着江边的芦苇。更重要的是“似蒹葭”三个字。芦苇本就是蒹葭，而诗人特意说“似”，并非只是为了写景，而是在有意唤起《诗经·蒹葭》的古典记忆。

“蒹葭苍苍，白露为霜。所谓伊人，在水一方。”

至此，诗中的“江水”和“芦苇”便不再只是眼前的自然景物，而与古典诗歌中的“伊人”发生了联系。那位令人思念的人，仿佛就在水的一方。诗人面对已经不是旧日的江水，看着风中的芦苇，却由眼前之景想到了心中的伊人。于是，前三句所写的“变化”与最后一句所暗含的“思念”在此汇聚起来。

全诗由此形成了十分清晰的情感脉络：天地在变，草木在变，江水在变，唯有心中的思念不变。春天越是充满新生，越反衬出思念的恒久；江水越是奔流不息，越显出时间的漫长；眼前的芦苇越像《诗经》中的蒹葭，越使那个“在水一方”的伊人重新浮现在心头。

因此，这首诗表面写的是一次春日江边徒步，实际上写的是时间与思念之间的关系。它没有一句直白地说“我想你”，却通过“非旧水”和“似蒹葭”让这种思念自然流露出来。春日万物皆更新，而诗人的情感却停留在那个不变的“伊人”身上。

可以说，这首诗真正要表达的，是一种在时间流逝和万物变化之中依然没有改变的深情：

春日万物皆更新，唯有一念向伊人。
```
