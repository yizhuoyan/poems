# 《通韵·荒芜》

>>  20261023 见旧路杂草丛生有感

```
荒芜侵旧路，岁月抹余情。
谁证当年雨，随风叶上停？

```




# 赏析

```
 一、诗意理解

荒芜侵旧路，岁月抹余情。

首联从眼前景象落笔。“荒芜侵旧路”，写杂草渐渐蔓延，昔日的道路已失去往日的模样。“侵”字颇有力度，不仅写出杂草滋长、旧路被掩的过程，也赋予荒芜一种步步逼近的意味。旧路本是往来之所，如今却被荒草侵占，既是实景，也暗示着昔日生活的痕迹正被时间一点点吞没。

“岁月抹余情”由景入情。“抹”字与上句的“侵”相呼应：荒草侵蚀的是旧路，岁月抹去的是余情。道路尚可见其形貌，往事中的情感却已难以辨认。一个写外在景物的变迁，一个写内心情感的消退，空间上的荒芜与时间中的淡忘相互映照，使诗意由眼前的旧路延伸至不可追回的过去。

谁证当年雨，随风叶上停？

颔联之后，诗意由感叹转入追问。

“谁证当年雨”，并非单纯询问当年究竟谁曾见过一场雨，而是借“谁证”追问往事的凭据。当年经历的一切，如今还有谁能证明？旧路已荒，余情渐淡，连曾经的风雨也仿佛失去了见证者。一个“谁”字，将诗人置于往事与现实之间：记忆虽在心中，却未必还能从外物中找到印证。

“随风叶上停”则是全诗最耐人寻味的一笔。风本有流动、无定之意，叶本是轻微、易逝之物，而雨滴即使暂时停留在叶上，也终究难以久存。风吹叶动，雨滴随之摇曳，眼前似乎尚有一瞬停驻，下一刻却可能消散无踪。

这里的“停”尤其值得玩味。它既写雨滴暂留叶面的自然情状，也与前句“当年”形成时间上的对照：当年之事早已远去，如今所能想见的，或许只剩一滴仿佛停在叶上的雨。诗人追问谁能为往事作证，最后却没有给出确切答案，而是将问题交给风、叶与雨。自然景象似乎提供了一个微弱的凭据，却又因风动叶摇而随时可能消失。

如此看来，“谁证”与“叶上停”之间，隐含着一种意味深长的矛盾：诗人渴望寻找往事的见证，而自然所呈现的，却恰恰是万物难以长久留存的事实。

 二、全诗的深层意蕴

这首诗的核心，不只是怀旧，而是对往事能否留下凭据、情感能否抵抗时间的追问。

旧路曾经存在，情感曾经发生，当年的风雨也曾真实落下。然而，现实中的道路会被荒草遮蔽，心中的情感会被岁月冲淡，连曾经发生过的事情，也可能逐渐失去可以指认的证据。

诗人并没有直接诉说悲伤，也没有明言遗憾，而是借“旧路”“余情”“当年雨”层层递进，将不可追寻的过去寄托于景物之中。到了结句，视线从荒芜的旧路收束到一片随风摇动的叶子，意象由大而小，情绪也由直露转为含蓄。

值得注意的是，诗中并未断言当年的情感已经彻底消失。“余情”尚存，“谁证”仍问，恰恰说明诗人心中仍有未曾完全放下的东西。倘若往事已全然无足轻重，也就不必追问谁能证明它曾经存在。

因此，诗中的荒芜既属于旧路，也属于记忆；而对“当年雨”的追问，则透露出诗人对往昔真实存在过的情感，仍怀有一份不甘被岁月抹去的执念。

 三、艺术特色与炼字点评

一是以景写情，虚实相生。 前两句由荒草旧路写到岁月余情，后两句借当年之雨和叶上之滴寄托追忆。诗中没有具体交代往事，却使读者能够从景物的变化中感受到时间的流逝与情感的消磨。

二是炼字简净，脉络清晰。 “侵”写荒芜渐盛，“抹”写岁月消磨，“证”将怀旧转为追问，“停”则在流动不定的风雨中制造出短暂的静止。四字各司其职，推动诗意逐层深入。

三是结句含蓄，留有余味。 “随风叶上停”不直接说雨滴即将消散，而是写它暂时停留的状态。正因为这个“停”只是片刻，才使整首诗的怀旧意味更加深长：越是想留住，越能感受到它终将离去。

从句法上看，“谁证当年雨”与“随风叶上停”也构成了由问到景的转换。前句提出问题，后句不作抽象回答，而将读者带回一幅具体的自然画面。这种处理避免了直白说理，让情绪停留在景物之中。

 四、总体评价

《通韵·见旧路杂草丛生有感》是一首由旧路荒芜引发的怀旧小诗。它以“侵”“抹”写外物与内情的共同变迁，以“谁证”提出关于记忆与往事的追问，再以“叶上停”收束全篇，将难以挽留的时间凝聚为一瞬雨滴。

全诗真正动人的地方，在于它没有把往事写得清清楚楚，而是写出了往事逐渐模糊之后，人仍想寻找某种证明的心情。旧路可以被荒草遮没，余情可以被岁月冲淡，但只要仍有人追问“谁证当年雨”，那些曾经发生过的事情，便还没有从心中彻底消失。

这首诗的情感落点，不是简单地感叹旧路荒凉，而是追问：当岁月抹去了痕迹，曾经真实存在过的一切，还能凭什么证明？ 而那片随风摇动、似有雨滴停留的叶子，正是诗人留给这个问题的含蓄回答——它并不能永久保存往事，却让往事在消失之前，仍有一瞬可供凝望。
```
