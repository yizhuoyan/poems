# 《平水·三山五岳之黄山游记》

```
黄帝栖真曾炼药，诗仙掷笔自生花。
峰升云海浮如岛，雾透霞光薄似纱。
一石飞来凝日月，千松迎送塑风沙。
游人络绎朝朝至，莫怪仙翁不在家。
```

# 赏析
```
首联以两个传说开篇，将黄山的历史推向神话时代——黄帝在此炼丹修道，李白的"梦笔生花"传说也源于此。诗仙掷笔化作山峰奇景，将文学想象与自然景观完美融合，起笔便有了仙气。颔联以精妙的白描写实景——"峰升云海浮如岛"，群峰在云海之中如岛屿漂浮；"雾透霞光薄似纱"，霞光穿透薄雾如轻纱般柔美，"浮"与"透"两个动词轻灵传神。

颈联写黄山两大标志——飞来石如天外之物凝固了日月光华，"凝日月"三字赋予了石头见证时间的灵性；迎客松与送客松千百年来迎送着四方来客，在风沙中塑造成今日之姿。尾联"游人络绎朝朝至，莫怪仙翁不在家"以幽默收束——游客天天络绎不绝，难怪山上的神仙都被吵得搬家了！全诗将神话传说、自然景观与人间烟火巧妙融合，既有仙气又有生气。
```
