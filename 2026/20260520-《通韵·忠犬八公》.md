# 《通韵·忠犬八公》

```
生从雪域来，死去雪中埋。
苦等十年竟，相亲一载才。
饥寒老街变，风雨旧门开。
治乱人如草，呜呼况犬哉！
```

# 赏析
``` 
这是一首以忠犬八公故事为题材、而最终落脚于人世悲悯的五言律诗。全诗语言极简，情感却层层深入：首联写生死，颔联写相守之短与等待之长，颈联写岁月流逝与环境变迁，尾联则由犬及人，把个体命运提升到对世道与生命的感喟。诗中最动人的，并非单纯写“忠”，而是写一个生命在世界不断变化之中始终不改的等待。

首联“生从雪域来，死去雪中埋”，以“生”“死”两端概括八公的一生。“雪域”与“雪中”前后照应，一个“来”，一个“埋”，使冰雪成为贯穿生命始终的背景，也营造出冷峻、苍凉的氛围。八公生于雪域，最终又归于雪中，仿佛生命从一开始便被置于寒冷与孤寂之中。诗句没有刻意铺陈悲情，只以极简的事实落笔，反而显得更加沉痛。

颔联“苦等十年竟，相亲一载才”，是全诗情感张力最强的一联。“十年”与“一载”形成惊人的时间反差：等待漫长得几乎覆盖生命，相守却短暂得只有一年。“苦等”写等待的艰辛，“相亲”则写曾经真正拥有过的亲近与温情。“竟”与“才”两个字尤其传神，“竟”写十年之久令人难以想象，“才”则写一载相亲又何其短暂。长与短、所得与失去在这一联中猛烈碰撞，使八公的忠诚不再只是一个抽象的“忠”字，而成为用漫长生命守护短暂温情的真实命运。

颈联“饥寒老街变，风雨旧门开”，由个人的等待进一步写向时间与环境。“饥寒”写八公长期等待所承受的现实苦难；“老街变”则写岁月流转，外部世界已经发生变化。街道变了，时代变了，万物都在变化，而八公的等待始终没有改变。“风雨旧门开”尤其含蓄。“风雨”写环境的冷酷与反复，“旧门”则凝聚着往昔生活的痕迹；一个“开”字，使画面顿时有了动态，也让等待与失望同时存在。门可以一次次打开，但那个真正等待的人却再也不会回来。这里并未直说悲伤，而是借门的开合，把物是人非的苍凉留给读者体会。

尾联“治乱人如草，呜呼况犬哉”，是全诗境界的提升。诗人没有停留在八公自身，而是突然由犬及人。“治乱”并非只说乱世，而含有世道治乱、时代兴衰之意。在巨大的时代变迁面前，人命尚且“如草”，轻微、脆弱、难以自主，那么一只犬又将如何呢？“呜呼”一声，使前面的叙事骤然转入感叹；“况犬哉”看似是在替犬悲叹，实际上又形成了意味深长的反衬。犬不能理解所谓治乱，却能够用十年的生命守住一份不改的忠诚；人身处治乱之中，反而未必能够拥有这样的坚定。因此，这一句既是哀犬，更是哀人，既写生命的卑微，也写真情的可贵。

全诗最突出的艺术特色，是多重对比共同形成的张力。首联以“生”与“死”写生命两端，颔联以“十年”与“一载”写时间的悬殊，颈联又以“老街变”与“旧门开”写世界变迁与等待不变。与此同时，雪、饥寒、风雨构成了整体的寒冷底色，而“相亲”“苦等”又赋予其中一点持久的人情温度。冷与暖、变与不变、短暂与漫长相互碰撞，使这首诗的悲情并不流于直白，而具有一种克制而深长的力量。

《通韵·忠犬八公》写的是一只犬的生命，却没有止于写犬；写的是等待，却最终写到了人世。它以十年守候映照一载相亲，以一犬之忠反观世道之变，在极简的叙事中容纳了生死、离别、无常与深情。结尾一声“况犬哉”，看似轻叹，实则余韵最深：可悲的不只是犬之命运，更是人世间那些如草般被时代裹挟的生命，以及在无常之中仍然难得的忠诚与深情。
``` 
