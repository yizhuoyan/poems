# 《通韵·登岳阳楼》

```
千秋风雨岳阳楼，一句先忧青史留。
浩荡洞庭吞日夜，奔江入海润神州。
```
>> 写于20260216

# 赏析
```

这首诗登楼写怀，以岳阳楼为立足点，以范仲淹“先忧”之句为精神核心，将千秋风雨、浩荡洞庭与奔腾江水融为一体，最终落到“润神州”的家国情怀。全诗只有二十八字，却由楼及人、由景及史、由历史人物及现实天下，格局开阔，气象雄浑，表现出登高远眺之后由景生怀的豪迈胸襟。

首句“千秋风雨岳阳楼”，起笔便有历史的纵深感。“岳阳楼”是眼前所登之楼，而“千秋风雨”则一下将视野从当下推向漫长岁月。千百年来，风雨不断，而岳阳楼始终矗立江湖之间。“风雨”既是自然之景，也隐含历史风云。一个“千秋”，一个“岳阳楼”，使眼前的登楼之景带上了厚重的历史感。诗人所登的已不只是一座楼，而是一座承载千年风雨与文化记忆的历史之楼。

第二句“一句先忧青史留”，是全诗的诗眼，也是全诗由写景转入怀古、由怀古转入抒怀的关键。“一句先忧”所指，显然是范仲淹《岳阳楼记》中“先天下之忧而忧”的千古名句。诗人没有完整引用原句，而以“先忧”二字提炼其精神内核，再以“青史留”写其千古流传。

这一句最妙之处，在于把“一座楼”与“一句话”联系起来。岳阳楼之所以千古闻名，并不仅仅因为它临洞庭而有壮阔景色，更因为它承载了“先天下之忧而忧”的精神。楼可以历经风雨，而一句话却可以穿越千秋。所谓“青史留”，留下的不只是文字，更是一种忧国忧民、以天下为己任的精神。

第三句“浩荡洞庭吞日夜”，镜头重新转向眼前的洞庭湖。“浩荡”写湖面之广阔，“吞”字尤其有气势。洞庭湖仿佛能够吞纳日夜，将时间与天地都收入其中。这里的“吞”不是单纯写水势，而是将洞庭写出了吞吐天地的气魄。

“日夜”二字也值得注意。它不仅写昼夜更替，更与首句的“千秋”遥相呼应。前面是千秋岁月，眼前是日夜流转；一座岳阳楼、一片洞庭水，仿佛同时处于漫长历史与无尽时间之中。诗的空间因此变得极为开阔，时间感也随之延伸。

末句“奔江入海润神州”，从洞庭湖继续推进水势。“奔”字使静态的湖水变成奔腾向前的力量，江河最终汇入大海，而“润神州”则完成了全诗最重要的升华。

“润”字用得很有意味。它没有使用“震”“撼”“壮”之类直接表现力量的字眼，而以“润”收尾。江河奔流入海，最终滋养的是神州大地。于是自然之水获得了象征意义：浩荡江河不仅奔腾于天地之间，也仿佛承载着滋养家国、泽被天下的力量。

这样一来，最后两句就不仅是在写洞庭湖的壮阔水势，也与第二句的“先忧”形成了精神上的呼应。“先忧”是精神上的担当，“润神州”是现实意义上的滋养；一个写胸怀，一个写愿景，共同构成全诗的家国情怀。

从结构上看，全诗由“楼”起，由“人”承，由“湖”转，由“神州”收。

第一句写岳阳楼的千秋风雨；

第二句写范仲淹的千古精神；

第三句写洞庭湖吞吐日夜的宏阔气象；

第四句写江河奔流、润泽神州的家国愿景。

空间从一座楼扩展到洞庭，再扩展到江海和神州；时间从当下扩展到千秋青史。因而诗虽短，格局却很大。

尤其值得注意的是，全诗没有直接写“我”，也没有直接说“忧国”“爱国”，而是借岳阳楼、范仲淹、洞庭、江海这些意象来完成情感表达。这使家国之情不是直白喊出，而是从历史与山河之中自然生发出来。

“千秋”与“青史”写历史，“日夜”写时间；“岳阳楼”与“洞庭”写眼前之景，“神州”则将眼前山河提升为天下家国。诗人登楼所见，最终已经超越一楼一湖，而进入千秋历史与神州大地的宏大背景之中。

全诗最有力量的地方，是将“先忧”的精神与“润神州”的愿望放在同一条意象链上：因为心怀天下，所以先天下之忧；因为心怀天下，所以愿江河奔流、润泽神州。

因此，这首诗真正写的不是一次简单的登楼，而是登岳阳楼之后的一次精神远眺。

楼历千秋而不朽，洞庭吞吐日夜，江河奔腾入海；而那一句“先忧”，穿越青史，至今仍在山河之间回响。

登楼观洞庭，怀古思先忧；放眼江海，则愿其奔流不息，润泽神州。

这便是这首小诗最核心的精神气象：登高见山河，怀古见担当。
```
