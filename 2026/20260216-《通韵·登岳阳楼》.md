# 《通韵·登岳阳楼》

```
千秋风雨岳阳楼，一句先忧青史留。
浩荡洞庭吞日夜，奔江入海润神州。
```

# 赏析
```
登岳阳楼，绕不开范仲淹"先天下之忧而忧，后天下之乐而乐"的千古名句。首句"千秋风雨岳阳楼"——千年来这座楼阁历经多少风雨沧桑，依然矗立于洞庭湖畔。"千秋"既是时间之深远，亦是文化之厚重。次句"一句先忧青史留"——范仲淹的一句话便足以在青史中永垂不朽，"一句"与"千秋"对举，语言的穿透力竟胜过千年的风雨。

后两句写洞庭湖的浩瀚景象——"浩荡洞庭吞日夜"，一个"吞"字将洞庭的雄浑气势写尽，日夜星辰仿佛都被这无垠水面吞入腹中。"奔江入海润神州"写洞庭之水东流入海、润泽神州的宏阔图景，从眼前景延伸到整个华夏大地，空间感大大拓展。全诗前两句写人文之永恒，后两句写自然之壮阔，人文与自然在此交汇，恰如其分地诠释了岳阳楼在国人心中的特殊位置。
```
