# 《通韵·冬日北海观海之浪花》

```
风如大帚扫云后，天似蓝刀斩海中，
溅起浪花千万朵，瞬生瞬灭自无穷。
```

# 赏析
```
这首诗整体呈现出一种非常鲜明的“观海之壮”的气势。它并不着意描写北海的辽阔、宁静，而是抓住风、云、天、海、浪花几个动态意象，通过“大帚”“蓝刀”“千万朵”等富有力度和视觉冲击的词语，把海上风云与浪花的生成、消灭写得既壮阔又奇崛。前两句写天地之势，后两句写浪花之变，最终由“瞬生瞬灭”落到“自无穷”，使眼前短暂的浪花获得了近乎永恒的意味。

首句“风如大帚扫云后”，一上来便赋予“风”以强烈的动作性。“大帚”这个比喻很有画面感，风仿佛一把巨大无比的扫帚，将天空中的云层横扫而过。“扫”字尤其传神，它不是静态地写风，而是让读者直接看到云层被风驱赶、天空逐渐显露的过程。一个“后”字也使画面具有了时间上的动态感：风扫云去，天地顿然开阔。这里的风并非柔风，而是一股具有力量、速度和范围感的自然之力。

第二句“天似蓝刀斩海中”，是全诗最奇峭的一笔。“蓝刀”并不是通常意义上的天空比喻，却因此显得新鲜而有力度。天空的蓝色仿佛化作一柄巨大的蓝色长刀，自上而下插入海中。“斩”字与上一句的“扫”字遥相呼应，一个横扫，一个斩落，两个动词都具有强烈的力量感，使天地之间仿佛正在发生一场剧烈的运动。

这一句还有一个很值得玩味的视觉关系：海面与天空本来以海天相接的水平线相连，而“蓝刀斩海中”却把原本平面的天空写成了具有锋刃的立体之物。于是，天空的蓝仿佛一直延伸到海里，蓝天与碧海在视觉上被这一“刀”劈开，却又因为颜色相近而彼此融合。这种既“斩”又“融”的感觉，使诗句具有一种奇特的张力。

前两句因此形成了一个宏大的天地背景：风扫云，天斩海。一个写横向的风势，一个写纵向的天势。天地之间充满运动，海面也不可能平静，于是自然顺势进入第三句。

“溅起浪花千万朵”，镜头由宏观天地迅速落到海面。前两句写的是风云与海天的大景，此处则突然聚焦于被力量激起的浪花。“溅起”承接前面的“扫”“斩”，说明浪花并非静静存在，而是风与海碰撞之后产生的结果。“千万朵”则把浪花的数量与规模一下推向极致。

这里的“朵”尤其有意思。浪花本来是海水受到冲击后形成的短暂泡沫，却用描写花朵的量词“朵”来称呼它，于是冰冷、猛烈的海浪突然拥有了花的形态。海浪在这里既有力量，又有美感；既是自然运动的结果，又像天地之间突然绽放的花海。

然而诗人并没有停留在“千万朵”的壮美上，而是紧接着写：“瞬生瞬灭自无穷。”

这一句使全诗从写景进入了对时间与生命状态的感悟。“瞬生瞬灭”四字极有节奏感，也极准确地概括了浪花的本质：一朵浪花刚刚被海浪托起，转眼便破碎消失；但这一朵消失之后，下一朵又随之生成。浪花本身是短暂的，浪花的生成却没有终点。

因此，“瞬生瞬灭”与“自无穷”构成了一个很有意味的矛盾统一：个体是有限的，循环却是无穷的；一朵浪花会消失，但整个大海的浪花永远不会消失。所谓“无穷”，并不是说某一朵浪花能够永恒存在，而是说生灭本身构成了自然无尽的循环。

这也让结句具有了超越单纯写景的意味。诗人眼中看到的已经不只是浪花，而是自然运行的一种规律：有生便有灭，有灭又有生；瞬间即逝，却又绵延不绝。浪花因短暂而显得美丽，也正因为无数次的生灭循环而呈现出一种宏大的永恒。

从结构上看，全诗前两句写“势”，后两句写“花”；前两句写天地的力量，后两句写力量作用于海面后的结果。也可以说，它的视角经历了“风云—海天—浪花—生灭”的逐层推进：先写大环境，再写海面，再聚焦浪花，最后由浪花的瞬间生灭进入对无穷的感悟。

整首诗最值得注意的，是它没有用大量形容词直接说海“壮阔”“雄奇”，而是通过“扫”“斩”“溅”“生”“灭”等动词，让这种壮阔自己呈现出来。尤其“大帚”与“蓝刀”两个比喻，使风与天都具有了某种器物般的力量；到了“浪花千万朵”，这种力量又转化成绚烂的美；最后“瞬生瞬灭自无穷”，美景又转化成了关于自然循环的哲思。

可以说，这首诗写的表面是北海浪花，真正写出的却是自然之力与时间之流。风云有势，海浪有形，浪花有生灭，而天地之变却无穷无尽。

如果用一句话概括这首诗的神韵，可以说：

“风扫云开，天斩海立，千万浪花于一瞬间盛放又消灭，而无穷的大海，正由这无数个瞬间构成永恒。”
```
