# 《通韵·冬日北海观海之浪花》

```
风如大帚扫云后，天似蓝刀斩海中，
溅起浪花千万朵，瞬生瞬灭自无穷。
```

![](images/beihai.jpg)

# 赏析
```
此诗写浪花，取喻奇崛，笔力劲健。"风如大帚扫云后"——以"大帚"为喻将风拟作一把巨大的扫帚，将云层一扫而空，粗犷有力、出人意表。"天似蓝刀斩海中"更进一层——蓝天如一把巨大的蓝色刀锋，直斩入大海之中。这两句用"扫"与"斩"两个暴烈动词，营造出一种近乎暴力美学的画面感，颇有几分李贺的奇诡之风。

后两句写浪花的生成与消逝——天刀斩海，溅起千万朵浪花。然而这些浪花"瞬生瞬灭"，从迸溅到消散不过一瞬之间。"自无穷"三字将刹那与永恒合为一体——浪花虽转瞬即逝，但一浪灭一浪又起，这种生灭循环本身便是无穷。全诗以奇特的想象力捕捉了浪花的本质：在短暂中蕴含着永恒的力量，在瞬间里看见了无限的循环。
```
