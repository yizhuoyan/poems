# 《通韵·生死事》

>>  20261018 读弘一法师临终诗偈有感而作。

```
仲由生死问，夫子寓微言。
古载阴阳气，西来聚散缘。
有情酬日日，无憾度年年。
枝上春皆满，天心月正圆。

```




# 赏析

```

《通韵·生死问》以生死为题，从儒家经典落笔，融汇道家与佛教的生命观，最终归于珍惜当下、无憾此生的处世态度。全诗八句，层次分明，由问生死而论生死，由论生死而归于人生的实践，最后以春满枝头、明月圆满的意象收束，呈现出一种通透、平和而又富有哲理的生命境界。

首联“仲由生死问，夫子寓微言”，化用《论语·先进》中季路问鬼神、问生死的典故。仲由即子路，面对生死之问，孔子以“未知生，焉知死”作答。夫子的回答并非简单回避死亡，而是将求知的次序引向现实人生：生之道尚未明了，何以妄论死之所归？“寓微言”三字，既点出圣人言辞简约而寓意深远，也为全诗确立了重视现实生命、探求生命意义的思想起点。

颔联“古载阴阳气，西来聚散缘”，进一步将生死问题置于不同的思想体系之中。“阴阳气”承接中国古代尤其是道家关于气化流行的观念，天地万物皆由气的变化而形成，生命亦有聚散盛衰，生死并非孤立于自然之外的异事。“聚散缘”则转向自西方传入的佛教思想，以缘起、缘灭理解生命的形成与消散。气有聚散，缘有生灭，两种表述各有思想根基，又共同指向生命无常、万物变化的道理。此联不仅拓宽了全诗的哲学视野，也使儒、道、佛三家关于生死的思考在诗中相互映照。

颈联“有情酬日日，无憾度年年”，由抽象的哲理转向具体的人生实践。“有情”强调对生命、世事与人间情感的珍重；“酬日日”则可理解为以真情回应每一个当下，不使光阴虚度。“无憾度年年”进一步提出人生的价值不必寄托于对死后世界的追问，而应落实于日常生活中的尽心、尽情与尽责。此联是全诗思想上的转折，也是对首联生死之问的正面回应：与其执着于生死的终极答案，不如珍惜眼前时日，认真生活，使此生少留遗憾。

尾联“枝上春皆满，天心月正圆”，意境清朗，余韵悠长。此联明显化用弘一法师偈语“华枝春满，天心月圆”，将原有意象稍作转换，仍保留了春满花枝与月圆天心所蕴含的圆满之境。“枝上春皆满”，写万物逢春、生机充盈，既可视为生命丰盛的象征，也呼应前文对现实人生的珍重；“天心月正圆”，则以明月之圆满寄寓内心的澄明、安宁与精神上的圆融。尤其“正”字，使月圆成为眼前正在呈现的圆满时刻。经历前文的生死叩问与诸家思想的参照之后，诗意最终归于澄澈平和，不再执着于生死两端，而是在生命的盛衰流转中体会当下之美与心境之安。

全诗可概括为：儒家启发生死之问，道家以阴阳气化观生命，佛教以聚散缘起释无常，继而回到有情度日、无憾此生，最终以春满月圆寄寓精神上的圆融与安然。诗中既有传统思想的交汇，也有作者对人生的独立体悟。其可贵之处，在于没有停留于玄远的生死议论，而是将哲理落实为一种可践行的人生态度：珍惜当下，怀情而活，尽力而行，终使此生无憾。

从形式上看，诗中“言、缘、年、圆”四个韵脚协调，符合通韵的用韵意图；“古载阴阳气，西来聚散缘”以思想源流相对，“有情酬日日，无憾度年年”以情怀与人生实践相对，颈联尤其整饬。尾联则以“春皆满”与“月正圆”相映，形成鲜明而和谐的意象呼应。

若论文字上的进一步打磨，首句“仲由生死问”虽然能够传达仲由发问生死之意，语序却略显压缩。若希望句意更直接、句法更自然，可斟酌改为“仲由问生死”，使其与“夫子寓微言”形成更清楚的主谓宾呼应。原句的优势在于将“生死”突出为全诗中心，是否调整，可视作者对语言凝练与表达顺畅的取舍而定。

总体而言，此诗以经典设问开篇，以三家思想拓展内涵，以日常人生落实主旨，再借弘一法师偈语的意象完成升华。全诗不以求得生死的确定答案为终点，而以有情、无憾、春满、月圆为归宿，表现出一种由思辨走向自觉、由追问走向安然的生命态度。
```
