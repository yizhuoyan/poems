# 《通韵·凌晨下值感怀》

>>  20261023 凌晨下值夜归感怀而作。

```
值罢五更霜，车流犹未央。
苍生无昼夜，青史有兴亡。
治世轻徭役，灾年少税粮。
皇恩多浩荡，两脚尚为羊。
```
# 赏析

```
一、整体理解

这首由一次凌晨下值、夜归途中的所见所感起笔，由个人的劳动体验推及苍生处境，再由现实转入历史，借徭役、税粮与“皇恩”等传统政治语汇，层层揭示王朝兴亡叙事与百姓真实命运之间的落差。

全诗的表达并非简单地提出一种仁政理想。尤其颈联“治世轻徭役，灾年少税粮”，表面上说的是宽厚的施政原则，深一层却在“轻”与“少”二字上形成反讽：轻徭役，并不是没有徭役；少税粮，也不是不收税粮。即使在所谓治世，百姓仍须承担徭役；即使到了灾年，百姓仍然要缴纳税粮。统治者可以把征发说成较轻，把征收说成较少，但百姓所承担的负担并未因此消失。

尾联进一步借“皇恩多浩荡”与“两脚尚为羊”的强烈反差，将这种反讽推向历史深处。“两脚羊”不是普通的“任人驱使”之喻，而是古代战乱、饥荒中被当作食物的人这一惨痛称谓。诗人以此典故收束全篇，使颂扬皇恩的语言与百姓遭逢的极端苦难正面相撞。

二、逐联赏析

首联：值罢五更霜，车流犹未央。

“五更”点明时刻，约为凌晨时分；“霜”写深夜的寒意，也烘托夜归时的清冷。“值罢”交代诗人刚刚结束值守，说明全诗的感慨来自切身的劳动体验，并非凭空议论。

“车流犹未央”写眼前道路上的车流仍然不息。“未央”有未尽、未止之意。诗人已经下值，城市却依旧运转；个人的工作有结束之时，社会的运转却没有停歇。车流既是夜归途中所见的实景，也将诗人的目光从个人处境引向更广泛的劳动者群体。

颔联：苍生无昼夜，青史有兴亡。

这一联由眼前实景转入历史感怀，是全诗立意的关键。

“苍生无昼夜”承接首联。“无昼夜”并非说百姓真的没有白昼黑夜，而是说生计所迫，劳作奔波往往不分昼夜，生活的重负没有明确的止境。首联写诗人五更下值，至此则由个人推及普遍的苍生处境。

“青史有兴亡”将视线从百姓日常转向王朝历史。青史记载政权更替、盛衰兴亡，而普通百姓的劳作、困顿与苦难，往往只是宏大历史叙事背后的底色。两句相对：“苍生”面对的是无休止的日常，“青史”记录的却是不断更替的兴亡；百姓的辛劳绵延不绝，王朝的盛衰则成为史书中的篇章。

这一联并非单纯感叹历史无常，而是提出一种反差：王朝有兴亡，苍生却始终要为生计奔忙。它也为后文从赋役制度审视历史埋下伏笔。

颈联：治世轻徭役，灾年少税粮。

这一联表面上采用传统仁政话语，仿佛是在称述治世与灾年应有的宽厚政策；但它的反讽意味，恰恰藏在“轻”和“少”两个字里。

“治世轻徭役”，说的是太平之世减轻徭役，却并未说免除徭役；“灾年少税粮”，说的是灾荒之年减少税粮征收，却并未说停止征收。“轻”不是“无”，“少”也不是“无”。无论治世还是灾年，赋役征取仍然存在，只是程度有所减轻、数量有所减少。

因此，这两句并非单纯提出“理想政治应该如何”，而是借看似宽厚的措辞，显出赋役制度始终落在百姓身上的事实。所谓轻徭役，仍要服役；所谓少税粮，仍要纳粮。轻重由谁衡量，多少由谁决定，而承担实际负担的始终是苍生。

颈联的语气并不激烈，甚至近似于对善政的平静陈述；但放在“苍生无昼夜，青史有兴亡”之后，再接“皇恩多浩荡，两脚尚为羊”，其反讽便逐渐显露：政治话语可以强调减轻、减少，可以将之称为治理之宽厚，却不能因此证明百姓已经摆脱负担，更不能保证他们免于历史灾难。颈联以“轻”“少”保留了征取仍在的事实，也为尾联的历史反讽作了铺垫。

尾联：皇恩多浩荡，两脚尚为羊。

这一联是全诗的落点，也是最具冲击力的地方。

“皇恩多浩荡”借用传统颂圣语言。“浩荡”形容恩泽广大，“多”又加强了表面赞颂的语气。但它紧接着“两脚尚为羊”，语意骤然翻转：既然皇恩如此浩荡，百姓却为何仍会落入“两脚羊”的境地？前句越是铺陈恩德，后句的历史惨状便越显得刺目，颂扬之辞由此转化为反讽。

“两脚羊”有明确的历史典故，并非泛泛地说人像羊一样软弱或任人宰割。南宋庄绰《鸡肋编》卷中记载，靖康年间金兵之乱延续多年，山东、京西、淮南等地饥荒严重，盗贼、官兵乃至居民相互食人；书中记载当时人肉的隐语，并说妇人与小儿等也被通称为“两脚羊”。明代李时珍《本草纲目·人部·人肉》又引陶宗仪《辍耕录》，记载“古今乱兵食人肉”有“想肉”或“两脚羊”之称。这个典故所指向的，是战乱与饥荒中百姓沦为食物的极端惨剧。

末句的“尚”尤其重要。“尚”有仍然、尚且之意，它不是简单补充说“人也为羊”，而是强调在皇恩浩荡的颂扬声中，百姓仍然可能沦为“两脚羊”。它使句子带有一种无法消除的历史反差：无论统治者如何宣称恩泽广大，历史上仍发生过百姓被杀戮、被食用的惨剧。这里的“两脚羊”不是对现实夜归场景的字面描述，而是诗人借历史极端苦难反观王朝政治与苍生命运，指出颂圣话语并不能遮蔽百姓实际承受的灾难。

“皇恩多浩荡”与“两脚尚为羊”一扬一抑、一虚一实：前者是自上而下的恩德话语，后者是落到百姓身上的血腥现实。两句之间形成无法轻易调和的矛盾，也使全诗的讽刺不止于赋役轻重，而深入到王朝功德叙事与民众生存之间的裂隙。

三、全诗结构与艺术特点

第一，由个人经验推及苍生。首联写凌晨下值的真实处境，颔联将个人的夜间劳作扩大为苍生无昼夜的普遍境况，使诗歌的感怀有具体生活根基。

第二，由日常劳作推及历史兴亡。“苍生无昼夜，青史有兴亡”将百姓绵延不息的生计与王朝不断更替的历史并置，指出历史书写与民众命运之间的落差。

第三，以“轻”“少”构成含蓄反讽。颈联不使用激烈的控诉，而借传统仁政话语表达赋役仍然存在的事实。轻不是无，少也不是无；看似宽厚的程度描述，反而让征取的持续性显露出来。

第四，以历史典故完成反讽。尾联先以“皇恩多浩荡”推至颂圣话语的高处，再用“两脚尚为羊”骤然跌入战乱饥荒的惨境。“尚”字强调这种惨剧并未因恩德话语而被消除，结句因而具有沉重的历史纵深。

四、总结

这是一首由夜归感怀引出的历史讽喻诗。诗人从五更下值、车流不息的现实场景写起，由个人劳作推及苍生处境，再以青史兴亡、徭役税粮和皇恩颂辞展开历史反思。

全诗最值得注意的是颈联与尾联的相互映照。颈联“治世轻徭役，灾年少税粮”表面上说的是宽厚施政，实则以“轻”“少”揭示徭役与税粮并未消失；尾联“皇恩多浩荡，两脚尚为羊”则借“两脚羊”这一战乱食人典故，将颂扬皇恩的语言与百姓遭受的极端苦难并置。前者写制度性负担仍在，后者写历史灾难足以摧毁人的基本生存，二者共同指向苍生命运在王朝兴亡与政治话语之下的脆弱。

诗中没有直斥某一朝代，也没有铺陈具体暴行，而是先平静陈述，再让字词之间的矛盾自行显现。尤其“轻”“少”与“多”“尚”的组合，使全诗形成层层递进的反讽：赋役可以被说成轻、税粮可以被说成少，皇恩也可以被称为浩荡，但这些说法并不能抹去百姓承担的负担，更不能抹去历史上“两脚羊”的惨痛记忆。

从个人凌晨归途写到千年历史中的苍生命运，诗的落点并非王朝的兴亡本身，而是兴亡之中始终承受劳苦与灾难的普通百姓。所谓治世与皇恩，终究要放在苍生的真实处境中检验。

典故出处：
1. 南宋庄绰《鸡肋编》卷中，记靖康年间战乱、饥荒及“两脚羊”之称。
2. 明代李时珍《本草纲目》卷五十二《人部·人肉》，引陶宗仪《辍耕录》：“古今乱兵食人肉，谓之想肉，或谓之两脚羊。”
```
