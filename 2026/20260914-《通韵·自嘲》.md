# 《通韵·自嘲》

>> 20260914

```
大肚秃头少锦肠，肥腰老齿臭皮囊。
一身俗病怎医治？江月山风是药方。
```




# 赏析

```
这首《通韵·自嘲》是一首很有生活气息的自嘲小诗。全诗不避“丑”字，不饰己身，先把“大肚、秃头、肥腰、老齿、臭皮囊”一股脑摆出来，写得甚至有些故意粗粝；然而结尾忽然一转，以“江月山风是药方”收住，把前面的俗病、衰老、外在不堪，转化为一种很旷达的生活态度。诗的真正落脚点并不是“嘲自己”，而是说：身体可以衰老，俗病可以缠身，但自然山水仍能疗愈精神。

首联“大肚秃头少锦肠，肥腰老齿臭皮囊”写得非常直白，而且两句有明显的递进。

“大肚秃头”首先是外貌上的自嘲，完全不加修饰；“少锦肠”则由形入神。“锦肠”本来有才思华美、文采斐然之意，“少锦肠”表面是在说自己没有多少文采，实际上又与前面的“大肚秃头”形成反差：身体已经不修边幅，连“锦肠”这样的文人自许也不要了，显出一种主动拆掉斯文外壳的幽默感。

“肥腰老齿臭皮囊”进一步把这种自嘲推到更彻底。“肥腰”比单纯的“腰圆”更有肉感，也更直接，甚至带着一点故意的粗俗；“老齿”点出年岁；到了“臭皮囊”，则已经不是某一个身体部位，而是把整个肉身一概而论。这个词本身就带有明显的佛家意味，因此它虽然诙谐，却并非纯粹的搞笑，而隐约包含着对肉身衰朽、人生无常的意识。

第三句“一身俗病怎医治？”是全诗的转折关节。“俗病”很值得玩味。它当然可以包括肥胖、衰老之类的身体毛病，但“俗”字又把范围扩大了：人的各种尘世习气、世俗牵累、精神上的毛病，也都可以叫“俗病”。所以这句表面自问身体，深处其实是在问：这样一个满身尘俗的人，究竟拿什么来医？

末句“江月山风是药方”回答得极漂亮，而且有一种近乎顽童式的幽默。

前面说了一大堆“大肚”“秃头”“肥腰”“老齿”“臭皮囊”，好像病得很重，结果最后开的药方却不是药，而是“江月山风”。这就产生了强烈的反差和诗意。所谓“药”，不是治肉身的药，而是山水对人的精神疗愈；所谓“方”，也不是传统医方，而是一种生活方式。江上之月、山间之风，既是自然美景，也是摆脱“俗病”的精神出口。

而且“江月山风”四字非常有画面感。读者仿佛能看到江边月色，听到山间清风。全诗前面一直是“身体”，最后突然打开到“天地”，空间一下子从自身的肉身扩展到了江山自然，境界也就在这一转之间豁然开朗。

这首诗最有意思的地方，是“自嘲”与“自我解嘲”其实是两层。前两句是真的嘲自己，而且嘲得不留情面；第三句又把自己归入“俗人”之中；最后却没有陷入自怜，而是用江月山风把自己从“皮囊”里解放出来。因此诗的底色并不悲凉，反而相当旷达。

尤其是“臭皮囊”与“药方”的对照，很见构思。一个是最世俗、最具体、甚至略带滑稽的肉身，一个是最清逸、最空灵的自然。全诗实际上是在写一种很朴素的哲学：肉身终究会老，人的“俗病”也未必能够彻底医治，但可以让江月山风来疗自己的心。

如果要概括这首诗的味道，我会说：前两句“敢于自丑”，后两句“终于自解”；笑自己而不苦自己，认自己的俗，却不困于自己的俗。这正是这首《自嘲》最可取的地方。
```
