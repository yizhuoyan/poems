# 《通韵·咏十一》

>> 家有猫，名十一，咏之以诗 20260917

```
喵喵复喵喵，轻灵大胖猫
临梅能作画，遇犬敢挥刀
蹲下爪尖蓄，扑出嘴上叼。
将军又得胜，尾竖一身骄。
```




# 赏析

```
这首《通韵·咏十一》以家猫“十一”为题，抓住猫的叫声、体态、捕猎动作和得意神态，将日常生活中的一只家猫写得既灵动可爱，又俨然一位能文能武、屡战屡胜的“将军”。全诗语言活泼，想象诙谐，把猫的一举一动都赋予了戏剧性的色彩。

“喵喵复喵喵，轻灵大胖猫。”开篇从猫叫写起，“喵喵复喵喵”写叫声连续不断，语气轻快，也一下点明了吟咏对象。“轻灵”与“大胖”并置尤其传神，体态虽胖，动作却轻捷，既写出了十一的外形，又写出了它灵活可爱的特点。

“临梅能作画，遇犬敢挥刀。”这一联开始发挥想象。“临”既有靠近之意，又暗含临摹之意，猫爪留下的痕迹于是仿佛成了作画的笔触；而遇到犬时，猫爪又被想象成锋利的刀。前一句写巧，后一句写勇，猫从一个会“作画”的小动物，转眼又成了敢于迎敌的武者，诙谐中带着几分神气。

“蹲下爪尖蓄，扑出嘴上叼。”诗笔重新落回猫的真实动作。“蹲下”是蓄势，“扑出”是爆发，一个“蓄”一个“扑”，把猫捕猎时由静到动的过程写得十分鲜明。“爪尖蓄”尤其有力量感，仿佛所有劲道都集中在爪尖，下一刻便猛然扑出，而“嘴上叼”则迅速交代了结果，动作干脆利落。

最后“将军又得胜，尾竖一身骄。”是全诗最有神的一笔。前面“挥刀”“蓄”“扑”“叼”写的其实只是猫的日常动作，到这里却被统一提升成了一场战斗，于是捕到猎物不再只是捕食，而成了“将军得胜”。“又”字尤其有趣，不仅写出这次胜利，还暗示十一似乎已经屡战屡胜，颇有战功。

更精彩的是“尾竖一身骄”。诗人没有直接说猫“骄傲”，而是抓住猫胜利后尾巴竖起这一极具辨识度的动作，以一个局部动作写出整只猫的精神状态。“一身骄”又把“尾竖”进一步夸张：不是尾巴在骄傲，而是全身都在骄傲。这样一来，前面的“将军”也就真正有了神态，仿佛刚刚凯旋，昂首挺胸，满身都是“我又赢了”的得意。

因此，这首诗真正有趣的地方，并不只是把猫写得可爱，而是把它日常的每一个动作都戏剧化了：见梅可以作画，遇犬可以挥刀，捕猎便如出征，捕获便是凯旋。全诗最终以“尾竖一身骄”收住，把十一的灵动、勇猛和得意集中在一个鲜活的动作里，使这只“大胖猫”带着满身骄气定格在读者眼前，生动而有趣。

```
