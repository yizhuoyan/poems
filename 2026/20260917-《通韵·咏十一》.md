# 《通韵·咏十一》

>> 家有猫，名十一，咏之以诗 20260917

```
食饱且攀高，轻灵大胖猫。
临梅能作画，遇犬敢挥刀。
蹲踞爪尖蓄，飞扑嘴上叼。
将军又得胜，尾竖一身骄。
```




# 赏析

```
《通韵·咏十一》是一首以庄写谐、以人写猫的趣诗。诗中故意采用“作画”“挥刀”“蓄”“将军”“得胜”等郑重甚至带有英雄色彩的语言，来描写一只家猫吃饱攀高、踩雪作画、遇犬亮爪、飞扑捕猎的日常生活。猫本来是家常之物，诗人却一本正经地将十一塑造成一位能文能武、屡战屡胜的“小将军”，越写得郑重，反而越显出诙谐，也越能传达主人对它的宠爱与欣赏。

“食饱且攀高，轻灵大胖猫。”首联看似只是写猫的日常状态，实际上前后两句彼此照应。“食饱”对应“大胖”，写出十一吃得饱、长得胖的体态；“攀高”对应“轻灵”，写出这样一只“大胖猫”却依然身手敏捷。于是“轻灵”与“大胖”并置，形成了形体与动作之间有趣的反差，而这种反差并非凭空制造，而是由上一句自然引出。一个“且”字又把“食饱”与“攀高”连接起来，仿佛吃饱之后仍兴致勃勃地四处攀登，既写出猫的自在，也写出它的活泼。首联因此既交代了十一的体态，又写出了它的性情，为全诗的诙谐基调定下了基础。

“临梅能作画，遇犬敢挥刀。”这一联最见巧思。上句的“临”既可理解为靠近梅，也暗含“临摹”之意；猫爪在雪地、地面或纸面上留下的痕迹，被诗人想象成一幅“梅花图”，于是十一俨然成了一个会作画的文人。“作画”本属人的行为，用来写猫，形成自然的拟人与幽默。下一句忽然由“文”转“武”，“刀”实为猫爪，却故意把猫爪写成兵刃；“敢”字尤其传神，写出十一面对狗时毫不退缩、敢于亮爪的气势。一联之中，十一从“画家”变成“战士”，文武兼备，庄谐意味也随之更加突出。

“蹲踞爪尖蓄，飞扑嘴上叼。”这一联把镜头进一步推向动作本身。“蹲踞”是出击前的定格，“爪尖蓄”写力量凝聚、蓄势待发；一个“蓄”字既符合猫收爪、蓄力的真实动作，又带有武者藏锋待发的意味。下一句“飞扑”骤然爆发，速度感极强，而“叼”又是非常贴近猫的动作，一个“叼”字便把整个捕猎过程落到了实处。于是这一联形成鲜明的动静转换：先蹲踞蓄势，继而飞扑得手，仿佛一组极短而有力的动作镜头。

“将军又得胜，尾竖一身骄。”结尾是全诗最精彩的收束。“将军”承接前面的“挥刀”“蓄势”“飞扑”，至此才正式揭晓十一的身份：原来这只“大胖猫”竟是一位屡战屡胜的将军。“又”字尤其有趣，说明得胜并非偶然，而是十一平日里反复上演的日常战绩。末句“尾竖一身骄”则把前面的英雄叙事重新落回到最真实、最可爱的猫态上。猫尾高高竖起，是胜利后的得意神态；“一身骄”又把这种骄傲从尾巴扩展到整个身体，仿佛刚刚凯旋的将军正在昂首接受夸赞。于是前面那些庄严的“作画”“挥刀”“将军”“得胜”，最终都落实成了一只猫得意洋洋地竖起尾巴的生活场景，反差之中趣味十足。

全诗的构思是一层层给十一“加封”：先以“食饱”“攀高”写出“轻灵大胖猫”的真实形象，继而成为作画的文人、挥刀的武士、捕猎的战士，最后成了凯旋而归的将军。诗人始终用一本正经的笔调写极其家常的猫事，把平凡生活写出了一种“英雄传奇”的意味。而结尾又从“将军”重新回到“尾竖”的猫态，使全诗既有夸张的戏剧性，又始终不失生活气息。

诗中没有直接写一个“爱”字，但对十一的熟悉、欣赏与宠爱，都藏在这些具体的动作和称呼之中。它不是泛泛咏猫，而是在写“十一”这个独一无二的角色：吃得胖，却攀得高；能画、敢战、善捕，而且每次胜利之后还要骄傲地竖起尾巴。正因为写得郑重其事，这只家猫才显得格外有趣，也格外可爱。
```
