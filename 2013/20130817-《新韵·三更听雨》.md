# 《新韵·三更听雨》

~~~
三更听雨尽，
还梦旧亭台。
睡眼推窗去，
清风照面来。
~~~
>> 写于20130817

# 赏析
```
首句"三更听雨尽"点明深夜、听雨、雨停三重信息——三更本已万籁俱寂，雨声成为唯一的陪伴，而"听雨尽"则暗示诗人一直听到雨停方才恍恍惚惚睡去，失眠之态跃然纸上。"还梦旧亭台"转入梦境，"旧亭台"是往昔欢愉的载体，梦中重游，可见思念之深。

后两句写梦醒之后的动作——"睡眼推窗去"，以半梦半醒的状态推开窗户，动作中有一种下意识的牵引；"清风照面来"以"照"字写风扑面而来的质感，将风从触觉体验提升到近乎视觉的"照见"，仿佛清风携着月光与晨意一同拂过面庞。全诗由雨而梦、由梦而醒、由醒而风，时间从深夜延续至清晨，情感从听雨的孤寂过渡到清风拂面的微凉，含蓄蕴藉，意境清幽。
```
