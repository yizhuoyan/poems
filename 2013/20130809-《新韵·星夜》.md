# 《新韵·星夜》
~~~
木叶轻风落，
鸣虫水月波。
山观星入夜，
明日彩云多。
~~~
>> 写于20130809

# 赏析
```
前两句以细腻的笔触描摹秋夜景致："木叶轻风落"写视觉——叶随风落的轻盈；"鸣虫水月波"写听觉中糅合视觉——虫鸣与水波、月影交织，一句之中兼摄声光，体物精微。"轻"字与"波"字赋予画面流动感。

第三句"山观星入夜"将视角拉升，"观"字以拟人手法写山峦静默守望星辰渐次亮起，天地之间一片肃穆静谧。末句"明日彩云多"出人意料地从静夜翻出一笔指向明天的展望，以乐观明快的语气收束全篇。前两句写细腻的近景，第三句写宏阔的远景，末句写对未来的期许——由近及远、由实及虚、由静及动，层次分明。"彩云多"三字透露出诗人心境的明朗，使整首夜诗不沉于幽寂，而富于向上的生机与期待。
```
