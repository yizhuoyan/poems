# 《新韵·贺寿》
```
东海沿江去，
南山不愿迟。
天边云几朵，
载我鹤一只？
```
>> 写于20130419

# 赏析
```
这是一首别具一格的贺寿诗。前两句化用传统祝辞"福如东海，寿比南山"——"东海沿江去"以流水意象暗喻福泽绵长；"南山不愿迟"以拟人手法写南山迫不及待地献寿，生动俏皮。"不愿迟"三字将静态的山水写得活泼有灵，一扫贺寿诗常有的庄重板滞。

后两句奇峰突起，"天边云几朵"意境清朗空灵，末句"载我鹤一只"以一个天真烂漫的问句收束——诗人仿佛欲化身为鹤、驾云而去，既有道家仙游的超逸，又不失童趣般的想象。鹤在传统文化中亦是长寿之征，与祝寿的主题暗合。全诗将传统寿俗意象信手拈来却又翻出新意，举重若轻，妙趣天成，在贺寿题材中可谓别开生面之作。
```
