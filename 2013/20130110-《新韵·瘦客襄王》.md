#《新韵·瘦客襄王》
```
莫名昨夜梦一场，山远斜阳草近香。
可恨当年为瘦客，才觉此刻若襄王！
```
>> 写于20130110

# 赏析
```
起句"莫名昨夜梦一场"以"莫名"二字领起，营造朦胧恍惚的梦境氛围。次句"山远斜阳草近香"以远景之山与近处之草构成空间纵深，斜阳余晖与草木芬芳交叠，是一帧颇具意境的梦中山水。

后两句化用宋玉《高唐赋》中楚襄王梦遇巫山神女的典故。"瘦客"与"襄王"对举，意趣横生——当年自视不过一个清瘦落拓的过客，如今回望才发觉彼时竟如襄王般置身于一段美好际遇之中。"可恨"二字看似懊恼，实则是对当时"不识庐山真面目"的慨叹——身在福中不知福，待到醒时才读懂那场梦的珍贵。全诗借典抒怀，将旧梦重温与人生感悟熔于一炉，语言晓畅而意蕴绵长。
```
