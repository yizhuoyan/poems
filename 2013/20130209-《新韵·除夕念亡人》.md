# 《新韵·除夕念亡人》

~~~
竹爆同一刻，
烟花起四方。
荣华坟外事，
岁岁短松岗!
~~~
>> 写于20130209

# 赏析
```
前两句铺陈除夕夜的热闹景象：爆竹齐鸣、烟花四起，万家团圆欢庆之时，以乐景为后文的哀思蓄势。一个"同"字写天下共此时的热烈，"四方"更拓展了喜庆的空间广度。

第三句"荣华坟外事"釜底抽薪——世间所有的繁华喧嚣都是"坟外"之事，与长眠之人再无关联。此句以极为冷静的语气道出残酷真相：死生之间隔着不可逾越的鸿沟，一切热闹都属于生者。末句"岁岁短松岗"化用苏轼"明月夜，短松冈"之意，以年年岁岁不变的松岗意象，写时间的恒久与思念的绵长。"岁岁"叠用，更添无尽之感。全诗前后两片、一热一冷形成强烈对比，二十字之中极具张力，是节令悼亡诗中的精品。
```
