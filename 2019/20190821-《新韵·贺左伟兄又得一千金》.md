# 《新韵·贺左伟兄又得一千金》
```
古有江东大小乔，
今全左氏两阿娇。
从来名字为难事，
诗奕诗瑶又桃夭。
```
>> 写于20190821

# 赏析
```
这是一首祝贺友人再添千金的酬赠之作。首句"古有江东大小乔"以历史上著名的绝代双姝——大乔与小乔起兴，将友人的两位女儿比作名门闺秀，格调高雅。次句"今全左氏两阿娇"进一步用典，"阿娇"既指汉武帝"金屋藏娇"的陈皇后，也是对可爱女儿的通称——古有乔家双璧，今有左氏双娇，古今呼应，贺意满满。

后两句转入风趣的调侃。"从来名字为难事"——给子女取名向来是令父母头痛的事，道出了多少父母的心声。末句"诗奕诗瑶又桃夭"巧妙嵌入两个千金的名字（诗奕、诗瑶），"桃夭"则化用《诗经·桃夭》"桃之夭夭，灼灼其华"之意，既赞美女孩的美好，又暗合婚嫁之喜。全诗用典精当、古今交融，既有祝贺的真诚，又有朋友间的诙谐，是一首得体的贺诗。
```
